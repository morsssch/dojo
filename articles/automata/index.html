Введение

Какие задачи будем решать

Регулярные выражения и конечные автоматы описывают одни и те же языки — это утверждение теоремы Клини. Научимся переводить одно в другое, убирать ε-переходы, детерминизировать и минимизировать автоматы. Отдельно разберём нумерацию слов и автоматы с выходом.

Тип А. Регулярка → автомат

Дано R, например (x+y+)(x*y+x)++(x+y)* из примера. Нарисовать конечный автомат, который допускает тот же язык. Автомат может быть недетерминированным и с ε-дугами. Метод: разбиение дуг.

Тип Б. Автомат → регулярка

Дан граф автомата. Найти регулярное выражение его языка. Метод: нормализуем граф и удаляем вершины по одной, пока не останется одна дуга. Пример — задача Б2.

В каждой теме: теория → пошаговый разбор → частые вопросы → практика с решением. Тренажёры принимают и твои примеры.

Как оформлять на листке

По образцу листка, который скинул преподаватель. Полные образцы обоих типов — в части 6.

  • шаги пронумерованы: «1. Нормализуем», «2. Удаляем q₂» и так далее;
  • на каждом шаге одна фраза, что делаешь, и перерисованный граф;
  • в типе Б для каждой удаляемой вершины выписываешь пары «откуда → куда» и формулу R₁R₂*R₃ — это то, что преподаватель будет проверять глазами;
  • в конце ответ: в типе А готовый граф, в типе Б выражение R = ….

Не перепутай с ЛР4. ε-замыкания, таблицы S₀, S₁, … и P₀, P₁, … — это детерминизация, её будешь программировать в ЛР4. На ЛР3 автомат может спокойно оставаться недетерминированным. Она разобрана в части 8, а следующая тема, минимизация, — в части 9.

Нумерация слов

Теория

Зафиксируй порядок букв: Σ = {a, b, c}. Сначала перечисляем слова по длине, а среди слов одной длины — по алфавиту: ε, a, b, c, aa, ab, ac, ba, … Это порядок по длине и лексикографический внутри длины (shortlex). Пустое слово имеет номер 0.

Буквам присваиваем номера от 1 до n, где n — размер алфавита. Номер слова x₁…xₖ равен:

N(x₁…xₖ) = d(x₁)·nᵏ⁻¹ + d(x₂)·nᵏ⁻² + … + d(xₖ)·n⁰.

Это похоже на позиционную систему счисления, но цифры здесь 1…n. Нулевой буквы нет. Поэтому при обратном переводе остаток 0 означает последнюю букву алфавита, а не отдельный символ.

Регулярные выражения

Регулярка строится из букв алфавита, ε (пустое слово) и ∅ (пустой язык) тремя операциями. Плюс одно сокращение, которое любят на доске. Под каждой операцией — автомат, который допускает ровно слова из примера: пройди по стрелкам и прочитай буквы.

Приоритет: сначала * и +-степень, потом склейка, в самом конце сумма. Поэтому ab* — это a, потом b сколько угодно раз, а не (ab)*. И a+bc — это a или bc, а не (a+b)c. Разница на картинке:

Тождества

Ими упрощаешь ответы в типе Б. Каждое тождество — это два графа, которые допускают одни и те же слова: слева как получилось, справа как можно записать короче. Пунктир с ∅ — дуги на самом деле нет.

На дугах можно писать регулярки

Разрешим писать на дуге не одну букву, а целое регулярное выражение. Дуга p —R→ q значит: из p в q можно пройти по любому слову из R. Такой граф называют обобщённым.

Отсюда оба метода. В типе А стартуем с одной дуги q₀ —R→ qf и разбиваем её на маленькие, пока на дугах не останутся буквы и ε. В типе Б делаем обратное: сворачиваем граф, удаляя вершины, пока не останется одна дуга. Её метка и есть ответ.

~35 мин

Регулярка → автомат

Теория

Рисуем q₀ и qf, между ними одна дуга с R. Дальше на каждом шаге берём любую дугу, на которой написано не одна буква и не ε, смотрим на её главную операцию и заменяем по правилу. Базовые случаи из лекции: R = ∅ — дуги нет; R = ε — ε-дуга; R = a — дуга по букве a. Это уже готовые кусочки, их не трогаем.

Как найти главную операцию

Это операция, которая выполняется последней. Смотри на то, что стоит вне всех скобок:

  • есть + вне скобок → главная сумма: (ab+b+)*a + (ab)* — два слагаемых;
  • плюсов вне скобок нет, но кусков несколько → главная склейка: (ab+b+)* · a;
  • всё выражение — одна скобка или буква со звёздочкой → главная итерация: (ab+b+)*;
  • всё выражение в скобках без звёздочки → сними скобки и смотри внутрь.
  1. Нарисуй q₀ —R→ qf.
  2. Найди дугу, где метка не буква и не ε. Определи главную операцию.
  3. Замени дугу по правилу: + → параллельные дуги, склейка → цепочка, * → вершина с петлёй и ε-дугами, ⁺ → вершина с петлёй, вход по R.
  4. Повторяй, пока все метки — буквы или ε. Петли разбиваются так же, как обычные дуги.

Что если в твоей задаче…
…хочется повесить петлю прямо на старую вершину, без ε-дуг

Нельзя: у вершины могут быть другие дуги, и петля начнёт «смешиваться» с ними. Пример: a*b + c. Если повесить петлю a прямо на q₀, получится, что слово ac допускается, хотя в языке его нет: в R буква c стоит одна. Поэтому для звёздочки всегда новая вершина с ε-входом и ε-выходом.

…в старом конспекте петля висит без ε-дуг

В разборе КР для ab*c нарисовано S —a→ q (петля b) —c→ …, без ε. Это законно только в цепочке: у вершины ровно одна входящая и одна исходящая дуга, и обе её собственные. Если не уверен, ставь ε-дуги, как на лекции 29.09 — так ошибиться нельзя.

…в выражении есть x+

R+ = RR*. Можно разбить как склейку R и R*, а можно короче: новая вершина n, вход p —R→ n, петля R на n, выход n —ε→ q. Тренажёр делает короче. Оба варианта правильные.

…получилось много ε-дуг

Это нормально, на ЛР3 автомат может быть с ε-переходами. Убирать их не обязательно. Если преподаватель просит автомат без ε, понадобятся ε-замыкания. Детерминизация — отдельный следующий шаг, если требуется ДКА.

…одна и та же буква встречается в выражении несколько раз

Каждому вхождению своя дуга. Не склеивай вершины «по смыслу», даже если кусочки похожи: например, в (ab)*+ab будут две разные цепочки a → b.

…скобки вложены глубоко

Иди снаружи внутрь, по одной дуге за шаг. Каждая скобка раскроется в своё время. Порядок, какую дугу брать первой, на результат не влияет.

…в выражении есть ε как слагаемое, например (ε+a)b

Сумма даёт две параллельные дуги, одна из них ε. То есть «можно пройти, ничего не прочитав». Ничего специального делать не надо.

Автомат → регулярка

Теория

Цель — свести граф к двум вершинам и одной дуге между ними. Метка на этой дуге — ответ. Делается в три шага.

Шаг 0. Подготовка: недостижимые вершины и нормализация

Сначала сотри недостижимые вершины — те, в которые нельзя попасть из начальной, — вместе с дугами, которые из них выходят. Так делают в разборе КР прошлого года. Если не стереть, ответ не испортится, но будет лишняя работа.

Нормализация — это подготовка графа к сворачиванию. В конце должна остаться одна дуга s —R→ f, и всё. Значит, нужна ровно одна начальная вершина, в которую ничего не входит, и ровно одна финальная, из которой ничего не выходит. Иначе на них по ходу удаления появятся петли и лишние дуги, и одной меткой ответ не запишешь.

Почему можно просто добавить вершины: ε-дуга ничего не читает, поэтому новые s и f язык не меняют. Все случаи на картинках, новое выделено синим:

На лекции 24.09 в q₁ ничего не входило, поэтому добавили только qf (задача Б2).

Шаг 1. Склейка параллельных дуг

Две дуги p —R₁→ q и p —R₂→ q заменяем одной p —R₁+R₂→ q. Две петли a и b на одной вершине — одна петля a+b. Подпись «0,1» сразу пиши как 0+1.

Шаг 2. Удаление вершин

Берём любую вершину r, кроме s и f. Смотрим на её петлю R₂ и на все дуги, которые в неё входят и из неё выходят. Для каждой пары «вход p —R₁→ r» и «выход r —R₃→ q» рисуем дугу:

  • Петли нет — пишем просто R₁R₃.
  • p и q совпали — новая дуга становится петлёй на p.
  • Между p и q уже была дуга R₀ — склеиваем: R₀ + R₁R₂*R₃.
  • Входов k, выходов m — новых дуг k·m. Самая частая ошибка — забыть пару, поэтому выписывай их списком.

Эти частные случаи на картинках (удаляем r):

  1. Нормализуй граф.
  2. Склей параллельные дуги и петли.
  3. Выбери вершину. Удобнее брать ту, у которой меньше всего пар «вход × выход».
  4. Выпиши входы, петлю, выходы и формулу для каждой пары. Упрости ε. Перерисуй граф.
  5. Повторяй, пока не останутся только начало и конец. Метка между ними — ответ.

Ответы бывают разными по виду. Другой порядок удаления даёт другую запись, но язык тот же. Если у тебя и у соседа разные выражения, это ещё не ошибка. Проверка — подставить несколько слов или прогнать в тренажёре.

Разбор 2. Две финальные и цикл

Тут нужна полная нормализация, а при удалении q₂ появляется петля на q₀ и склейка с уже существующей дугой.

Что если в твоей задаче…
…начальная вершина одновременно финальная

Значит, пустое слово ε в языке. Нормализуй как обычно: s —ε→ q₀ и q₀ —ε→ f. В ответе появится ε как слагаемое или звёздочка снаружи. Пример — задача Б3.

…у вершины нет выходов или в неё нельзя попасть

Через неё не проходит ни одно допускаемое слово. Пар «вход × выход» ноль, поэтому просто стираешь вершину вместе с дугами.

…между двумя вершинами дуги в обе стороны

Когда удаляешь одну из них, пара «вход из p, выход в p» даёт петлю на p: p —R₁R₂*R₃→ p. Если на p уже была петля, склеиваешь через +.

…у удаляемой вершины несколько петель

Сначала склей их в одну: петли a и b = петля a+b. В формулу идёт (a+b)*, а не a*b*.

…в метке уже стоит сумма, а её надо склеить

Бери в скобки. Вход 1+00, петля 0, выход 1 дают (1+00)0*1, а не 1+000*1. Это самая частая ошибка при переписывании.

…хочется сокращать быстрее

В разборе КР есть два частных случая правила R₁R₂*R₃: p —ε→ r (петля a) —ε→ q даёт a*, а p —a→ r (петля a) —ε→ q даёт aa* = a+. Если узнаёшь картинку, пиши сразу.

…из начала в конец вообще нет пути

Язык пустой: R = ∅.

Здесь две разные задачи. Удалить ε — заменить бесплатные перемещения обычными переходами. Детерминизировать — заменить несколько возможных текущих вершин одной вершиной-набором. Сделаем их по очереди на одном маленьком примере.

Сначала идея, без новых обозначений

Будем использовать только q₀,q₁,q₂,q₃. Фигурные скобки означают «все возможные варианты», а не маршрут: {q₁,q₂} — можно находиться в q₁ или q₂. Для допуска слова достаточно одного успешного варианта, поэтому терять варианты нельзя.

Одна клетка при удалении ε: бесплатно до буквы → прочитать одну букву из всех доступных вершин → бесплатно после буквы → записать все результаты. Это правило повторяется для каждой строки и каждой буквы.

Первый лист: автомат без ε

Второй лист: детерминированный автомат

  1. Создай P₀={q₀}. Это начальный набор после удаления ε.
  2. Возьми первый набор P с незаполненной строкой. Для каждой буквы объедини клетки первого листа всех q из P.

Дополнительно: как читать обозначения S и P в исходном материале

Удаление ε-переходов: что именно сохраняем

ε-переход не съедает букву. Если из p можно бесплатно дойти в r, то все способы читать слово из r должны оставаться доступны и из p. Удаляем стрелку, но переносим её возможности. Простое стирание ε-дуг изменит язык.

  1. До чтения буквы: найди всё, куда можно бесплатно попасть из текущего состояния — Ξ(q). Поиск продолжай через всю цепочку ε-дуг. В цикле повторно посещённые вершины не добавляй.
  2. Прочитай ровно одну букву: из всех вершин Ξ(q) собери концы дуг с нужной буквой.
  3. После буквы: снова пройди любые ε-дуги из полученных концов. Объедини результаты, удали повторы. Это одна клетка новой таблицы.
  4. Проверь финальность: если Ξ(q) содержит хотя бы одно старое финальное состояние, новое состояние тоже финальное. Так сохраняется в том числе допуск пустого слова.

Детерминизация: одна вершина хранит все варианты

НКА после одной буквы может находиться сразу в нескольких состояниях. ДКА хранит весь этот набор как одну вершину. Для каждого нового набора создай строку; на каждой букве объедини переходы всех его элементов. Порядок и повторы не важны: {S₁,S₂}={S₂,S₁,S₁}. Уже встречавшийся набор получает прежнее имя.

На примере P₀={S₀,S₃}: по a объединяем {S₁,S₂}∪{S₂}={S₁,S₂}=P₁; по b получаем {S₃}=P₂. Из P₁ по a получаем P₂, по b — ∅. Из P₂ по a получаем {S₂}=P₃, по b — P₂. Из P₃ переходов нет. Финальные P₁ и P₃. Останавливаемся, когда заполнены все строки всех найденных наборов.

∅ и ε — разные вещи. ∅ — ни одного возможного состояния; ε — пустое слово или бесплатный переход. В полный ДКА ∅ входит как нефинальная вершина с петлями по всем буквам. В неполном ДКА клетку можно оставить пустой и считать слово отвергнутым.

Теория
Детерминированный
δ(q, a) содержит не больше одного состояния для любых q и a: из каждой вершины по каждой букве не больше одной стрелки, ε-дуг нет.

Теорема
для любого недетерминированного автомата-распознавателя существует эквивалентный ему детерминированный. Доказательство конструктивное — это и есть алгоритм ниже.
ε-замыкание Ξ(q)
множество состояний, достижимых из q без подачи входного сигнала (по одним ε-дугам), включая само q.
Переход в автомате без ε
δ(Ξ(q), a) = ∪ Ξ(s) по всем s, куда из состояний Ξ(q) можно уйти по a. По-русски: из ε-замыкания q по букве a, а потом снова ε-замыкание.

Строим так:

  1. ε-замыкания. Для каждого состояния q находим Ξ(q) — всё, куда из q можно дойти по одним ε-дугам, включая само q. Обозначаем Si = Ξ(qi).
  2. Таблица S (автомат без ε). Для Si и буквы a: берём все состояния из Si, смотрим, куда они уходят по a, к результату добавляем ε-замыкание. Каждое полученное состояние qx записываем как Sx. Финальные S — те, в которых есть исходное финальное.
  3. Таблица P (детерминизация). P0 — все начальные S: каждое Si, у которого qi ∈ Ξ(q0). Например, Ξ(q0) = {q0, q1} ⇒ P0 = {S0, S1}. Для P и буквы a объединяем клетки таблицы S по всем S из P. Новое множество получает следующее имя P1, P2, …, уже встречавшееся — своё старое имя, пустое — ∅, стрелки нет. Повторяем, пока у всех P не заполнены строки. Финальные P — те, где есть финальное S.
  4. Граф по таблице P.
  5. Проверка цепочки, как в лекции: (P0, w) ⊢ … ⊢ (Pk, ε). Pk финальное — допускается.

…ε-дуг в автомате нет вообще

Тогда Ξ(q) = {q} для каждого q, и таблица S просто повторяет таблицу переходов. Сразу переходи к таблице P: P0 = {S0}, дальше объединения. Пример — задача Д3.

…ε-дуги идут цепочкой p —ε→ q —ε→ r

В замыкание попадает вся цепочка: Ξ(p) = {p, q, r}. Иди по ε-дугам, пока есть куда.

…непонятно, с чего начинать P0

P0 — это не {S0}, а все начальные S: берёшь Ξ(q0) и для каждого qi оттуда пишешь Si. В лекции Ξ(q0) = {q0, q1}, поэтому начальные S0, S1 и P0 = {S0, S1}. Записывай множествами из S, а не из q.

Это одно состояние. Перед тем как давать новое имя, проверь все уже выписанные P. Иначе таблица станет бесконечной.

Минимизация

Следующая тема после детерминизации. Метод взят из разбора КР прошлого года (задание 4а, автомат-распознаватель). Своей лекции по ней у тебя пока нет, так что если на паре покажут иначе — верь паре.

Теория

Два состояния эквивалентны, если из них допускаются одни и те же слова: по поведению их не отличить, значит, их можно склеить в одно. Минимальный автомат — тот, где таких пар не осталось.

≡⁰ (0-эквивалентность)
два класса: финальные и нефинальные. Пустым словом их уже различить можно, больше ничем.
≡ᵏ (k-эквивалентность)
состояния в одном классе ≡ᵏ, если они были в одном классе ≡ᵏ⁻¹ и по каждой букве уходят в один и тот же класс ≡ᵏ⁻¹.
Класс [q]
класс эквивалентности; в квадратных скобках пишут представителя.
  1. Если автомат недетерминированный — сначала детерминизируй (часть 8).
  2. Удали недостижимые вершины вместе с исходящими из них дугами.
  3. ≡⁰ = { финальные, остальные }. Обозначь классы C₁, C₂, ….
  4. ≡ᵏ. Для каждого класса ≡ᵏ⁻¹ выпиши все переходы, сгруппировав по буквам: (q, a) → q′ и подпиши, в каком классе q′. Если у всех состояний класса по каждой букве классы совпадают — класс не делится. Если нет — выноси состояния, у которых классы другие, в отдельный класс.
  5. Сравни ≡ᵏ и ≡ᵏ⁻¹. Равны — стоп, автомат минимизирован. Нет — повтори шаг 4 для k + 1.
  6. Строим минимальный автомат. Из каждого класса берём представителя [q]. Начальное — класс с исходным начальным, финальные — классы, где есть финальное. Дуги переносим из исходного графа, заменяя состояния их классами (не забудь петли).

Две ловушки из разбора КР. Сравнивай классы в рамках одной и той же буквы: по a все должны вести в один класс, по b — в один класс (может быть другой, чем по a). И в новый класс записывай сами состояния, которые выносишь, а не то, куда ведут их переходы.

Разбор по шагам

Пример из разбора КР: q₄ недостижима, после неё ≡¹ отделяет q₅, и на ≡² всё останавливается. Цвет вершины — её класс.

Зачем нужны классы и почему сравниваем их, а не имена

Два состояния можно склеить, если любое оставшееся слово из них либо принимается в обоих случаях, либо отвергается в обоих. Внешне разные дуги ещё не означают разное поведение. Алгоритм ищет различия постепенно: сначала без букв, затем по одной, двум и так далее.

  1. В ≡⁰ финальные отделены от нефинальных: их уже различает пустое слово. Назовём классы F и N.
  2. Для каждого состояния запиши подпись: классы назначения по a, по b, …, всегда в одном порядке. Например, (N,F).
  3. Внутри каждого старого класса одинаковые подписи оставь вместе, разные — раздели. Между разными старыми классами ничего не склеиваем.
  4. Закончи весь проход по старому разбиению и только потом используй новые классы для следующего прохода. Если классы не изменились — стоп.

В примере q₄ недостижимо. После удаления: F={q₃,q₆}, N={q₀,q₁,q₂,q₅}. У q₀,q₁,q₂ подпись (N,N), у q₅ — (F,F). Значит, отделяется q₅, а не q₃ и q₆, куда оно переходит. F не делится: у обоих его состояний (F,F).

Теперь три класса: C₁={q₃,q₆}, C₂={q₀,q₁,q₂}, C₃={q₅}. По новому разбиению у q₀,q₁,q₂ подпись (C₂,C₃). Куда именно внутри C₂ ведёт a — в q₁ или q₂ — не важно: эти состояния пока ведут себя одинаково. Все подписи внутри классов совпали: ≡²=≡¹.

C₂ —a→ C₂, C₂ —b→ C₃; C₃ —a,b→ C₁; C₁ —a,b→ C₁.

C₂ начальное, C₁ финальное. Слова ε, a, b отвергаются; ba и bb принимаются. Различающее слово между C₂ и C₃ — a: из C₂ оно не принимается, из C₃ принимается. Это подтверждает, почему склеить их нельзя.

Для неполного ДКА сначала добавь ⊥. Отсутствующая дуга и дуга в нефинальную «мёртвую область» могут вести себя одинаково: никакого принимаемого продолжения нет. Нельзя автоматически объявлять их различием. Тренажёр дополняет все пустые клетки общим поглощающим состоянием, а затем минимизирует полный ДКА. Полученный результат минимален среди полных ДКА над данным алфавитом.

Что если…
…класс делится не на два, а на три

Группируй по набору классов: у всех с одинаковым набором — свой подкласс. Пример — задача М2, где {q₁, q₂, q₄, q₅} делится на {q₁, q₄} и {q₂, q₅}.

…в таблице есть пустые клетки (автомат не полностью определён)

Сначала добавь нефинальное поглощающее состояние ⊥: все пустые клетки ведут в него, а из него по каждой букве переход в себя. Затем минимизируй обычным методом. Дуга в мёртвое состояние и отсутствие дуги могут иметь одинаковое поведение — само по себе это не различие.

…уже ≡¹ = ≡⁰

Значит, разбиение уже устойчиво: дальше дробить классы не нужно. Но исходные вершины внутри одного класса ещё надо склеить. Построй автомат по классам: даже если уточнений не было, число вершин может уменьшиться.

…какого представителя выбрать

Любого из класса. Обычно первого по номеру: {q₃, q₆} → [q₃]. Начальное определяется по тому, в каком классе лежит q₀, а не по имени представителя.

Автомат, который замечает нужную последовательность

Задача: после каждой входной буквы выдавать X тогда и только тогда, когда последние четыре входных символа равны ABAA; во всех остальных случаях выдавать Y. Алфавит входа — {A, B}, выхода — {X, Y}. Здесь нужен преобразователь: он выдаёт последовательность ответов во время чтения.

Теория

Что именно нужно запоминать

Представь, что уже прочитал BBBAB. Чтобы продолжить искать ABAA, полезно помнить последние AB: они уже совпали с началом образца. Если следующая буква A, будет ABA; если ещё одна A — получим полное совпадение и выдадим X.

Состояние хранит самое длинное начало образца, которое сейчас есть на конце прочитанного. Вместо всей истории достаточно четырёх вариантов памяти:

q₁ означает «прочитанное заканчивается на A», а не «за всё время прочитали ровно одну A». Номер состояния показывает, сколько начальных букв образца мы помним.

Как получить каждую стрелку

  1. Возьми то, что помнит состояние. Например, q₃ помнит ABA.
  2. Допиши очередную входную букву. По B получится ABAB.
  3. Определи выход. Если только что завершился полный образец ABAA — X. Иначе Y. Для ABAB выход Y.
  4. Выбери новую память. Проверяй концы от самого длинного к короткому: заканчивается ли результат на ABA? Если нет — на AB? Если нет — на A? В ABAB подходит AB: идём в q₂. Если не подошло ничего, идём в q₀.
  5. Повтори для каждой буквы из каждого состояния. Результат запиши как «следующее состояние / выход».

В этом решении используем автомат Мили: ответ записывается на стрелке. q₃ —A/X→ q₁ читается так: «были в q₃, пришла A, выдаём X и переходим в q₁». Обычная A/Y на стрелке означает «пришла A, выдаём Y».

Что если…

Посмотри, осталось ли на конце полезное начало образца. Из q₁ по A получится AA: последняя A всё ещё подходит, поэтому остаёмся в q₁. Из q₃ по B получится ABAB: конец AB подходит, идём в q₂. Только у ABB подходящего конца нет: q₂ по B идёт в q₀.

…прочитано меньше четырёх символов?

Выдаём Y на каждом шаге: ABAA ещё не могло завершиться. Пустой вход даёт пустой выход — переходов не было.

…совпадение уже было раньше, а теперь пришла другая буква?

Здесь X означает совпадение на текущем шаге. Это не флаг «когда-либо видели ABAA». Например, ABAAB даёт YYYXY: после X на пятой букве снова Y, потому что последние четыре символа — BAAB.

…нужно нарисовать граф на листке?

Нарисуй q₀, q₁, q₂, q₃; входную стрелку направь в q₀. Из каждой строки таблицы перенеси две дуги. Например, q₀ —A/Y→ q₁ и q₀ —B/Y→ q₀. Двойных кружков здесь нет: для этого преобразователя ответы определяются выходными метками, а не финальностью состояний.

Теория

Распознаватель отвечает «да/нет» после слова. Преобразователь Мили выдаёт выходной символ на каждом переходе. Метка a/1 означает: прочитать a, выдать 1, перейти в указанное состояние. Здесь F иногда обозначает выходной алфавит, а не финальные вершины. Чтобы не путаться, назовём его Γ.

Два состояния эквивалентны, если на любом одинаковом входном слове дают одинаковое выходное слово. Начальное разбиение делаем по вектору выходов: λ(q,a), λ(q,b), …; затем уточняем по классам назначения, как при минимизации ДКА.

  1. Составь таблицу «следующее состояние / выход».

  3. ≡⁰: объедини состояния с одинаковыми выходами по каждой входной букве.
  4. ≡ᵏ: внутри старых классов сравни подписи классов назначения по каждой букве. Разные подписи раздели.

Эквивалентность преобразователей

Теория

Запускаем оба автомата на одном входе одновременно. Состояние совместного запуска — пара (q,s). По входу x идём в (δ₁(q,x),δ₂(s,x)) и сравниваем выходы на этом же шаге. Различие в достижимой паре доказывает неэквивалентность; путь до этой дуги даёт конкретное различающее слово.

  1. Начни с пары начальных состояний. Она достижима по ε.
  2. Для каждой буквы отдельно выпиши оба перехода и оба выхода.
  3. Если выходы отличаются — остановись: выписанный вход уже контрпример.
  4. Если одинаковы — добавь пару новых состояний в очередь, если её ещё не было.
  5. Когда обработаны все достижимые пары и различий нет — автоматы эквивалентны. Пар не больше |Q₁|·|Q₂|, поэтому проверка конечна.

Пары «ab» и «ba» — разные выходы. Это не множества букв: первый символ принадлежит первому автомату, второй — второму. На дуге x/ab выходы отличаются. Сам вход x должен быть одинаковым для обоих автоматов.

Шпаргалка

Образец → преобразователь

  1. Состояния — полезные начала образца на конце входа.
  2. Добавь входную букву к тому, что помнишь.
  3. Завершился весь образец → X, иначе Y.

Тип А. R → автомат

  1. q₀ —R→ qf.
  2. Дуга с R₁+R₂ → две параллельные.
  3. Дуга с R₁R₂ → p —R₁→ n —R₂→ q.
  4. Дуга с R* → p —ε→ n, петля R на n, n —ε→ q.
  5. Дуга с R+ → p —R→ n, петля R на n, n —ε→ q.
  6. Петли разбиваются так же. Стоп, когда на всех дугах буквы и ε.

Тип Б. Автомат → R

  1. В начало что-то входит → s —ε→ q₀.
  2. Финальных > 1 или из финала что-то выходит → f и ε-дуги в неё.
  3. Параллельные дуги и петли склеить через +.
  4. Удаляем r: для каждой пары вход × выход дуга R₁R₂*R₃.
  5. Совпали концы → петля. Была дуга → «+».
  6. Остались s и f → метка = ответ.

Где ошибаются

  • Петля для * повешена прямо на старую вершину.
  • Забыта пара при удалении (входов k, выходов m → k·m дуг).
  • Сумма не взята в скобки при склейке: (1+00)0*1.
  • Две петли записаны как a*b* вместо (a+b)*.
  • Забыли, что финальная с исходящими дугами требует новой f.

Упрощения

  • εR = R,  ε* = ε.
  • ∅R = ∅,  R + ∅ = R.
  • (R*)* = R*,  (ε+R)* = R*.
  • RR* = R+.
  • Проверка: 2–3 слова «да» и 2–3 слова «нет».

Детерминизация

  1. Si = Ξ(qi) — всё, куда дойти по ε.
  2. Клетка (Si, a): из Si по a, плюс замыкание, каждое qx → Sx.
  3. P0 = {Si : qi ∈ Ξ(q0)}; клетка (P, a) = объединение строк S.
  4. Новое множество — новое P, пустое — ∅.
  5. Финальные — содержащие финальное.
  6. Проверка: (P0, w) ⊢ … ⊢ (Pk, ε).

Минимизация

  1. НКА → сначала детерминизировать.
  2. Стереть недостижимые.
  3. ≡⁰ = {финальные, остальные}.
  4. ≡ᵏ: в классе по каждой букве — один и тот же класс? Нет → делим.
  5. ≡ᵏ = ≡ᵏ⁻¹ → стоп.
  6. Представители [q], дуги переносим, петли не теряем.

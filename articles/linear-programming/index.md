# Линейное программирование с нуля

Эта статья — компактный маршрут по первым четырём домашним заданиям: от постановки задачи и графического метода до симплекс-метода, искусственного базиса и двойственных задач. Иди по разделам последовательно: каждый следующий опирается на предыдущий.

> [!NOTE] Как читать обозначения
> `x` — переменные решения, `A` — матрица коэффициентов, `b` — правая часть ограничений, `c` — коэффициенты целевой функции. ОДР — область допустимых решений.

## 1. Что решает линейное программирование

Представь мастерскую, которая делает столы и полки. Стол приносит 2 единицы прибыли, полка — 3. На производство расходуются доски, рабочее время и лак. Нужно выбрать объёмы выпуска так, чтобы прибыль была максимальной и ни один ресурс не закончился раньше времени.

Математическая модель выглядит так:

```text
f = 2x₁ + 3x₂ → max
x₁ + 3x₂ ≤ 15       (доски)
x₁ + x₂   ≤ 7        (время)
2x₁ + x₂  ≤ 12       (лак)
x₁, x₂ ≥ 0
```

Здесь целевая функция — то, что оптимизируем, а ограничения описывают допустимые планы. Любая точка, удовлетворяющая всем ограничениям, лежит в ОДР. Среди таких точек ищем ту, где `f` наибольшая или наименьшая.

Главный факт: если линейная задача имеет конечный оптимум, хотя бы один оптимум находится в вершине ОДР. Поэтому нам не нужно проверять все точки — достаточно разобраться с вершинами.

## 2. Графический метод

Он удобен только для двух переменных, зато хорошо показывает геометрию алгоритмов.

1. Замени каждое неравенство на граничную прямую.
2. Проверь сторону прямой пробной точкой, обычно `(0, 0)`.
3. Пересечение всех полуплоскостей и первой четверти даст ОДР.
4. Построй вектор `c = (c₁, c₂)`. Линии уровня `c₁x₁ + c₂x₂ = α` перпендикулярны этому вектору.
5. Двигай линию уровня по `c` для максимизации или против `c` для минимизации. Последняя точка касания — оптимум.

Если область пуста, задача несовместна. Если линия уровня уходит бесконечно в направлении улучшения, задача не ограничена. Если линия уровня совпала со стороной ОДР, оптимумов бесконечно много — весь отрезок между двумя соседними вершинами.

## 3. От геометрии к таблице

Для алгоритма переменные-«запасы» превращают неравенства в равенства. Например:

```text
x₁ + 3x₂ + x₃ = 15
x₁ + x₂   + x₄ = 7
2x₁ + x₂  + x₅ = 12
```

`x₃`, `x₄`, `x₅` — балансовые переменные. В начальном базисе они образуют единичные столбцы, а свободные `x₁` и `x₂` равны нулю. Так появляется вершина `(0, 0)`.

Для базиса `B` считаем оценки:

```text
Δⱼ = (cᴮ, Aⱼ) − cⱼ
```

При принятом здесь соглашении для задачи на максимум оптимальность достигается, когда все `Δⱼ ≥ 0`. Если есть отрицательная оценка, соответствующая переменная может войти в базис и улучшить целевую функцию.

Дальше нужны два выбора:

- **входящий столбец** — отрицательная `Δ`, обычно берём самую отрицательную;
- **выходящая строка** — минимальное положительное отношение `bᵢ / aᵢⱼ` среди строк, где `aᵢⱼ > 0`.

Пересчёт таблицы вокруг ведущего элемента называется жордановым преобразованием. После него повторяем шаги, пока все оценки не станут неотрицательными.

## 4. Метод искусственного базиса

Иногда единичного базиса нет: это происходит у ограничений `=` и `≥`. Для `≥` после вычитания балансовой переменной в строке появляется `−1`, а для `=` переменная вообще не добавляется.

Тогда в проблемную строку добавляют искусственную переменную `wᵢ ≥ 0` с коэффициентом `+1`. Базис появляется, но задача временно меняется. В первой фазе максимизируем:

```text
F = −w₁ − w₂ − … → max
```

`F` не может быть больше нуля. Если максимум равен нулю, все искусственные переменные удалось убрать и исходная задача допустима. Если максимум строго отрицателен, исходная система ограничений несовместна.

После первой фазы искусственные столбцы вычёркиваются, и обычный симплекс продолжается уже по исходной целевой функции. Не оставляй искусственную переменную в финальном базисе: она не является переменной исходной задачи.

## 5. Двойственная задача

Каждой задаче линейного программирования соответствует двойственная. В примере мастерской двойственная задача назначает цену каждому ресурсу. Цены должны быть достаточно высокими, чтобы стоимость ресурсов покрывала прибыль от изготовления каждой продукции.

Для прямой задачи

```text
f = cᵀx → max
Ax ≤ b,  x ≥ 0
```

получаем двойственную

```text
g = bᵀy → min
Aᵀy ≥ c,  y ≥ 0
```

Матрица транспонируется: каждый столбец прямой становится ограничением двойственной. Правые части прямой становятся коэффициентами целевой функции двойственной.

Слабая двойственность говорит: для любых допустимых `x` и `y` выполняется `f(x) ≤ g(y)`. Поэтому допустимое решение двойственной даёт верхнюю оценку для максимума прямой. Если значения совпали, оба решения оптимальны — это признак сильной двойственности.

Чтобы восстановить `y*` по таблице, можно использовать оценки балансовых переменных: для единичного столбца `Aᵢ` со стоимостью `cᵢ` имеем `yᵢ = Δᵢ + cᵢ`. Второй способ — формула `y = cᴮ B⁻¹`.

## 6. Двойственный симплекс

Обычный симплекс поддерживает допустимость плана (`b ≥ 0`) и исправляет оценки. Двойственный делает наоборот: сначала все оценки уже неотрицательны, но некоторые `b` отрицательны.

| Обычный симплекс | Двойственный симплекс |
| --- | --- |
| выбираем отрицательную `Δ` | выбираем самое отрицательное `b` |
| затем строку по `b/a`, `a > 0` | затем столбец по `Δ/|a|`, `a < 0` |
| ведущий элемент положительный | ведущий элемент отрицательный |
| стоп при `Δ ≥ 0` | стоп при `b ≥ 0` |

Если в выбранной строке нет отрицательного коэффициента, исправить правую часть нельзя: задача несовместна. Если в обычном симплексе в выбранном столбце нет положительного элемента, целевая функция не ограничена.

## 7. Шпаргалка перед решением

- Сначала приведи задачу к понятной форме и проверь знаки ограничений.
- Для двух переменных начни с графика: он быстро показывает пустую или неограниченную область.
- Для симплекса проверь `b ≥ 0` и наличие единичного базиса.
- Нет базиса — первая фаза с искусственными переменными.
- В каждой таблице явно подписывай базис, оценки и правую часть.
- После нахождения `x*` проверь допустимость и значение целевой функции.
- Построй двойственную и сравни значения `f*` и `g*`.

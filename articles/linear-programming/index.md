# Линейное программирование с нуля

Полный конспект по ДЗ №1–4: графический метод, симплекс, искусственный базис, двойственность и двойственный симплекс. Исходный тренажёр устроен как маршрут: теория, пошаговый разбор, разборы типовых задач и шпаргалка.

## Основы

### Зачем это всё

Мастерская делает столы и полки. Стол приносит 2 тыс. ₽ прибыли, полка 3 тыс. ₽. Ресурсов ограниченно:

| ресурс      | стол | полка | есть |
|-------------|------|-------|------|
| доски, м²   | 1    | 3     | 15   |
| часы работы | 1    | 1     | 7    |
| лак, банки  | 2    | 1     | 12   |

Сколько чего сделать, чтобы прибыль была максимальной? Пусть x₁ — столы, x₂ — полки:

```text
\begin{array}{l}f=2x_1+3x_2\to\max\[6pt\]\begin{cases}x_1+3x_2\le15&\text{(1) доски}\x_1+x_2\le7&\text{(2) часы}\2x_1+x_2\le12&\text{(3) лак}\x_1\ge0,\ x_2\ge0\end{cases}\end{array}\
```

Это **задача линейного программирования (ЗЛП)**: линейная целевая функция, линейные ограничения и неотрицательность переменных. «Линейная» значит, что переменные стоят только в первой степени: никаких x₁·x₂ или x₁².

Так устроены план производства, перевозки «откуда куда везти», расписания, составление смесей, распределение бюджета. «Поиск решения» в Excel решает именно такие задачи и именно симплексом. **Задача про мастерскую будет сквозной:** на ней объясняется вся теория, и её же решим графически, симплексом и через двойственную.

- **f(x)** — целевая функция, её максимизируем или минимизируем.
- **X (ОДР)** — область допустимых решений: все x, которые удовлетворяют всем ограничениям.
- **x\*, f\*** — оптимальное решение и оптимальное значение f.

Дальше в «Основах» четыре шага: как устроены системы уравнений, что такое ранг, как неравенства превращают в уравнения и почему решения такой системы — это вершины многоугольника. После этого симплекс-метод будет выглядеть логичным, а не набором правил.

### 3. Из неравенств — уравнения

Неравенства решать неудобно: решений у них «область», а не точка. Поэтому каждое неравенство превращают в уравнение, добавляя переменную-остаток:

```text
\x_1+3x_2\le15\quad\Longrightarrow\quad x_1+3x_2+x_3=15,\ \ x_3\ge0\
```

x₃ — сколько досок останется. Если x₃ ≥ 0, досок хватило. Неравенство и уравнение с условием x₃ ≥ 0 говорят одно и то же.

Так получаются две формы записи задачи. В обеих ищется **max** и все x ≥ 0:

- **Стандартная**: все ограничения со знаком ≤.
- **Каноническая**: все ограничения — равенства. С ней работает симплекс. Удобно, когда ещё и все b ≥ 0.

Приведение идёт в два шага. Шаг 1 одинаковый для обеих форм. Потом решаешь, какую форму строишь, и берёшь только её таблицу. Если в задании просят обе формы (как в задаче 0), делаешь шаг 1 один раз, а потом отдельно 2а и отдельно 2б.

> [!NOTE]
> **Обозначения в таблицах.** Любое ограничение записывают в виде \a\cdot x\ \le\ b\ (или ≥, или =):
>
> - **a·x** — левая часть, всё, где есть переменные: \a_1x_1+a_2x_2+\ldots\;
- **b** — правая часть, число без переменных (её ещё называют свободным членом).
>
> Пример из задачи 0: в \2x_1+x_2-x_3\le4\ левая часть \a\cdot x=2x_1+x_2-x_3\, а \b=4\. В \x_1-x_2\ge-3\ было бы \b=-3\, то есть b \< 0.

#### Шаг 1. Подготовка — делается перед переводом в любую из форм

| в задаче есть | что делаем |
|----|----|
| f → min | Пишем \-f\to\max\: меняем знаки у всех коэффициентов f. Ограничения не трогаем. В конце \f\_{\min}=-(\text{найденный max})\. |
| xj любого знака | Замена \x_j=x_j'-x_j''\, обе ≥ 0. Подставляем и в f, и во все ограничения. |
| xj ≤ 0 | Замена \x_j=-x_j'\, \x_j'\ge0\. |

#### Шаг 2а. Перевод в каноническую форму

Нужна для симплекс-метода. Цель: все ограничения «=», все x ≥ 0, удобно b ≥ 0.

| ограничение | что делаем |
|----|----|
| b \< 0 | Сначала умножаем строку на −1, знак неравенства переворачивается. Потом по строкам ниже. |
| a·x ≤ b | Прибавляем новую: \a\cdot x+x\_{n+i}=b\. |
| a·x ≥ b | Вычитаем новую: \a\cdot x-x\_{n+i}=b\. |
| a·x = b | Оставляем как есть. |

Каждому неравенству — своя новая переменная (x₄, x₅, …), все ≥ 0. В f они входят с коэффициентом 0.

#### Шаг 2б. Перевод в стандартную форму

Нужна, например, для построения двойственной задачи. Цель: все ограничения «≤», все x ≥ 0. Новых переменных не добавляем.

| ограничение | что делаем |
|----|----|
| a·x ≤ b | Оставляем как есть. |
| a·x ≥ b | Умножаем на −1: \-a\cdot x\le-b\. |
| a·x = b | Заменяем парой: \a\cdot x\le b\ и \-a\cdot x\le-b\. |
| b \< 0 | Ничего не делаем: в стандартной форме b может быть отрицательным. |

> [!NOTE]
> **«Разными способами»** — так формулируют задачу 1 в ДЗ №1. Способов два:
>
> - **Способ 1** — по таблицам выше: балансовые переменные, пары неравенств вместо «=», замена \x_j=x_j'-x_j''\ для свободной переменной.
- **Способ 2 — исключение переменных.** Выражаешь переменную из уравнения и подставляешь её во всё остальное, включая f. Уравнение при этом исчезает. Если выраженная переменная была свободной, условий на неё не остаётся. Если она должна быть ≥ 0, условие «выражение ≥ 0» становится новым неравенством. Так получается стандартная форма без пар неравенств и без штрихов.
>
> Оба способа разобраны в задачах 0а и 0б внизу главы.

Мастерская в канонической форме:

```text
\begin{array}{l}f=2x_1+3x_2+0x_3+0x_4+0x_5\to\max\[6pt\]\begin{cases}x_1+3x_2+x_3=15\x_1+x_2+x_4=7\2x_1+x_2+x_5=12\x_j\ge0,\ j=\overline{1,5}\end{cases}\end{array}\
```

> [!NOTE]
> **Что значит \j=\overline{1,5}\.** Читается «j от 1 до 5». Черта сверху означает «все целые числа подряд от … до …». Запись \x_j\ge0,\ j=\overline{1,5}\ — сокращение для пяти условий: \x_1\ge0,\ x_2\ge0,\ x_3\ge0,\ x_4\ge0,\ x_5\ge0\. Пятёрка — это число переменных после перехода к канонической форме: две исходные (x₁, x₂) и три балансовые (x₃, x₄, x₅). Так же пишут \i=\overline{1,m}\ для номеров ограничений.

### Термины, которые теперь можно назвать

Все слова ниже — это то, что ты только что видел на картинке.

- **Свободные (небазисные) переменные** — те n − r переменных, которые приравниваем к 0. На графике это две прямые, на пересечении которых стоит точка.
- **Базисные переменные** — остальные r штук (r = ранг), их значения вычисляются из системы.
- **Базис** — набор столбцов Aj при базисных переменных. Столбцы должны быть линейно независимы: если две прямые параллельны, точки нет, и такой набор не базис.
- **Базисное решение** — точка пересечения прямых «свободные = 0» вместе со значениями всех переменных.
- **Опорное решение (опорный план)** — базисное решение, где все переменные ≥ 0. Это вершина ОДР.
- **Вырожденное опорное решение** — опорное, у которого нулей больше, чем n − r: через вершину проходит больше прямых, чем нужно. Одну точку тогда дают несколько базисов (включи галочку в интерактиве и обнули пары из x₃, x₄, x₅). Так же устроена домашка 1.б: у x̂ = (4, 0, 0, 0) базис можно добрать по-разному.
- **Единичные столбцы (орты)** — столбцы вида (1; 0; 0), (0; 1; 0), (0; 0; 1). Если базис из них, значения базисных переменных просто равны b — ничего решать не надо. Поэтому симплекс стартует с базиса из балансовых x₃, x₄, x₅: это вершина O.

### 5. Типовые задачи с опорными решениями

В ДЗ №1 есть четыре вида задач на этот материал. Это то же, что ты видел на графике мастерской, только без картинки.

#### Проверить, что x̂ — опорное решение, и найти все его базисы

1.  Подставить x̂ в систему: все уравнения выполняются и x̂ ≥ 0 — значит, это допустимое решение.
2.  Выписать столбцы Aj при **ненулевых** компонентах x̂j. Если они линейно независимы, x̂ опорное. Один ненулевой столбец независим всегда, для двух столбцов из двух чисел проверяют определитель: \\begin{vmatrix}a&b\c&d\end{vmatrix}=ad-bc\ne0\.
3.  Базис — это r независимых столбцов (r — ранг), в который обязательно входят столбцы ненулевых компонент. Если ненулевых компонент меньше r, решение **вырожденное**: недостающие столбцы добираем из остальных всеми способами и каждый набор проверяем на независимость.

> [!NOTE]
> Пример на мастерской с лаком 10 (вырожденный вариант в интерактиве выше). Вершина C = (3; 4; 0; 0; 0): ненулевые x₁ и x₂, ранг 3, значит нужен ещё один столбец из A³, A⁴, A⁵. Все три набора дают ненулевой определитель, поэтому у C три базиса: {A¹, A², A³}, {A¹, A², A⁴}, {A¹, A², A⁵}. Включи галочку в интерактиве и обнули любые две из x₃, x₄, x₅ — каждый раз получится C.

#### Найти все опорные решения системы

1.  Переменных n, независимых уравнений r. Перебираем все наборы из r базисных переменных, их \C_n^r\ (для n = 4, r = 2 это 6 наборов).
2.  Для каждого набора: остальные переменные = 0, решаем систему r × r. Если столбцы зависимы (определитель 0), набор не базис.
3.  Все значения ≥ 0 — опорное решение. Есть отрицательное — нет.

Это ровно то, что делает интерактив «обнули любые две» выше.

#### Найти вершины множества X и изобразить его на плоскости x₁Ox₂

Работает, когда свободных переменных две: n − r = 2.

1.  Методом Гаусса выразить базисные переменные через x₁ и x₂.
2.  Условия «базисная ≥ 0» превращаются в неравенства с x₁, x₂. Вместе с x₁, x₂ ≥ 0 это многоугольник на плоскости, рисуешь его как в графическом методе.
3.  Вершины многоугольника подставляешь в выражения из пункта 1 и получаешь вершины X — полные векторы из n чисел.

Это шаг «Выражаем через две свободные» из разбора выше, только наоборот: там свободными были x₁, x₂ с самого начала.

#### Жорданова таблица ↔ система уравнений

Жорданова таблица — это симплекс-таблица без строки Δ. Каждая строка — уравнение: базисная переменная плюс сумма «элемент × переменная столбца» равна b. Например, начальная таблица мастерской, строка «x₃ \| 1 3 \| 15», означает \x_3+x_1+3x_2=15\.

- **Базисное решение:** переменные столбцов = 0, переменные строк = своим b.
- **Базис:** столбцы Aj переменных строк, в порядке строк.
- **Жорданова форма системы:** система из этих уравнений. В ней каждая базисная переменная стоит ровно в одном уравнении с коэффициентом 1.

### Главная идея и две неразрешимости

> [!NOTE]
> **Теорема, на которой держатся все методы:** если оптимум есть, он достигается в вершине ОДР, то есть в опорном решении. Вершин конечное число. Графический метод находит нужную вершину глазами, симплекс — переходя от базиса к соседнему базису с бóльшим f.

Но оптимума может и не быть. Таких случаев два, и в методичке они называются так:

|  | что это | на графике | в симплекс-таблице |
|----|----|----|----|
| **Нр1** | X = ∅: ограничения противоречат друг другу | у полуплоскостей нет общей области | в искусственном базисе max F \< 0 |
| **Нр2** | X есть, но f → +∞ | область уходит в бесконечность по направлению роста f | есть Δj \< 0, а все элементы столбца ≤ 0 |

Как это выглядит в таблице, станет понятно в частях 3 и 4.

## Графический метод

Работает, когда переменных две: тогда каждое ограничение — полуплоскость, а X — многоугольник на плоскости x₁Ox₂. По горизонтали обычно x₁, по вертикали x₂.

1.  Каждое неравенство превращаем в уравнение прямой и строим её по двум точкам. Удобнее всего пересечения с осями: x₁ = 0 → x₂ = …, x₂ = 0 → x₁ = ….
2.  Выбираем сторону: подставляем пробную точку, обычно (0, 0). Неравенство верное → нужная полуплоскость содержит эту точку. Если прямая проходит через (0, 0), бери другую точку, например (1, 0).
3.  Пересечение всех полуплоскостей и первой четверти (x ≥ 0) — это ОДР X.
4.  Строим вектор C = (c₁, c₂) из коэффициентов f. Это направление, в котором f растёт быстрее всего. Линии уровня c₁x₁ + c₂x₂ = α перпендикулярны C.
5.  Двигаем линию уровня по направлению C (для max) или против C (для min). Последняя точка ОДР, которой она коснётся, — оптимум.
6.  Находим координаты этой точки из системы двух прямых, на пересечении которых она лежит. Считаем f\*.

Сквозная задача: f = 2x₁ + 3x₂ → max (и min); x₁ + 3x₂ ≤ 15; x₁ + x₂ ≤ 7; 2x₁ + x₂ ≤ 12; x ≥ 0. Листай кнопками, стрелками клавиатуры или ползунком.

Это ещё не значит, что решения нет. Проверь, куда смотрит C.

…линия уровня параллельна неограниченному ребру

## Симплекс-метод

Обычный (прямой) симплекс запускается сразу, если у задачи в канонической форме все **b ≥ 0** и есть **полный набор единичных столбцов**. Это всегда так для задачи вида «max, все ограничения ≤, b ≥ 0»: базис дают сами балансовые переменные. Если базиса нет — следующая часть, искусственный базис.

### Идея

Из «Основ»: оптимум сидит в вершине, а вершина — это базисное решение, где две переменные обнулены. Симплекс стартует в вершине O (базис x₃, x₄, x₅) и на каждом шаге меняет **одну** переменную в базисе: одна свободная становится базисной, одна базисная — свободной. На графике это переход по стороне многоугольника в соседнюю вершину. Переход делают только если f растёт.

Чтобы так ходить, нужно отвечать на три вопроса: какую переменную ввести, какую вывести и как пересчитать систему. Ответы дают симплекс-таблица, оценки Δ и жордановы преобразования.

### Симплекс-таблица: как читать

Это мастерская в начальной таблице. Формат как в методичке и в твоих конспектах:

- **Строки** — базисные переменные, **столбцы** — свободные (небазисные). Строка «x₃ \| 1 3 \| 15» — это уравнение x₃ + 1·x₁ + 3·x₂ = 15.
- **b** — текущие значения базисных переменных. Свободные равны 0, их в таблице как значения не пишут.
- **Сверху пунктиром** — коэффициенты cj целевой функции у свободных переменных.
- **Слева пунктиром** — cB, коэффициенты базисных переменных. У балансовых это 0.
- **Нижняя строка Δ** (в методичке f или F) — оценки. В правом нижнем углу — текущее значение f.

### Откуда берутся оценки Δ

Строка Δ — это целевая функция, выраженная через свободные переменные. Проверим на двух таблицах мастерской.

1.  **Начальная таблица.** Свободные x₁, x₂, и f уже записана через них: \f=2x_1+3x_2\. Перенесём всё влево: \f-2x_1-3x_2=0\. Коэффициенты −2 и −3 — это Δ₁ и Δ₂, а 0 — значение в углу.
2.  **Что они значат.** Сейчас x₁ = x₂ = 0. Если поднять x₂ на 1, f вырастет на 3. В строке Δ это записано как −3: **отрицательная оценка = эта переменная увеличит f**.
3.  **После шага симплекса** x₂ стала базисной: из первого уравнения \x_2=5-\tfrac13x_1-\tfrac13x_3\. Подставим в f:
    ```text
\f=2x_1+3\left(5-\tfrac13x_1-\tfrac13x_3\right)=15+x_1-x_3\ \Longrightarrow\ f-x_1+x_3=15\
```

    Получились Δ₁ = −1, Δ₃ = 1 и угол 15 — ровно вторая таблица разбора ниже.
4.  **Формула-сокращение.** Каждый раз подставлять долго, поэтому Δ считают сразу из таблицы:
    ```text
\Delta_j=(c_B,A^j)-c_j=c\_{B_1}a\_{1j}+c\_{B_2}a\_{2j}+\ldots-c_j,\qquad f=(c_B,b)\
```

    У столбца b в углу ничего не вычитаем.

Отсюда три правила:

- **Δj \< 0** — увеличение xj повышает f, план можно улучшить. Этот столбец — кандидат в ведущие.
- **Все Δj ≥ 0** — какую свободную ни увеличь, f не растёт. План оптимален.
- **Δj = 0** у свободной переменной в оптимальной таблице — её можно увеличить без потери f, значит есть и другие оптимальные решения.

### Жордановы преобразования

Это пересчёт таблицы при смене базиса. Ведущий столбец — переменная, которая входит в базис, ведущая строка — которая выходит. Ведущий элемент p стоит на их пересечении.

1.  Ведущий элемент: **p → 1/p**.
2.  Ведущая строка: каждый элемент **делим на p**.
3.  Ведущий столбец: каждый элемент **делим на p и меняем знак**.
4.  Все остальные — **правило прямоугольника**: (a·p − b·c) / p. a — сам элемент, b — элемент ведущей строки в его столбце, c — элемент ведущего столбца в его строке. В тетради это «перемножить перпендикуляры».
5.  Меняем местами подписи: переменная строки уходит наверх, переменная столбца — влево.

pbca

```text
\a\_{\text{нов}}=\frac{a\cdot p-b\cdot c}{p}\
```

p и a стоят по одной диагонали прямоугольника, b и c — по другой.

> [!NOTE]
> **Почему это работает.** Это тот же метод Гаусса из части 1 «Основ». Строка x₃ значит x₃ + x₁ + 3x₂ = 15. Выразим из неё x₂ (ведущий элемент 3): x₂ + ⅓x₁ + ⅓x₃ = 5. Получились числа ⅓, ⅓ и 5 — правила 1 и 2. Подставим x₂ = 5 − ⅓x₁ − ⅓x₃ в строку x₄ + x₁ + x₂ = 7: x₄ + ⅔x₁ − ⅓x₃ = 2. Числа ⅔, −⅓ и 2 — правила 3 и 4. Строка Δ пересчитывается так же — это и есть подстановка в f из пункта 3 выше.

### Алгоритм

1.  Привести к канонической форме, найти базис (единичные столбцы).
2.  Начальная таблица: c сверху, cB слева, посчитать строку Δ: Δj = (cB, Aj) − cj, угол = (cB, b).
3.  Все Δ ≥ 0 → оптимум, читаем ответ. Стоп.
4.  Есть Δj \< 0, но в этом столбце все элементы ≤ 0 → Нр2. Стоп.
5.  **Ведущий столбец**: любой с Δj \< 0. Обычно берут самую отрицательную оценку.
6.  **Ведущая строка**: делим b на **положительные** элементы ведущего столбца, берём минимальное отношение. Нули и отрицательные пропускаем.
7.  Жордановы преобразования → новая таблица → снова пункт 3.

> [!NOTE]
> **Почему отношение минимальное.** Ведущая переменная растёт с нуля, а базисные при этом уменьшаются. bi/ais — насколько её можно увеличить, прежде чем базисная в строке i станет 0. Возьмёшь не минимум — какая-то переменная уйдёт в минус, решение станет недопустимым.

## Метод искусственного базиса

Нужен, когда в канонической форме нет полного набора единичных столбцов. Так бывает из-за ограничений «=» (никакой переменной не добавляли) и «≥» (вычли xn+i, у неё коэффициент −1, а не +1).

**Идея.** В каждую строку, где нет «своего» единичного столбца, добавляем искусственную переменную wi ≥ 0 с коэффициентом +1. Базис появился, но это уже другая система. Исходные ограничения выполняются, только если все w = 0. Поэтому сначала решаем **вспомогательную задачу**:

```text
\F(x,w)=-w_1-w_2-\ldots\to\max\
```

F ≤ 0 всегда, а F = 0 ровно тогда, когда все w = 0. Значит, если max F = 0, мы нашли допустимую точку исходной задачи, а если max F \< 0 — её нет.

1.  Каноническая форма; в строки без единичного столбца добавить wi. Строки, где уже есть +xn+i (бывшие ≤), не трогать.
2.  Фаза 1: таблица для F. Сверху все c = 0 (x не входят в F), слева cB = −1 у w и 0 у остальных. Строка F по той же формуле Δ.
3.  Обычный симплекс по строке F. Столбец w, вышедшей из базиса, можно сразу вычеркнуть — он больше не понадобится.
4.  max F \< 0 → исходная задача Нр1. Стоп.
5.  max F = 0, все w вне базиса → вычёркиваем F-строку, ставим исходные c и считаем f-строку: Δj = (cB, zj) − cj. Это начальная таблица исходной задачи.
6.  Фаза 2: обычный симплекс по f.

## Двойственные задачи

У каждой ЗЛП есть пара — двойственная задача. Смысл на мастерской: кто-то хочет выкупить все ресурсы. Какие цены y₁, y₂, y₃ (за м² досок, час, банку лака) ему назначить? Продать нужно не дешевле, чем заработаешь сам: ресурсы одного стола должны стоить хотя бы 2, одной полки — хотя бы 3. Покупатель хочет заплатить минимум:

```text
\begin{array}{l}\text{прямая:}\quad f=2x_1+3x_2\to\max\[6pt\]\begin{cases}x_1+3x_2\le15\x_1+x_2\le7\2x_1+x_2\le12\x\ge0\end{cases}\end{array}\
```

```text
\begin{array}{l}\text{двойственная:}\quad g=15y_1+7y_2+12y_3\to\min\[6pt\]\begin{cases}y_1+y_2+2y_3\ge2\3y_1+y_2+y_3\ge3\y\ge0\end{cases}\end{array}\
```

Правила для прямой задачи на max. Двойственная к двойственной — снова исходная (взаимная двойственность).

| прямая (max) | двойственная (min) |
|----|----|
| i-е ограничение | своя переменная yi |
| коэффициенты целевой cj | правые части ограничений |
| правые части bi | коэффициенты целевой g |
| матрица A (строки) | Aᵀ: j-й столбец A становится j-м ограничением |
| ограничение ≤ | yi ≥ 0 |
| ограничение = | yi любого знака |
| ограничение ≥ | yi ≤ 0 |
| xj ≥ 0 | j-е ограничение со знаком ≥ |
| xj любого знака | j-е ограничение со знаком = |

#### Теоремы, которые используют в задачах

1.  **Слабая:** для любых допустимых x и y выполняется f(x) ≤ g(y).
2.  **Основная:** если одна из задач разрешима, то разрешима и другая, и f\* = g\*.
3.  Если в прямой f → +∞ (Нр2), у двойственной нет допустимых решений. Если прямая Нр1, двойственная Нр1 или Нр2.
4.  **Дополняющая нежёсткость** (условия (6) задачника): если xj\* \> 0, то j-е ограничение двойственной выполняется как равенство; если i-е ограничение прямой строгое (\< bi), то yi\* = 0.

#### Как достать y\* из оптимальной таблицы

- **Способ 1, по оценкам** (формулы (4)): Δj = (y\*, Aj) − cj. Для единичного столбца Aj = ei получаем **yi = Δj + cj**. Для балансовой cj = 0, поэтому yi = Δj. Базисная переменная имеет Δ = 0.
- **Способ 2, матрица:** y\* = cB·B⁻¹. B — столбцы базисных переменных оптимального плана в исходной матрице, в порядке строк таблицы. B⁻¹ читается из таблицы: её столбцы — это столбцы переменных, которые в исходной задаче были единичными.
- **Способ 3, система:** если единичных столбцов мало (после искусственного базиса), берёшь базисные столбцы оптимального плана, для них Δj = 0, то есть (y, Aj) = cj. Решаешь систему (задачник, примеры 5 и 6).

> [!NOTE]
> **Если в прямой было лишнее ограничение** (в искусственном базисе его строка обнулилась и её вычеркнули), y\* получается не единственным. Для вычеркнутого ограничения обычно берут yi = 0 и ищут остальные y из оставшихся строк. Так сделано в практике Д5.

#### При каких λ план оптимален

В ДЗ №3–4 (задача 4) параметр λ стоит в целевой функции. Решают это той же схемой проверки на оптимальность, что в разборе 3. Разница одна: y получаются выражениями с λ, и условие «y ∈ Q» превращается в неравенства на λ.

1.  Проверить, что x̄ допустим (λ на это не влияет).
2.  Построить J и I, записать систему (7) — в правой части появится λ.
3.  Выразить y через λ.
4.  Подставить в оставшиеся условия двойственной (знаки y и ограничения при x̄j = 0). Получаются неравенства на λ — их пересечение и есть ответ.

Схема из задачника с множествами J и I. Здесь вообще не нужна симплекс-таблица.

…прямая задача на min

Проще всего перевести в max (f → −f) и строить по таблице выше. Или зеркально: двойственная к min — задача на max, и правила знаков отражаются (ограничение ≥ в min-задаче даёт y ≥ 0).

…в прямой есть ограничения ≥

Два честных пути. Либо по таблице: yi ≤ 0 (задачник, пример 4: y₃ ≤ 0). Либо заранее умножить на −1 и получить ≤ с yi ≥ 0. Ответы отличаются только знаком этой yi, g\* одинаковое.

…прямая в канонической форме (все =)

Все y свободного знака (задачник, пример 1б). Ограничения двойственной всё равно ≥, если x ≥ 0.

…в прямой Нр1 или Нр2

Прямая Нр2 → у двойственной X = ∅ (задачник, пример 4). Решать двойственную не нужно, достаточно сослаться на теорему.

…единичные столбцы — не балансовые, а обычные x с c ≠ 0

Тогда yi = Δj + cj, не забудь прибавить c. Задачник, пример 3: единичные A³, A⁴, A⁵ с c = 1, −1, 2 и Δ = 1/2, 5/2, 0 → y\* = (3/2, 3/2, 2).

…единичный столбец пришёл от «−xn+i» (было ≥)

Столбец равен −ei, значит Δ = −yi и yi = −Δj.

…надо проверить на оптимальность заданную точку x̄

Схема из задачника (пример 7):

1.  J = {j : x̄j \> 0}, I = {i : ограничение i строгое при x̄}.
2.  Система: (Aj, y) = cj для j ∈ J; yi = 0 для i ∈ I.
3.  Противоречива → x̄ не оптимален. Есть решение — проверить, что оно допустимо для двойственной (все её ограничения и знаки). Допустимо → x̄ оптимален, нет → не оптимален.

Разобрано в практике Д3.

…план x̄ вообще не удовлетворяет ограничениям

Схему начинают с проверки допустимости: подставь x̄ во все ограничения прямой и в условия на знаки. Если хоть одно нарушено, план недопустимый и оптимальным быть не может — дальше проверять не нужно. В ДЗ №3–4, задача 9б так отсеивается x¹ (практика Д10).

…в прямой есть свободные переменные или задача на min

Задачу на min сначала переведи в max (−f), ≥ — в ≤. Для свободной xj ограничение двойственной — **всегда равенство**, независимо от того, x̄j \> 0 или нет. Поэтому все свободные переменные сразу дают уравнения в системе (7).

…система (7) имеет бесконечно много решений

Уравнений меньше, чем y. Тогда выражаешь y через параметр и ищешь, есть ли среди них хоть одно в Q: подставляешь в ограничения двойственной и смотришь, совместны ли получившиеся неравенства на параметр. Нашлось хоть одно — x̄ оптимален (практика Д9).

…в задаче параметр λ

Схема та же, только y зависят от λ. Условия «y ∈ Q» дают неравенства на λ — их пересечение и есть ответ. Если x̄ при каком-то λ стал недопустимым, такие λ тоже исключаются (практика Д11, Д12).

…g(y\*) не совпало с f\*

## Двойственный симплекс-метод

Обычный симплекс держит план **допустимым** (все b ≥ 0) и шаг за шагом добивается, чтобы все Δ стали ≥ 0. Двойственный делает наоборот: все Δ ≥ 0 с самого начала, а он шаг за шагом убирает отрицательные b.

|  | обычный симплекс | двойственный симплекс |
|----|----|----|
| всё время верно | b ≥ 0 | Δ ≥ 0 |
| добиваемся | Δ ≥ 0 | b ≥ 0 |
| сначала выбираем | столбец: Δj \< 0 | строку: самое отрицательное b |
| потом выбираем | строку: min b/a по a \> 0 | столбец: min Δ/\|a\| по a \< 0 |
| ведущий элемент | положительный | отрицательный |
| стоп «нет решения» | в столбце нет a \> 0 — Нр2 | в строке нет a \< 0 — Нр1 |

**Когда применять.** Есть единичный базис, все Δ ≥ 0, но некоторые b \< 0. Чаще всего это задача на **min** с ограничениями **≥** и неотрицательными коэффициентами f. Например, «смесь» или «рацион»: купить подешевле, но не меньше нормы. Обычным симплексом её решают через искусственный базис, а здесь w не нужны.

1.  **Подготовка.** min → max(−f). Каждое ≥ умножить на −1 (станет ≤ с b \< 0) и прибавить балансовую. Если переменная входит в одно уравнение с коэффициентом −1, умножение этой строки на −1 делает её столбец единичным.
2.  Начальная таблица, строка Δ. Проверить, что все Δ ≥ 0. Если нет — этот метод не подходит, нужен обычный симплекс с искусственным базисом.
3.  Все b ≥ 0 → оптимум, читаем ответ. Для задачи на min: \f\_{\min}=-(\text{угол})\.
4.  **Ведущая строка:** самое отрицательное b.
5.  В этой строке нет отрицательных элементов → допустимых решений нет (Нр1). Стоп.
6.  **Ведущий столбец:** среди отрицательных элементов строки берём минимум \\Delta_j/\|a\_{rj}\|\.
7.  Жордановы преобразования — те же самые. Возвращаемся к пункту 3.

> [!NOTE]
> **Почему min Δ/\|a\|.** После шага новая оценка равна \\Delta_j-\frac{\Delta_s}{a\_{rs}}a\_{rj}\. Если взять не минимум, какая-то Δ уйдёт в минус, и метод потеряет то, что держал. Это зеркало правила min b/a.

## Шпаргалка

#### Графический

1.  Прямые по 2 точкам, сторона — пробной точкой O.
2.  ОДР = пересечение + x ≥ 0.
3.  C = (c₁, c₂), линия уровня ⊥ C.
4.  max — по C, min — против C.
5.  Точка = система двух прямых, f\* = f(x\*).

Пусто → Нр1. Уходит по C → Нр2. ∥ стороне → отрезок через β.

#### Симплекс

1.  Каноника, b ≥ 0, единичный базис.
2.  Δⱼ = (c_B, Aʲ) − cⱼ, угол = (c_B, b).
3.  Все Δ ≥ 0 → ответ.
4.  Столбец: Δ \< 0. Строка: min b/a, a \> 0.
5.  p → 1/p; строка / p; столбец / (−p); остальные (a·p − b·c)/p.

Δ \< 0 и столбец ≤ 0 → Нр2. Δ = 0 у небазисной → альтернативный оптимум.

#### Искусственный базис

1.  w в строки без единичного столбца.
2.  F = −Σw → max; c_B(w) = −1, c сверху = 0.
3.  Симплекс по F, вышедшую w вычёркиваем.
4.  max F \< 0 → Нр1.
5.  F = 0 → убрать F, посчитать f-строку, симплекс дальше.

w в базисе с b = 0 → вывести через любой ненулевой элемент строки.

#### Двойственность

1.  max ↔ min, b ↔ c, A ↔ Aᵀ.
2.  ≤ → y ≥ 0; = → y любой; ≥ → y ≤ 0.
3.  x ≥ 0 → «≥»; x любой → «=».
4.  yᵢ = Δⱼ + cⱼ по единичным столбцам, или y = c_B·B⁻¹.
5.  Проверка: g(y\*) = f(x\*).

xⱼ \> 0 → ограничение j двойственной — равенство. Строгое ограничение i → yᵢ = 0.

#### Двойственный симплекс

1.  min → max(−f); ≥ × (−1), + балансовые.
2.  Нужно: все Δ ≥ 0 (b могут быть \< 0).
3.  Все b ≥ 0 → ответ, fmin = −угол.
4.  Строка: самое отрицательное b.
5.  Столбец: a \< 0, min Δ/\|a\|. Нет a \< 0 → Нр1.

Ведущий элемент всегда отрицательный. Жордановы преобразования те же.

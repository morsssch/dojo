# Скиллы для авторов Dojo

В репозитории лежат два переносимых скилла:

- [`dojo-course`](dojo-course/SKILL.md) — создать или дополнить курс;
- [`dojo-article`](dojo-article/SKILL.md) — создать статью и интерактивные вставки.

Оба скилла **пишут материалы в рабочую копию репозитория**, а не создают отдельные HTML-файлы. При запуске они проверяют GitHub-логин: `morsssch` работает в оригинальном `morsssch/dojo`, другой автор — в собственном форке. Создание форка и публикация требуют подтверждения пользователя; скиллы не должны пушить в чужой репозиторий автоматически.

## Установка

### Claude Code (локальный CLI и проект в Claude Desktop)

Скачай каталог нужного скилла целиком и положи его в `~/.claude/skills/`:

```text
~/.claude/skills/dojo-course/SKILL.md
~/.claude/skills/dojo-article/SKILL.md
```

Можно установить только один из них. После установки начни новую сессию и попроси: «Создай курс в Dojo…» или «Добавь статью в Dojo…».

### Claude Desktop (импорт скилла)

Скачай [`dojo-course.skill`](dojo-course.skill) и [`dojo-article.skill`](dojo-article.skill). Каждый файл — ZIP-архив с `SKILL.md` в корне. Если в твоей версии Claude Desktop доступен импорт пользовательских скиллов, загрузи эти файлы через его настройки скиллов. Если импорта нет, используй установку через `~/.claude/skills/` для локального Claude Code, описанную выше.

### Для автора с форком

1. Установи и авторизуй `gh` (`gh auth login`).
2. Скилл предложит создать публичный форк `morsssch/dojo` или использовать существующий.
3. Изменения создаются в форке и не попадают в оригинал без отдельного PR.

Репозиторий публичный: не включай личные данные, токены и закрытые материалы в контент, даже если у курса стоит `owners`. Инструкции скиллов намеренно отсылают к актуальному `docs/AUTHORING.md` из выбранной копии репозитория, а не содержат замороженную схему платформы.

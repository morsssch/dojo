# Один ответ

Вопросы стоят сразу после кусочка теории — как на Stepik. Ошибся — увидишь, почему именно этот вариант неверный. После двух неудачных попыток откроется объяснение.

```quiz
id: single
question: Что выведет программа?
code: |
  s := []int{1, 2, 3}
  t := s[:2]
  t = append(t, 99)
  fmt.Println(s)
options:
  - text: "`[1 2 3]`"
    why: Казалось бы, `t` — отдельный срез. Но у него общий массив с `s`, а места хватает.
  - text: "`[1 2 99]`"
    correct: true
  - text: "`[1 2 3 99]`"
    why: "`append` дописывает в `t`, а не в `s`; длина `s` не меняется."
explain: |
  `t` смотрит на тот же массив, что и `s`. Ёмкость `t` — 3, поэтому `append` не выделяет новую память,
  а пишет 99 прямо в третью ячейку общего массива. Отсюда и сюрприз.
hints:
  - Посмотри на `cap(t)`. Нужно ли `append` выделять новый массив?
```

# Несколько ответов

```quiz
id: multi
kind: multiple
question: Какие из этих команд меняют историю коммитов в репозитории?
options:
  - text: "`git commit`"
    correct: true
  - text: "`git status`"
    why: Только показывает состояние.
  - text: "`git reset --hard HEAD~1`"
    correct: true
  - text: "`git diff`"
    why: Только показывает разницу.
explain: "`commit` добавляет коммит, `reset` двигает ветку назад. `status` и `diff` ничего не меняют."
```

# Сопоставь

`kind: match` — пары «левое → правое». Правая колонка перемешивается, ученик подбирает пару к каждой строке.

```quiz
id: match
kind: match
question: Сопоставь выражение Go и результат.
pairs:
  - { left: "`7 / 2`", right: "3" }
  - { left: "`7 % 2`", right: "1" }
  - { left: "`7.0 / 2`", right: "3.5" }
  - { left: "`len(\"привет\")`", right: "12" }
explain: Целочисленное деление отбрасывает дробную часть, а `len` у строки считает байты, не символы.
```

# Расставь по порядку

Правильный порядок — это порядок вариантов в файле; ученику они показываются перемешанными. Строки можно перетаскивать мышью или пальцем, двигать кнопками или стрелками ↑↓ с клавиатуры.

```quiz
id: order
kind: order
question: Расставь строки, чтобы получилась рабочая программа на Go.
options:
  - "`package main`"
  - "`import \"fmt\"`"
  - "`func main() {`"
  - "`fmt.Println(\"hi\")`"
  - "`}`"
```

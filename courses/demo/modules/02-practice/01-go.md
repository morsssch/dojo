# Ввод и вывод

Самый простой вид задачи: программа читает ввод и печатает ответ, а платформа сравнивает вывод с ожидаемым. Тесты с `hidden: true` ученик не видит — только «прошёл/не прошёл».

Жми **Проверить** (или Ctrl+Enter). **Запустить** просто выполняет код на первом тесте и показывает вывод.

```task
id: sum
lang: go
title: Сумма двух чисел
prompt: |
  На вход подаются два целых числа через пробел. Выведи их сумму.
starter: |
  package main

  import "fmt"

  func main() {
  	var a, b int
  	fmt.Scan(&a, &b)
  	// твой код
  }
solution: |
  package main

  import "fmt"

  func main() {
  	var a, b int
  	fmt.Scan(&a, &b)
  	fmt.Println(a + b)
  }
tests:
  - { stdin: "2 3", stdout: "5" }
  - { stdin: "-10 4", stdout: "-6" }
  - { stdin: "1000000000 1000000000", stdout: "2000000000", hidden: true }
hints:
  - Сумма — это `a + b`, а печатает `fmt.Println`.
```

# Проверка функции

Второй вид — ученик пишет функцию, а скрытый **харнесс** вызывает её и сравнивает результат через `dojoCheck(имя, получено, ожидалось)`. В `main` ученика при этом нет необходимости.

Здесь же видны ещё три вещи:
- плашка **«Опирается на»** сверху (`needs`) — ссылки на уроки, которые нужны для задачи;
- требования к коду (`require` / `forbid`): например, запрет готового `slices.Reverse`;
- при ошибке компиляции или паники под сообщением появляется **объяснение по-русски** — попробуй убрать `}` или записать в nil-мапу.

```task
id: reverse
lang: go
title: Перевернуть слайс
prompt: |
  Напиши функцию `Reverse(xs []int) []int`, которая возвращает **новый** слайс в обратном порядке.
  Исходный слайс менять нельзя.
starter: |
  package main

  func Reverse(xs []int) []int {
  	return nil
  }
solution: |
  package main

  func Reverse(xs []int) []int {
  	out := make([]int, len(xs))
  	for i, x := range xs {
  		out[len(xs)-1-i] = x
  	}
  	return out
  }
harness: |
  package main

  func main() {
  	dojoCheck("Reverse([1 2 3])", Reverse([]int{1, 2, 3}), []int{3, 2, 1})
  	dojoCheck("пустой слайс", len(Reverse([]int{})), 0)
  	src := []int{5, 6}
  	Reverse(src)
  	dojoCheck("исходный слайс не изменился", src, []int{5, 6})
  }
needs: [content/theory]
forbid:
  - ['slices\.Reverse', 'Сделай сам, без slices.Reverse — в этом весь смысл задачи']
require:
  - ['\bfor\b', 'Нужен цикл for']
hints:
  - Создай новый слайс через `make([]int, len(xs))`.
  - Элемент с индексом `i` должен попасть на позицию `len(xs)-1-i`.
explain: |
  `make` сразу выделяет память нужного размера — это быстрее, чем `append` в цикле.
```

# HTTP-хендлер прямо в браузере

Сети в браузере нет, но в Go есть `net/http/httptest`: он вызывает хендлер напрямую, без сокетов. Поэтому писать и проверять настоящие хендлеры можно уже здесь.

```task
id: handler
lang: go
title: Эндпоинт /hello
prompt: |
  Напиши хендлер `Hello`, который:
  - читает query-параметр `name` (если его нет — `"гость"`);
  - отвечает JSON `{"message":"привет, <name>"}` с заголовком `Content-Type: application/json`.
starter: |
  package main

  import (
  	"net/http"
  )

  func Hello(w http.ResponseWriter, r *http.Request) {
  	// твой код
  }
solution: |
  package main

  import (
  	"encoding/json"
  	"net/http"
  )

  func Hello(w http.ResponseWriter, r *http.Request) {
  	name := r.URL.Query().Get("name")
  	if name == "" {
  		name = "гость"
  	}
  	w.Header().Set("Content-Type", "application/json")
  	json.NewEncoder(w).Encode(map[string]string{"message": "привет, " + name})
  }
harness: |
  package main

  import (
  	"encoding/json"
  	"net/http/httptest"
  )

  func call(url string) (int, string, map[string]string) {
  	rec := httptest.NewRecorder()
  	Hello(rec, httptest.NewRequest("GET", url, nil))
  	var body map[string]string
  	json.Unmarshal(rec.Body.Bytes(), &body)
  	return rec.Code, rec.Header().Get("Content-Type"), body
  }

  func main() {
  	code, ct, body := call("/hello?name=Дима")
  	dojoCheck("статус 200", code, 200)
  	dojoCheck("Content-Type", ct, "application/json")
  	dojoCheck("message с именем", body["message"], "привет, Дима")
  	_, _, body = call("/hello")
  	dojoCheck("message без имени", body["message"], "привет, гость")
  }
hints:
  - Параметр читается так — `r.URL.Query().Get("name")`.
  - Для JSON удобно `json.NewEncoder(w).Encode(...)`.
```

# Горутины

Горутины и каналы тоже работают. Если программа зависнет (например, дедлок), через несколько секунд её остановят и объяснят, что могло случиться.

```task
id: workers
lang: go
title: Параллельный квадрат
prompt: |
  Функция `Squares(nums []int) []int` должна посчитать квадраты чисел **в отдельных горутинах**
  (по одной на число) и вернуть их в исходном порядке.
starter: |
  package main

  import "sync"

  func Squares(nums []int) []int {
  	var wg sync.WaitGroup
  	out := make([]int, len(nums))
  	// запусти горутину на каждое число
  	wg.Wait()
  	return out
  }
solution: |
  package main

  import "sync"

  func Squares(nums []int) []int {
  	var wg sync.WaitGroup
  	out := make([]int, len(nums))
  	for i, n := range nums {
  		wg.Add(1)
  		go func(i, n int) {
  			defer wg.Done()
  			out[i] = n * n
  		}(i, n)
  	}
  	wg.Wait()
  	return out
  }
harness: |
  package main

  func main() {
  	dojoCheck("Squares([1 2 3 4])", Squares([]int{1, 2, 3, 4}), []int{1, 4, 9, 16})
  	dojoCheck("пусто", len(Squares(nil)), 0)
  }
hints:
  - "`wg.Add(1)` перед `go`, `defer wg.Done()` внутри горутины."
  - Каждая горутина пишет в свою ячейку `out[i]` — гонки нет.
```

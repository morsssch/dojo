# От набора значений к таблице

**Множество** — набор различимых элементов, где порядок и повторения не важны: `{1, 2}` и `{2, 1}` задают одно множество. **Мощность** `|A|` — число элементов. Если каждый элемент `A` входит в `B`, то `A` — **подмножество** `B` (обозначим `A ⊆ B`). Для `A = {1, 2}` и `B = {2, 3}` получаем:

- **Объединение** `A ∪ B = {1, 2, 3}` — есть хотя бы в одном.
- **Пересечение** `A ∩ B = {2}` — есть в обоих.
- **Разность** `A ∖ B = {1}` — есть в A, но нет в B. Направление важно: `B ∖ A = {3}`.

Эти операции лежат под операциями над отношениями; там дополнительно требуется согласование атрибутов и доменов.

```quiz
id: set-ops
kind: match
question: Для A = {1, 2} и B = {2, 3} выбери результат.
pairs:
  - { left: A ∪ B, right: "{1, 2, 3}" }
  - { left: A ∩ B, right: "{2}" }
  - { left: A ∖ B, right: "{1}" }
  - { left: B ∖ A, right: "{3}" }
explain: Объединение собирает элементы, пересечение оставляет общие, разность чувствительна к порядку операндов.
```

# Почему у кортежа порядок важен

В отличие от множества **кортеж** — упорядоченная последовательность компонентов: `(42, «Атлас»)` не то же самое, что `(«Атлас», 42)`. В конспекте это называют «упорядоченным множеством»; математически точнее говорить «упорядоченный набор/кортеж», потому что в кортеже компоненты могут повторяться.

**Декартово произведение** множеств `A × B` содержит все пары `(a, b)`, где `a ∈ A`, `b ∈ B`. Если `A = {1, 2}`, `B = {книга, журнал}`, то произведение состоит из четырёх пар. Для конечных множеств `|A × B| = |A| · |B|`. **Отношение** над заданными множествами — *подмножество* их декартова произведения: мы оставляем только пары, которые имеют смысл, например «читатель 1 взял книгу», а не все теоретически возможные сочетания.

```quiz
id: product-size
kind: number
question: Сколько пар в A × B, если |A| = 3, |B| = 4?
answer: 12
explain: Каждый из трёх элементов A образует пару с каждым из четырёх элементов B.
```

# Применение к предметной области

Пусть читатели `{1, 2}`, книги `{К, Ж}`. Возможны четыре сочетания, но сегодня выдана только книга `К` читателю `1`. Отношение «сейчас выдано» содержит единственную пару `(1, К)`. Чтобы описать реальную БД, к этому добавят схему атрибутов и ограничения: не любое значение из произвольного множества подходит для номера читателя. Далее переведём математический язык на язык реляционной БД.

```quiz
id: relation-subset
question: Обязательно ли отношение «читатель взял книгу» содержит каждую пару из произведения Читатели × Книги?
options:
  - text: Нет, только пары, для которых связь действительно существует
    correct: true
  - text: Да, иначе это уже не отношение
    why: Отношение — подмножество произведения, не обязательно всё произведение.
  - text: Да, если множеств ровно два
    why: Число исходных множеств не требует включать все комбинации.
explain: Произведение перечисляет возможные пары, отношение выбирает фактически подходящие.
```

## Вопрос 30. Основные понятия теории множеств

Множество — совокупность различимых элементов, рассматриваемая как целое; порядок перечисления и повторы не меняют его. Задать множество можно перечислением, словесным описанием или предикатом: A={1,2}, либо A={x | x — целое, 1≤x≤2}. Мощность |A| — число элементов конечного множества. A⊆B означает, что каждый элемент A принадлежит B.

Объединение содержит элементы хотя бы одного множества, пересечение — обоих, разность A∖B — элементы A, не входящие в B. При A={1,2}, B={2,3}: A∪B={1,2,3}, A∩B={2}, A∖B={1}. Кортеж — упорядоченный набор компонентов, в котором возможны повторы. A×B содержит все пары (a,b); здесь это (1,2), (1,3), (2,2), (2,3), а |A×B|=4. n-арное отношение — подмножество D₁×…×Dₙ; оно может содержать лишь некоторые допустимые комбинации.

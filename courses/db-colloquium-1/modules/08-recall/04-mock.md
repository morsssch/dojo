# Условия

Закрой предыдущие уроки и не открывай карточки до конца проверки. Здесь короткие вопросы по всем разделам; после теста вернись к ошибкам и ещё раз ответь на соответствующий устный вопрос. Порог этого тренировочного теста — 80%; это не правило оценки на настоящем коллоквиуме. Реальный формат — три случайных письменных вопроса. После теста выбери три номера из 1–33 и напиши полные ответы, затем сверь их с образцами в предыдущем уроке.

```quiz
id: mock-01
question: Что такое СУБД?
options:
  - text: Программа для определения структуры, хранения, обработки и защиты данных БД

  - text: Сами записи и их значения без управляющего ПО
    why: Это база данных, но не управляющая система.

    why: Сервер — оборудование, СУБД — программное обеспечение.
```

# После проверки

Вернись к темам, где ошибся, и повтори соответствующий [письменный вопрос](lesson:recall/oral-answers). Через день проверь карточки ещё раз без подсказок. Если можешь объяснить каждый из 33 пунктов на новом примере, материал усвоен лучше, чем после простого перечитывания.

# Разбор после попытки

Для каждого ошибочного пункта восстанови полный ответ и сравни его с [образцами 1–33](lesson:recall/oral-answers). Не ограничивайся запоминанием правильной кнопки.

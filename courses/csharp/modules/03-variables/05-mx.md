# Мини-экзамен модуля 2


````task
id: step-1
lang: cs
title: Мини-экзамен модуля 2
prompt: |-
  > [!DEEP] Мини-экзамен модуля 2
  > По мотивам LeetCode 2469 «Convert the Temperature» (Easy), с добавками на всё, что было в модуле: константы, вещественные типы, разбор строки, явное приведение и округление.

  Прочитай температуру в градусах Цельсия — вещественное число, как его пишут в русской культуре, через запятую (`36,6`), может быть отрицательным. Выведи три строки:

  ```cs
  Кельвин: K
  Фаренгейт: F
  Округлённо: N °F
  ```

  - K = C + 273,15; F = C · 1,8 + 32 — оба с двумя знаками после запятой (формат `F2`);

  - N — F, округлённое через `Math.Round` и приведённое к `int`;

  - 273,15 и 1,8 объяви как `const double` с понятными именами;

  - число читай через `double.Parse`.

  Обрати внимание на третий пример: 2,5 °C = 36,5 °F, а `Math.Round(36.5)` даёт 36. Это не ошибка, а банковское округление из урока про преобразования.
starter: string? line = Console.ReadLine();
solution: |-
  const double KelvinShift = 273.15;
  const double FahrenheitFactor = 1.8;

  string? line = Console.ReadLine();
  double c = double.Parse(line);
  double k = c + KelvinShift;
  double f = c * FahrenheitFactor + 32;
  int rounded = (int)Math.Round(f);

  Console.WriteLine($"Кельвин: {k:F2}");
  Console.WriteLine($"Фаренгейт: {f:F2}");
  Console.WriteLine($"Округлённо: {rounded} °F");
````

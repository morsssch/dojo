# Типы .NET и их имена в C#

У каждого встроенного типа C# есть «настоящее» имя в .NET. Это синонимы: `int` и `System.Int32` — один и тот же тип.

| .NET | C# | Что хранит |
| --- | --- | --- |
| `System.Byte` | `byte` | целое 0…255 |
| `System.Int32` | `int` | целое, 4 байта |
| `System.Int64` | `long` | целое, 8 байт |
| `System.Single` | `float` | вещественное, 4 байта |
| `System.Double` | `double` | вещественное, 8 байт |
| `System.Boolean` | `bool` | true / false |
| `System.Char` | `char` | один символ |
| `System.String` | `string` | строка |
| `System.Decimal` | `decimal` | точное десятичное |
| `System.Object` | `object` | что угодно |

- **decimal** — число с плавающей точкой с фиксированной точностью. Преимущественно для финансов.

- В .net для любого текста только двухбайтовый Юникод: `char` занимает 2 байта.

- .net — тотально объектно-ориентированная среда: вне класса не существует ничего, в том числе глобальных переменных и функций. **Object** является предком всех классов.

> [!DEEP] В конспекте / на самом деле
> В таблице конспекта написано `System.Int` и `System.Long`. Таких типов нет, правильно `System.Int32` и `System.Int64`. Если преподаватель спросит, как в .NET называется `int`, отвечай **Int32**.

```cs run
int a = 5;
System.Int32 b = 7;
Console.WriteLine(a.GetType());
Console.WriteLine(b.GetType());
Console.WriteLine(0.1 + 0.2);
Console.WriteLine(0.1m + 0.2m);
Console.WriteLine(sizeof(char));
```

Последние строки показывают, зачем нужен `decimal`: `double` хранит двоичную дробь, и 0,1 + 0,2 даёт не ровно 0,3. Суффикс `m` делает литерал decimal-ом.


# Описание переменных и var

Стандартное C-подобное описание: `  [= ];`

```cs
int i = 5;
int j;
```

**В C# использование неинициализированных переменных запрещено**, это ошибка компиляции:

```cs run
int j;
Console.WriteLine(j); // ошибка CS0165
```

`var  = ;` — аналог `auto` из C++: тип выводится из выражения справа.

```cs run
var x = 0;       // int
var s = "abc";   // string
var d = 2.5;     // double
var m = 2.5m;    // decimal
Console.WriteLine(x.GetType().Name + " " + s.GetType().Name + " " + d.GetType().Name + " " + m.GetType().Name);
```

var — это не «любой тип»
Тип фиксируется при компиляции. После `var x = 0;` переменная навсегда `int`, и `x = "abc";` не скомпилируется. Поэтому `var x;` без значения тоже ошибка: не из чего вывести тип.


# Диапазоны, литералы и символы

У каждого числового типа есть границы — константы `MinValue` и `MaxValue`. Тип выбирают по задаче: счётчик — `int`, большие произведения — `long`, деньги — `decimal`, физика и геометрия — `double`.

```cs run
Console.WriteLine($"byte:  {byte.MinValue} … {byte.MaxValue}");
Console.WriteLine($"int:   {int.MinValue} … {int.MaxValue}");
Console.WriteLine($"long:  {long.MinValue} … {long.MaxValue}");
Console.WriteLine($"double: до {double.MaxValue}");
Console.WriteLine($"decimal: до {decimal.MaxValue}");
```

**Литерал** — значение, записанное прямо в коде. Его тип определяется видом записи:

| Литерал | Тип |
| --- | --- |
| `42` | int |
| `42L` | long |
| `4.2` | double |
| `4.2f` | float |
| `4.2m` | decimal |
| `'A'` | char — **одинарные** кавычки, ровно один символ |
| `"A"` | string — двойные кавычки |
| `true` | bool |
| `1_000_000` | int, подчёркивания для читаемости |

По лекции текст в .net — только двухбайтовый Юникод. `char` — это номер символа в таблице Юникода, поэтому с ним можно считать:

```cs run
char c = 'Ж';
int code = c;                  // char → int неявно: номер символа
Console.WriteLine(code);
Console.WriteLine((char)(code + 1));  // следующий символ
Console.WriteLine('7' - '0');         // 7: так цифру-символ превращают в число
Console.WriteLine(char.IsLetter(c) + " " + char.IsDigit('7') + " " + char.ToLower('Ж'));
```

# Задача: сумма покупок


````task
id: step-5
lang: cs
title: 'Задача: сумма покупок'
prompt: |-
  На вход подаются две строки: цена товара и количество (целое). Прочитай их, посчитай стоимость и выведи `Итого: `. Цена может быть дробной, например `199,90` — так вводят числа в русской локали, как и на твоём компьютере. Для денег используй `decimal`.

  Чтение: `string s = Console.ReadLine();`, превращение в число: `decimal.Parse(s)`, `int.Parse(s)`.
starter: |-
  string priceText = Console.ReadLine();
  string countText = Console.ReadLine();
  // преврати строки в числа и выведи итог
solution: |-
  string priceText = Console.ReadLine();
  string countText = Console.ReadLine();
  decimal price = decimal.Parse(priceText);
  int count = int.Parse(countText);
  Console.WriteLine("Итого: " + price * count);

  - stdin: |

      3

  - stdin: |
      50
      2
    stdout: 'Итого: 100'
  - stdin: |
      0,5
      7
    stdout: 'Итого: 3,5'
    hidden: true
hints:
  - 'decimal price = decimal.Parse(priceText); int count = int.Parse(countText); Console.WriteLine("Итого: " + price * count);'
require:
  - - decimal
    - 'Цену храни в decimal: это деньги.'
````

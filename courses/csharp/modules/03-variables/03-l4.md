# Операции и целочисленное деление

| Операция | Пример | Результат |
| --- | --- | --- |
| `+ - *` | `7 * 3 - 1` | 20 |
| `/` для целых | `7 / 2` | **3** — дробная часть отбрасывается |
| `/` если хоть один дробный | `7.0 / 2` | 3,5 |
| `%` остаток | `7 % 3` | 1 |
| `%` с минусом | `-7 % 3` | -1 — знак как у делимого |
| деление целых на 0 | `1 / 0` (через переменную) | исключение DivideByZeroException |
| деление double на 0 | `1.0 / 0` | ∞ (бесконечность), без исключения |

**Правило:** тип результата определяется типами операндов, а не тем, куда ты его кладёшь. `double r = 7 / 2;` даст 3, а не 3,5: сначала посчиталось целое деление, и уже готовая тройка превратилась в 3,0.

```cs run
int a = 7, b = 2;
double wrong = a / b;          // 3 — деление целых
double right = (double)a / b;  // 3,5 — a стало double до деления
Console.WriteLine($"{wrong} {right} {a % b}");
Console.WriteLine($"{-7 / 2} {-7 % 3}");   // -3 и -1: деление «к нулю»
Console.WriteLine(1.0 / 0);
```

Целочисленное деление и остаток — главные инструменты для работы с цифрами числа, временем, делимостью. В Лабе 1 они понадобятся для сокращения дробей.

## ++ и --

`i++` увеличивает на 1. Разница префикса и постфикса видна, только если результат используется в выражении:

```cs run
int i = 5;
int x = i++;   // сначала x = 5, потом i = 6
int y = ++i;   // сначала i = 7, потом y = 7
Console.WriteLine($"i={i} x={x} y={y}");
```


# Неявные и явные преобразования

Если значение одного числового типа нужно в другом, есть два случая:

|  | Неявное (само) | Явное (приведение) |
| --- | --- | --- |
| Когда | ничего не теряется: из «узкого» в «широкий» | можно потерять данные: из «широкого» в «узкий» или из дробного в целое |
| Примеры | `int → long`, `int → double`, `byte → int` | `(int)3.99` → 3, `(byte)300` → 44, `(int)someLong` → мусор, если не влезает |
| Запись | `long big = 5;` | `int n = (int)2.7;` |

```cs run
double d = 3.99;
int t = (int)d;                // 3: дробная часть отброшена, НЕ округление
int r = (int)Math.Round(d);    // 4: округление
Console.WriteLine($"{t} {r} {Math.Round(2.5)} {Math.Round(3.5)}");  // 2 и 4: банковское округление к чётному
long big = int.MaxValue;       // неявно: int помещается в long
Console.WriteLine(big + 1);
int v = 300;
Console.WriteLine((byte)v);    // 300 - 256 = 44: старшие биты отрезаны
```

Как выбирать
Если компилятор просит явное приведение (ошибка CS0266), он предупреждает: тут можно потерять данные. Прежде чем ставить `(int)`, ответь себе, что должно случиться с дробной частью или слишком большим числом. Нужно округление — `Math.Round`; нужна гарантия — проверка или `checked`.


# Переполнение: когда число не влезает

`int` хранит числа от −2 147 483 648 до 2 147 483 647 (32 бита). Если результат выходит за границы, по умолчанию лишние биты молча отбрасываются, и число «заворачивается» на другой конец диапазона.

```cs run
int max = int.MaxValue;
Console.WriteLine(max);
Console.WriteLine(max + 1);            // -2147483648: тихое переполнение

int big = 50000;
Console.WriteLine(big * big);          // мусор: 2 500 000 000 не влезает
Console.WriteLine((long)big * big);    // 2500000000: считаем в long

try
{
    int bad = checked(big * big);      // checked: переполнение — исключение
}
catch (OverflowException)
{
    Console.WriteLine("checked поймал переполнение");
}
```

Три способа защититься:

- Считать в типе пошире: `(long)a * b`. Важно привести **до** умножения: `(long)(a * b)` не поможет — умножение уже переполнилось в int.

- Обернуть в `checked( … )` — тогда вместо мусора будет `OverflowException`.

- Посчитать в long и проверить: `if (r > int.MaxValue || r < int.MinValue) …`

Это прямое требование твоей Лабы 1 — «безопасная арифметика»: при сложении дробей знаменатели перемножаются и легко выходят за int.


# Строки и числа: Parse, ToString, Math

Всё, что прочитано из консоли, — строки. Чтобы считать, их превращают в числа:

| Способ | При плохой строке |
| --- | --- |
| `int.Parse("42")` | исключение FormatException |
| `int.TryParse("42", out int n)` | возвращает false, исключения нет (подробно в модуле 5) |
| `Convert.ToInt32("42")` | исключение; для null вернёт 0 |

Обратно — `x.ToString()` или просто сложение со строкой. Формат дробей зависит от языка системы: в русской локали десятичный разделитель — запятая, `double.Parse("1,5")` работает, а `"1.5"` — нет. Курс работает в русской локали, как твой компьютер.

```cs run
double x = double.Parse("2,75");
Console.WriteLine(x * 2);
Console.WriteLine(x.ToString("F1") + " | " + (1234567.891).ToString("N2"));
Console.WriteLine(Math.Abs(-5) + " " + Math.Max(3, 9) + " " + Math.Min(3, 9));
Console.WriteLine(Math.Pow(2, 10) + " " + Math.Sqrt(2).ToString("F4"));
```

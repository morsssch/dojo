# Что такое переменная

**Переменная** — именованная ячейка памяти, в которой лежит значение определённого **типа**. Тип решает три вещи: сколько памяти занять, какие значения туда можно положить и какие операции с ними разрешены.

```cs run
int count = 3;            // объявили ячейку типа int и сразу положили 3
double price = 199.9;     // дробное число
string title = "кофе";    // строка
bool paid = false;        // логическое значение

count = count + 2;        // прочитали 3, прибавили 2, записали обратно 5
paid = true;

Console.WriteLine($"{count} × {title} по {price}, оплачено: {paid}");
```

Три действия с переменной:

| Действие | Пример | Что происходит |
| --- | --- | --- |
| Объявление | `int count;` | заводится ячейка типа int с именем count |
| Присваивание | `count = 5;` | в ячейку кладётся новое значение, старое пропадает |
| Инициализация | `int count = 5;` | объявление и первое присваивание сразу |

Знак `=` — это не «равно» из математики, а команда «вычисли правую часть и положи в левую». Поэтому `count = count + 2` имеет смысл: сначала берётся старое значение, потом записывается новое.

## Трассировка

Самый надёжный способ понять код — пройти его по строкам и записывать значения переменных. Так же работает отладчик. Пример: обмен значений двух переменных через третью.

```cs run
int a = 7;
int b = 2;
int tmp = a;   // запомнили a
a = b;         // a затёрли значением b
b = tmp;       // в b положили старое a
Console.WriteLine($"a = {a}, b = {b}");
```

| Строка | a | b | tmp |
| --- | --- | --- | --- |
| int a = 7; | 7 | — | — |
| int b = 2; | 7 | 2 | — |
| int tmp = a; | 7 | 2 | 7 |
| a = b; | 2 | 2 | 7 |
| b = tmp; | 2 | 7 | 7 |

Без `tmp` не получится: после `a = b` старое значение a исчезло бы навсегда.


# Область видимости и константы

Переменная живёт **внутри блока** `{ }`, где объявлена, начиная со строки объявления. Снаружи блока её нет.

```cs run
int total = 0;
for (int i = 1; i <= 3; i++)
{
    int square = i * i;     // square существует только внутри тела цикла
    total += square;
}
Console.WriteLine(total);
// Console.WriteLine(square);  // CS0103: имени square здесь нет
// Console.WriteLine(i);       // и i тоже: она объявлена в заголовке for
```

Во вложенном блоке нельзя объявить переменную с тем же именем, что во внешнем (в отличие от JavaScript), — компилятор выдаст ошибку CS0136. Это защищает от путаницы, какая из двух переменных имеется в виду.

## Константы

`const` — значение, которое известно при компиляции и не меняется. Компилятор подставляет его прямо в IL.

```cs run
const int Variants = 5;
const string Group = "ВПР32";
int myNumber = 7;
Console.WriteLine($"{Group}: вариант {myNumber % Variants}");
// Variants = 6;   // CS0131: константу менять нельзя
```

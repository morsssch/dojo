  > [!DEEP] Мини-экзамен модуля 5
  > По мотивам LeetCode 22 «Generate Parentheses» (Medium). Классическая задача на рекурсию, плюс модификаторы параметров `ref` и `out`.

  Прочитай число n. Если это не целое число или оно не от 1 до 8 — выведи `ошибка`. Иначе выведи все **правильные** скобочные последовательности из n пар скобок, по одной в строке, в алфавитном порядке (`(` раньше `)`), а последней строкой — `Всего: k`.

  Правильная — та, где каждой открывающей скобке соответствует закрывающая после неё: `(())()` правильная, `())(()` нет.

  **Обязательное устройство:**

  - рекурсивный метод `static void Gen(int open, int close, int n, string cur, ref int count)`: open и close — сколько скобок каждого вида уже поставлено, cur — собранная часть, count — счётчик готовых последовательностей (через `ref`, чтобы все уровни рекурсии считали в одну переменную);

  - ввод разбирай через `int.TryParse(…, out int n)`.

  Идея рекурсии: открывающую можно поставить, пока `open < n`; закрывающую — пока `close < open`. Когда длина cur стала 2n — последовательность готова (это база рекурсии).
starter: string? line = Console.ReadLine();
solution: |-
  static void Gen(int open, int close, int n, string cur, ref int count)
  {
      if (cur.Length == 2 * n)
      {
          Console.WriteLine(cur);
          count++;
          return;
      }
      if (open < n) Gen(open + 1, close, n, cur + "(", ref count);
      if (close < open) Gen(open, close + 1, n, cur + ")", ref count);
  }

  string? line = Console.ReadLine();
  if (!int.TryParse(line, out int n) || n < 1 || n > 8)
  {
      Console.WriteLine("ошибка");
  }
  else
  {
      int count = 0;
      Gen(0, 0, n, "", ref count);
      Console.WriteLine($"Всего: {count}");
  }

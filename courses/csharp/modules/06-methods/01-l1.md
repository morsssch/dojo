# Что происходит при вызове метода

**Метод** — именованный кусок кода, который можно вызывать много раз с разными данными. Зачем: не повторять код, дать действию понятное имя и проверять его отдельно (ровно так устроены этапы твоих лаб).

```cs run
using System;

class Program
{
    static int Square(int x)       // сигнатура: что принимает и что возвращает
    {
        int r = x * x;             // r — локальная переменная, живёт только внутри вызова
        return r;                  // вернуть значение и выйти
    }

    static int SumOfSquares(int a, int b)
    {
        return Square(a) + Square(b);   // метод вызывает метод
    }

    static void Main()
    {
        int s = SumOfSquares(3, 4);
        Console.WriteLine(s);
    }
}
```

Каждый вызов кладёт на **стек вызовов** новый кадр: параметры, локальные переменные и адрес, куда вернуться. `return` снимает кадр и отдаёт значение вызвавшему. Трассировка примера:

| Шаг | Стек вызовов (сверху — текущий) | Что происходит |
| --- | --- | --- |
| 1 | Main | вызов SumOfSquares(3, 4) |
| 2 | SumOfSquares(a=3, b=4) / Main | вызов Square(3) |
| 3 | Square(x=3, r=9) / SumOfSquares / Main | return 9 — кадр снят |
| 4 | SumOfSquares / Main | вызов Square(4) |
| 5 | Square(x=4, r=16) / SumOfSquares / Main | return 16 — кадр снят |
| 6 | SumOfSquares / Main | return 9 + 16 = 25 |
| 7 | Main (s = 25) | печать 25 |

Именно этот стек показывает панель «Стек вызовов» в отладчике, и по нему поднимаются исключения (модуль 3). У каждого вызова свои переменные: две переменные `x` в двух вызовах Square — разные ячейки.

static — пока просто правило
`Main` статический, поэтому из него напрямую можно вызывать только статические методы того же класса. Отсюда `static` перед методами в задачах. Что это значит по сути — в модуле ООП.

````task
  Допиши три статических метода:

  - `bool IsEven(int n)` — чётное ли;
  - `int Abs(int n)` — модуль без `Math.Abs`;
  - `int CountDigits(int n)` — сколько цифр в числе (у 0 одна цифра, знак не считается).
starter: |-
  using System;

  class Program
  {
      // IsEven, Abs, CountDigits

      static void Main()
      {
          Console.WriteLine(IsEven(10) + " " + IsEven(-3));
          Console.WriteLine(Abs(-7) + " " + Abs(5));
          Console.WriteLine(CountDigits(0) + " " + CountDigits(12345) + " " + CountDigits(-99));
      }
  }
solution: |-
  using System;

  class Program
  {
      static bool IsEven(int n) => n % 2 == 0;
      static int Abs(int n) => n < 0 ? -n : n;
      static int CountDigits(int n)
      {
          n = Abs(n);
          int c = 1;
          while (n >= 10) { n /= 10; c++; }
          return c;
      }

      static void Main()
      {
          Console.WriteLine(IsEven(10) + " " + IsEven(-3));
          Console.WriteLine(Abs(-7) + " " + Abs(5));
          Console.WriteLine(CountDigits(0) + " " + CountDigits(12345) + " " + CountDigits(-99));
      }
  }

  - stdout: |-

      7 5
      1 5 2
````

````task
starter: |-
  using System;

  class Program
  {
      static int Gcd(int a, int b)
      {
          return 1;
      }

      static void PrintReduced(int n, int d)
      {
      }

      static void Main()
      {
          PrintReduced(12, 18);
          PrintReduced(7, 3);
          PrintReduced(-4, 6);
          PrintReduced(0, 5);
      }
  }
solution: |-
  using System;

  class Program
  {
      static int Gcd(int a, int b)
      {
          a = Math.Abs(a); b = Math.Abs(b);
          while (b != 0) { int r = a % b; a = b; b = r; }
          return a;
      }

      static void PrintReduced(int n, int d)
      {
          int g = Gcd(n, d);
          Console.WriteLine($"{n / g}/{d / g}");
      }

      static void Main()
      {
          PrintReduced(12, 18);
          PrintReduced(7, 3);
          PrintReduced(-4, 6);
          PrintReduced(0, 5);
      }
  }
tests:
  - stdout: |-
      2/3
      7/3
      -2/3
      0/1
hints:
  - int g = Gcd(n, d); Console.WriteLine($"{n / g}/{d / g}"); — НОД(0, 5) = 5, поэтому 0/5 станет 0/1 сам.
````


# Функции живут только в классах

Функции могут существовать только внутри класса, поэтому **все функции — это методы**. Общий синтаксис C-подобный:

```cs
 ([параметры])
{
    
}
```

``, как и в C, может быть `void`.

## Отличия от C++

**1. Все ветки обязаны вернуть значение.** В C# нельзя использовать неинициализированные переменные, и для функций компилятор так же отслеживает, что во всех ветках программы есть оператор `return`. Иначе — ошибка компиляции:

```cs run
int Sum(int a, int b)   // CS0161: не все ветки возвращают значение
{
    if (a > b)
        return a + b;
}

Console.WriteLine(Sum(1, 2));
```

**2. Значения по умолчанию**, как в C: `int Sum(int a, int b = 1)`. Но если у параметра указано значение по умолчанию, то **все последующие** параметры тоже должны его иметь.

> [!DEEP] В конспекте
> В конспекте опечатки: «Отличия от .net» (имеется в виду от C/C++), `int sum(int am inb)`, параметры через точку с запятой. Правильный синтаксис — в примерах здесь: параметры через запятую.


# Формальные и фактические параметры, позиционный и именованный вызов

Терминология, которую преподаватель использует на лекциях и практиках (это не официальные термины C#, но спрашивать будут именно так):

- **Формальные параметры** — записаны в функции при объявлении: `(int a, int b)`.

- **Фактические параметры** — передаются при вызове: в `Sum(4, 3)` это 4 и 3.

- **Позиционный вызов** — базовый способ, параметры передаются по порядку: `Sum(4, 3)`.

- **Именованный вызов** — `Sum(a: 4, b: 3)` или `Sum(b: 3, a: 4)`. Позицию соблюдать не обязательно.

Вызовы можно смешивать, но тогда **позиционная часть стоит в начале**. Обычно это применяют к функциям с большим количеством параметров по умолчанию, из которых нужно изменить только некоторые: `f(x, y, black_list: true)`.

```cs run
string Greet(string name, string greeting = "Привет", string end = "!", bool loud = false)
{
    string s = $"{greeting}, {name}{end}";
    return loud ? s.ToUpper() : s;
}

Console.WriteLine(Greet("Марк"));                    // позиционный, остальное по умолчанию
Console.WriteLine(Greet("Марк", "Здравствуй"));
Console.WriteLine(Greet("Марк", loud: true));        // смешанный: пропустили два параметра
Console.WriteLine(Greet(end: "?", name: "преподаватель"));  // только именованные, в любом порядке
```


# Стрелочная форма функции

С лекции: **если значимый результат работы функции описывается ровно одним выражением, функцию можно записать в стрелочном виде**:

```cs
int Sum(int a, int b = 1)
{
    return a + b;
}

int Sum(int a, int b = 1) => a + b;   // то же самое
```

Таким же образом можно написать и `void`-функцию: `void Hello() => Console.WriteLine("Hi");`

```cs run
int Square(int x) => x * x;
bool IsEven(int x) => x % 2 == 0;
void Print(string s) => Console.WriteLine($"[{s}]");

Print(Square(7).ToString());
Print(IsEven(10).ToString());
```

> [!WARNING] Ловушка на защите: «почему здесь стрелочная функция, а не обычная?»
> Слово «стрелочная» в C# относится к двум разным вещам, и важно их не путать.
> 
> - **Стрелочная форма метода** (expression-bodied member): `int Square(int x) => x * x;`. Это **тот же самый метод**, что и с телом `{ return x * x; }`. Компилятор генерирует одинаковый код. Разница только в записи: стрелку используют, когда тело — одно выражение. Нельзя написать несколько операторов, нельзя цикл. Так же пишут свойства: `public int Count => items.Count;`
> 
> - **Лямбда-выражение**: `x => x * x` без имени и типа. Это **анонимная функция-значение**: её кладут в переменную делегата (`Func sq = x => x * x;`) или передают в другой метод. Лямбда может захватывать внешние переменные (замыкание). Разберём в модуле 6.
> 
> **Как ответить:** «Это стрелочная форма записи метода. Результат описывается одним выражением, поэтому по лекции функцию можно записать в стрелочном виде. По смыслу это обычный метод с return, просто короче». А если стрелка в лямбде: «Это лямбда-выражение: анонимная функция, которая передаётся как значение, как делегат».


# Задача: функции в двух формах


````task
id: step-7
lang: cs
title: 'Задача: функции в двух формах'
prompt: |-
  Напиши три функции:

  - `int Max3(int a, int b, int c)` — максимум из трёх, **обычная** форма с телом `{ }`;
  - `double Hypot(double a, double b)` — гипотенуза, в **стрелочной** форме (`Math.Sqrt`);
  - `string Repeat(string s, int times = 2, string sep = "")` — повторить строку, в **стрелочной** форме (подойдёт `string.Join(sep, Enumerable.Repeat(s, times))`).

  Main уже вызывает их, в том числе именованно.
starter: |-
  using System;
  using System.Linq;

  class Program
  {
      // твои функции

      static void Main()
      {
          Console.WriteLine(Max3(3, 9, 4));
          Console.WriteLine(Hypot(3, 4));
          Console.WriteLine(Repeat("ab"));
          Console.WriteLine(Repeat("ab", sep: "-", times: 3));
      }
  }
solution: |-
  using System;
  using System.Linq;

  class Program
  {
      static int Max3(int a, int b, int c)
      {
          int m = a;
          if (b > m) m = b;
          if (c > m) m = c;
          return m;
      }

      static double Hypot(double a, double b) => Math.Sqrt(a * a + b * b);

      static string Repeat(string s, int times = 2, string sep = "") => string.Join(sep, Enumerable.Repeat(s, times));

      static void Main()
      {
          Console.WriteLine(Max3(3, 9, 4));
          Console.WriteLine(Hypot(3, 4));
          Console.WriteLine(Repeat("ab"));
          Console.WriteLine(Repeat("ab", sep: "-", times: 3));
      }
  }
tests:
  - stdout: |-
      9
      5
      abab
      ab-ab-ab
hints:
  - static int Max3(int a, int b, int c) { int m = a; if (b > m) m = b; if (c > m) m = c; return m; } — функции внутри класса должны быть static, раз вызываются из static Main.
require:
  - - Hypot\s*\([^)]*\)\s*=>
    - 'Hypot напиши в стрелочной форме: … Hypot(double a, double b) => …'
  - - Repeat\s*\([^)]*\)\s*=>
    - Repeat тоже в стрелочной форме.
  - - Max3\s*\([^)]*\)\s*\{
    - Max3 — в обычной форме с телом { }.
````

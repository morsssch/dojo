# in, out, ref

Параметры могут иметь модификаторы:

- `in int a` — **входной** параметр. Подразумевается по умолчанию, можно прописать явно.

- `out int a` — **выходной** параметр, фактически результат работы функции. Он считается чисто выходным, поэтому его инициализация на входе не проверяется, но **при завершении функции у него должно быть значение**.

- `ref int a` — передача параметра **по ссылке**, аналог `int&` из C++.

Для **значимого** типа `ref` позволяет изменить переменную вызывающего:

```cs run
void Foo(ref int x)
{
    x *= 2;
}

int y = 10;
Foo(ref y);
Console.WriteLine(y); // 20
```

Для **ссылочных** типов и так передаётся ссылка, и менять содержимое можно без ref. А `ref` для ссылочного типа позволяет изменить **саму ссылку**, например подменить массив новым:

```cs run
void Change(int[] a) { a[0] = 100; }             // меняем содержимое — видно снаружи
void Replace(int[] a) { a = new int[] { 7, 7 }; } // меняем локальную копию ссылки — не видно
void ReplaceRef(ref int[] a) { a = new int[] { 2, 3, 5 }; } // меняем саму ссылку — видно

var ar = new int[] { 1, 2, 3 };
Change(ar);        Console.WriteLine(string.Join(",", ar)); // 100,2,3
Replace(ar);       Console.WriteLine(string.Join(",", ar)); // 100,2,3
ReplaceRef(ref ar); Console.WriteLine(string.Join(",", ar)); // 2,3,5
```

И при объявлении, и при вызове ключевое слово пишется: `Foo(ref y)`, `int.TryParse(s, out int n)`.

> [!DEEP] В конспекте / на самом деле: про in
> По лекции `in` — «входной параметр, подразумевается по умолчанию». По смыслу так и есть: функция его только читает. Технически разница есть: без модификатора параметр передаётся **копией значения**, а с `in` — **по ссылке только для чтения** (менять его внутри нельзя, компилятор запретит). `in` ставят для больших структур, чтобы не копировать их при каждом вызове. Поэтому в лабах встречается `Contains(in IPv4Address address)`.


# params и шаблон Try

`params` — упрощённый способ передачи, возможно, неопределённого количества параметров в функцию.

```cs run
int Sum(params int[] a)
{
    int s = 0;
    foreach (int x in a) s += x;
    return s;
}

var ar = new[] { 1, 2, 3 };
Console.WriteLine(Sum(ar));                   // массив
Console.WriteLine(Sum(new[] { 1, 2, 3, 5 })); // массив
Console.WriteLine(Sum(2, 5, 15, -7));         // только благодаря params
Console.WriteLine(Sum(4, 9));                 // только благодаря params
Console.WriteLine(Sum());                     // пустой массив

void Show(params object[] o) => Console.WriteLine(o.Length + " шт.: " + string.Join(" | ", o));
Show(2, "abc", 3.5, true);                    // параметр для любых типов
```

`params` ставится только на **последний** параметр, и он один.

## Шаблон Try: bool + out

дополнение В .NET есть устойчивый приём: метод `TryЧтото(…, out результат)` возвращает `bool` «получилось ли», а сам результат кладёт в out-параметр. Исключения при этом не бросаются. Он нужен в Лабе 1: `TryCreate(int n, int d, out Rational value)`.

```cs run
string[] inputs = { "42", "abc", "-7" };
foreach (var s in inputs)
{
    if (int.TryParse(s, out int n))
        Console.WriteLine($"{s} → число {n}");
    else
        Console.WriteLine($"{s} → не число");
}

bool TryDivide(int a, int b, out int result)
{
    if (b == 0) { result = 0; return false; } // out обязан получить значение и тут
    result = a / b;
    return true;
}
Console.WriteLine(TryDivide(7, 2, out var r1) + " " + r1);
Console.WriteLine(TryDivide(7, 0, out var r2) + " " + r2);
```


# Задача: Swap и MinMax


````task
id: step-3
lang: cs
title: 'Задача: Swap и MinMax'
prompt: |-
  Напиши две функции:

  - `void Swap(ref int a, ref int b)` — меняет значения местами;
  - `void MinMax(int[] arr, out int min, out int max)` — находит минимум и максимум; для пустого массива бросает `ArgumentException`, для `null` — `ArgumentNullException`.
starter: |-
  using System;

  class Program
  {
      // Swap и MinMax

      static void Main()
      {
          int x = 1, y = 2;
          Swap(ref x, ref y);
          Console.WriteLine($"{x} {y}");

          MinMax(new[] { 5, -3, 12, 0 }, out int lo, out int hi);
          Console.WriteLine($"{lo} {hi}");

          try { MinMax(new int[0], out _, out _); }
          catch (ArgumentNullException) { Console.WriteLine("null"); }
          catch (ArgumentException) { Console.WriteLine("пусто"); }

          try { MinMax(null, out _, out _); }
          catch (ArgumentNullException) { Console.WriteLine("null"); }
          catch (ArgumentException) { Console.WriteLine("пусто"); }
      }
  }
solution: |-
  using System;

  class Program
  {
      static void Swap(ref int a, ref int b)
      {
          int t = a;
          a = b;
          b = t;
      }

      static void MinMax(int[] arr, out int min, out int max)
      {
          if (arr == null) throw new ArgumentNullException(nameof(arr));
          if (arr.Length == 0) throw new ArgumentException("Массив пуст", nameof(arr));
          min = max = arr[0];
          foreach (int v in arr)
          {
              if (v < min) min = v;
              if (v > max) max = v;
          }
      }

      static void Main()
      {
          int x = 1, y = 2;
          Swap(ref x, ref y);
          Console.WriteLine($"{x} {y}");

          MinMax(new[] { 5, -3, 12, 0 }, out int lo, out int hi);
          Console.WriteLine($"{lo} {hi}");

          try { MinMax(new int[0], out _, out _); }
          catch (ArgumentNullException) { Console.WriteLine("null"); }
          catch (ArgumentException) { Console.WriteLine("пусто"); }

          try { MinMax(null, out _, out _); }
          catch (ArgumentNullException) { Console.WriteLine("null"); }
          catch (ArgumentException) { Console.WriteLine("пусто"); }
      }
  }
tests:
  - stdout: |-
      2 1
      -3 12
      пусто
      null
hints:
  - 'Swap: (a, b) = (b, a); или через временную переменную. В MinMax сначала обе проверки, потом min = max = arr[0] и цикл.'
````


# Задача: TryParseFraction


````task
id: step-4
lang: cs
title: 'Задача: TryParseFraction'
prompt: |-
  Разминка перед Лабой 1. Напиши `bool TryParseFraction(string s, out int num, out int den)`: строка вида `3/4` или `-5/2`. Верни `false` (и нули в out), если строка `null`, в ней нет ровно одного `/`, одна из частей не число или знаменатель 0. Исключений не бросай — используй `int.TryParse`.

  Программа читает строки до конца ввода и печатает `num den` или `ошибка`.
starter: |-
  using System;

  class Program
  {
      static bool TryParseFraction(string s, out int num, out int den)
      {
          num = 0; den = 0;
          // твой код
          return false;
      }

      static void Main()
      {
          string? line;
          while ((line = Console.ReadLine()) != null)
          {
              if (TryParseFraction(line, out int n, out int d))
                  Console.WriteLine($"{n} {d}");
              else
                  Console.WriteLine("ошибка");
          }
      }
  }
solution: |-
  using System;

  class Program
  {
      static bool TryParseFraction(string s, out int num, out int den)
      {
          num = 0; den = 0;
          if (s == null) return false;
          string[] p = s.Split('/');
          if (p.Length != 2) return false;
          if (!int.TryParse(p[0], out int n) || !int.TryParse(p[1], out int d)) return false;
          if (d == 0) return false;
          num = n; den = d;
          return true;
      }

      static void Main()
      {
          string? line;
          while ((line = Console.ReadLine()) != null)
          {
              if (TryParseFraction(line, out int n, out int d))
                  Console.WriteLine($"{n} {d}");
              else
                  Console.WriteLine("ошибка");
          }
      }
  }
tests:
  - stdin: |
      3/4
      -5/2
      abc
      1/0
    stdout: |-
      3 4
      -5 2
      ошибка
      ошибка
  - stdin: |
      1/2/3
      /5
      7/x
      10/-4
    stdout: |-
      ошибка
      ошибка
      ошибка
      10 -4
    hidden: true
hints:
  - string[] p = s.Split('/'); if (p.Length != 2) return false; if (!int.TryParse(p[0], out num) || !int.TryParse(p[1], out den)) { num = den = 0; return false; }
forbid:
  - - int\.Parse\s*\(
    - 'Используй int.TryParse: метод не должен бросать исключения.'
````


# Задача: params-среднее


````task
id: step-5
lang: cs
title: 'Задача: params-среднее'
prompt: 'Напиши `static double Average(params int[] nums)`: среднее арифметическое; если чисел нет — `ArgumentException`; если передан `null` — `ArgumentNullException`. Main вызывает его по-разному.'
starter: |-
  using System;

  class Program
  {
      static void Main()
      {
          Console.WriteLine(Average(1, 2, 3, 4));
          Console.WriteLine(Average(5));
          Console.WriteLine(Average(new[] { 10, 20 }));
          try { Average(); } catch (ArgumentException) { Console.WriteLine("пусто"); }
      }
  }
solution: |-
  using System;

  class Program
  {
      static double Average(params int[] nums)
      {
          if (nums == null) throw new ArgumentNullException(nameof(nums));
          if (nums.Length == 0) throw new ArgumentException("Нет чисел", nameof(nums));
          long s = 0;
          foreach (int x in nums) s += x;
          return (double)s / nums.Length;
      }

      static void Main()
      {
          Console.WriteLine(Average(1, 2, 3, 4));
          Console.WriteLine(Average(5));
          Console.WriteLine(Average(new[] { 10, 20 }));
          try { Average(); } catch (ArgumentException) { Console.WriteLine("пусто"); }
      }
  }
tests:
  - stdout: |-
      2,5
      5
      15
      пусто
hints:
  - if (nums == null) throw new ArgumentNullException(nameof(nums)); if (nums.Length == 0) throw new ArgumentException("Нет чисел"); long s = 0; foreach (int x in nums) s += x; return (double)s / nums.Length;
require:
  - - params\s+int\s*\[\s*\]
    - Нужен параметр params int[] nums.
````

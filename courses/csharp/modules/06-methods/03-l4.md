# Перегрузка: одно имя — разные параметры

В классе может быть несколько методов с одним именем, если у них разные **списки параметров** (число или типы). Это **перегрузка**. Компилятор выбирает подходящую версию по фактическим параметрам ещё при компиляции.

```cs run
using System;

class Program
{
    static double Area(double r) => Math.PI * r * r;           // круг
    static double Area(double w, double h) => w * h;           // прямоугольник
    static int Area(int side) => side * side;                  // квадрат с целой стороной

    static void Main()
    {
        Console.WriteLine(Area(1.0).ToString("F2"));   // double → версия для круга
        Console.WriteLine(Area(2.0, 3.0));             // два параметра
        Console.WriteLine(Area(4));                    // int → версия для квадрата
    }
}
```

**Сигнатура** метода — имя плюс типы параметров. Тип результата в сигнатуру **не** входит: два метода, отличающихся только тем, что возвращают, не скомпилируются.

Ты уже пользовался перегрузкой: у `Console.WriteLine` 18 версий — для int, double, string, object, без аргументов… Перегрузка понадобится в Лабе 1: `Equals(Rational)` и `Equals(object)` — два метода с одним именем, а операторы `-a` и `a - b` — два разных оператора «минус».


# Рекурсия: метод вызывает сам себя

Рекурсия — когда метод решает задачу, вызывая себя на задаче поменьше. Нужны две части: **базовый случай** (ответ без рекурсии) и **шаг** (свести к меньшей задаче). Алгоритм Евклида рекурсивно записывается ровно своим определением:

```cs run
using System;

class Program
{
    static int Gcd(int a, int b)
    {
        Console.WriteLine($"  Gcd({a}, {b})");
        if (b == 0) return a;          // базовый случай
        return Gcd(b, a % b);          // шаг: задача меньше
    }

    static void Main()
    {
        Console.WriteLine("ответ: " + Gcd(48, 18));
    }
}
```

Каждый рекурсивный вызов — новый кадр на стеке вызовов. Если забыть базовый случай, кадры будут копиться бесконечно, и программа упадёт со `StackOverflowException` — это исключение даже нельзя поймать catch. Правило: рекурсия хороша, когда задача естественно определяется через себя (НОД, деревья, обход папок в Лабе 4); для простого счёта цикл проще и надёжнее.


# Задача: перегрузка Max


````task
id: step-3
lang: cs
title: 'Задача: перегрузка Max'
prompt: 'Напиши три перегрузки `Max`: для двух `int`, для трёх `int` (через вызов версии для двух) и для двух `double`. Main уже их вызывает.'
starter: |-
  using System;

  class Program
  {
      static void Main()
      {
          Console.WriteLine(Max(3, 8));
          Console.WriteLine(Max(3, 8, 5));
          Console.WriteLine(Max(2.5, -1.0));
      }
  }
solution: |-
  using System;

  class Program
  {
      static int Max(int a, int b) => a > b ? a : b;
      static int Max(int a, int b, int c) => Max(Max(a, b), c);
      static double Max(double a, double b) => a > b ? a : b;

      static void Main()
      {
          Console.WriteLine(Max(3, 8));
          Console.WriteLine(Max(3, 8, 5));
          Console.WriteLine(Max(2.5, -1.0));
      }
  }
tests:
  - stdout: |-
      8
      8
      2,5
require:
  - - Max\s*\(\s*Max\s*\(|Max\s*\(\s*\w+\s*,\s*Max\s*\(
    - Версию для трёх чисел собери из вызовов версии для двух.
````


# Задача: рекурсивная степень


````task
id: step-4
lang: cs
title: 'Задача: рекурсивная степень'
prompt: 'Напиши рекурсивный `static long Power(long x, int n)` для n ≥ 0: базовый случай n = 0 → 1; если n чётное — `Power(x, n/2)` в квадрате; иначе `x * Power(x, n - 1)`. Циклы не используй.'
starter: |-
  using System;

  class Program
  {
      static long Power(long x, int n)
      {
          return 1;
      }

      static void Main()
      {
          Console.WriteLine(Power(2, 10));
          Console.WriteLine(Power(3, 0));
          Console.WriteLine(Power(-2, 5));
          Console.WriteLine(Power(7, 13));
      }
  }
solution: |-
  using System;

  class Program
  {
      static long Power(long x, int n)
      {
          if (n == 0) return 1;
          if (n % 2 == 0)
          {
              long h = Power(x, n / 2);
              return h * h;
          }
          return x * Power(x, n - 1);
      }

      static void Main()
      {
          Console.WriteLine(Power(2, 10));
          Console.WriteLine(Power(3, 0));
          Console.WriteLine(Power(-2, 5));
          Console.WriteLine(Power(7, 13));
      }
  }
tests:
  - stdout: |-
      1024
      1
      -32
      96889010407
hints:
  - if (n == 0) return 1; if (n % 2 == 0) { long h = Power(x, n / 2); return h * h; } return x * Power(x, n - 1);
forbid:
  - - \b(for|while)\b
    - Без циклов — только рекурсия.
  - - Math\.Pow
    - Без Math.Pow.
````

# Как это могут спросить на защите


````cards
id: step-6
title: Как это могут спросить на защите
items:
  - q: Чем out отличается от ref?
    a: 'ref — передача по ссылке: переменная должна быть инициализирована до вызова, функция может её читать и менять. out — чисто выходной: инициализация на входе не проверяется, но к завершению функции он обязан получить значение.'
  - q: Что такое params и где он встречается в стандартной библиотеке?
    a: 'Способ передать неопределённое количество параметров: внутри функции это массив. Пример — `string.Format(string fmt, params object[] args)` и `Console.WriteLine(format, …)`.'
  - q: Почему у вас здесь стрелочная функция, а не обычная?
    a: 'Результат функции описывается одним выражением, а по лекции такую функцию можно записать в стрелочном виде. Это та же самая функция, что и с блоком и return, компилятор создаёт одинаковый код, просто запись короче. Лямбда — другое: это анонимная функция-значение для делегата.'
  - q: Что такое формальные и фактические параметры?
    a: Формальные — записаны в объявлении функции, например `(int a, int b)`. Фактические — передаются при вызове, в `Sum(4, 3)` это 4 и 3.
````

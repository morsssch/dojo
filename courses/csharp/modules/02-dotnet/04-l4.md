# Из чего состоит программа

Разберём классическую программу по частям:

```cs run
using System;                       // 1. директива: сокращаем имена из System

class Program                       // 2. класс — контейнер для всего кода
{                                   //    фигурные скобки — границы блока
    static void Main()              // 3. метод Main — точка входа
    {
        // 4. комментарий до конца строки, компилятор его не видит
        string name = "Марк";       // 5. оператор: объявление переменной; в конце ;
        Console.WriteLine("Привет, " + name + "!");   // 6. вызов метода
        /* многострочный
           комментарий */
        Console.WriteLine(2 + 3 * 4);
    }
}
```

| Часть | Правило |
| --- | --- |
| `;` | каждый оператор заканчивается точкой с запятой. Перенос строки ничего не значит |
| `{ }` | блок: тело класса, метода, if, цикла. Пары обязательно сходятся |
| Регистр | C# различает регистр: `Main` ≠ `main`, `WriteLine` ≠ `writeline` |
| `Main` | с него начинается выполнение. Ровно один на программу |
| Имена | соглашение: классы, методы, свойства — `PascalCase`; переменные и параметры — `camelCase`; поля — `camelCase` или `_camelCase` |

## Что происходит при запуске

CLR загружает сборку, находит метод `Main`, JIT компилирует его, и строки выполняются сверху вниз, по одной. Вот трассировка — таблица, какое значение у переменных после каждой строки. Это ровно то, что показывает отладчик при шагах F10:

| Строка | name | Вывод |
| --- | --- | --- |
| string name = "Марк"; | "Марк" |  |
| Console.WriteLine("Привет, " + name + "!"); | "Марк" | Привет, Марк! |
| Console.WriteLine(2 + 3 * 4); | "Марк" | 14 |

Обрати внимание: `2 + 3 * 4` даёт 14, умножение раньше сложения, как в математике.


# Два вида записи: классический Main и код без класса

С C# 9 можно писать команды прямо в файле, без класса — **операторы верхнего уровня** (top-level statements). Так выглядит пустой новый проект без флага `--use-program-main`:

```cs run
Console.WriteLine("Привет, C#!");
Console.WriteLine(2 + 3);
```

Это та же программа: компилятор сам заворачивает строки в класс `Program` и метод `Main`. Поэтому слова лекции 01.09 *«.net — тотально объектно-ориентированная среда, вне класса не существует ничего»* остаются верными: класс есть, его просто не видно. Проверим:

```cs run
Console.WriteLine(typeof(Program).Name);   // класс Program существует, хоть мы его и не писали
```

> [!TIP] Что выбрать
> В коротких задачах курса пиши как удобно. В лабах — классический `class Program` со `static void Main()`: так видно точку входа, и автопроверки лаб вызывают твои классы отдельно от меню. Если в одном файле есть и код верхнего уровня, и классы, код верхнего уровня обязан стоять **выше** объявлений классов.

## Вывод в консоль

- `Console.WriteLine(x)` — вывести и перейти на новую строку. Без аргументов — просто пустая строка.
- `Console.Write(x)` — вывести без перевода строки.

Внутри строки специальные символы записываются через обратную косую черту: `
` — перевод строки, `	` — табуляция, `"` — кавычка, `\` — сама обратная черта.

```cs run
Console.Write("один ");
Console.Write("два");
Console.WriteLine();
Console.WriteLine("колонка1\tколонка2");
Console.WriteLine("Он сказал: \"привет\"");
Console.WriteLine("путь C:\\labs\\Lab1");
Console.WriteLine("строка 1\nстрока 2");
```

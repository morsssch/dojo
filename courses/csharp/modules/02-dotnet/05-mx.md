# Мини-экзамен модуля 1


````task
id: step-1
lang: cs
title: Мини-экзамен модуля 1
prompt: "> [!DEEP] Мини-экзамен модуля 1\n> Задачи в духе LeetCode начнутся со следующего модуля, когда появятся ввод и вычисления. Здесь проверка другая: сможешь ли ты написать программу **целиком с нуля**, без заготовки, как на защите в пустом проекте.\n\nНапиши программу в **классическом** виде: пространство имён `Exam`, в нём `class Program` со `static void Main()`. Программа выводит ровно это:\n\n```cs\nОтчёт о сборке\n\tПроект: \"Lab1\"\n\tПуть: C:\\Users\\Mors\\Lab1\\bin\n\tСреда: .NET\nГотово!\n```\n\nСтроки 2–4 начинаются с символа табуляции. Обязательно:\n\n- кавычки, табуляция и обратные слэши — через escape-последовательности `\\\"`, `\\t`, `\\\\` (без `@`);\n\n- хотя бы один вызов через **полное имя** `System.Console.WriteLine(…)`, остальные — коротко, через `using System;`;\n\n- слово `Готово!` выведи двумя вызовами: `Console.Write(\"Готово\")` и `Console.WriteLine(\"!\")`."
starter: '// пустой файл: пиши всё сам'
solution: |-
  using System;

  namespace Exam
  {
      class Program
      {
          static void Main()
          {
              System.Console.WriteLine("Отчёт о сборке");
              Console.WriteLine("\tПроект: \"Lab1\"");
              Console.WriteLine("\tПуть: C:\\Users\\Mors\\Lab1\\bin");
              Console.WriteLine("\tСреда: .NET");
              Console.Write("Готово");
              Console.WriteLine("!");
          }
      }
  }
tests:
  - stdout: "Отчёт о сборке\n\tПроект: \"Lab1\"\n\tПуть: C:\\Users\\Mors\\Lab1\\bin\n\tСреда: .NET\nГотово!"
hints:
  - 'Скелет: using System; namespace Exam { class Program { static void Main() { … } } }. Строка пути: "\tПуть: C:\\Users\\Mors\\Lab1\\bin".'
needs:
  - dotnet/l3
  - dotnet/l4
require:
  - - namespace\s+Exam
    - Нужно пространство имён Exam.
  - - class\s+Program
    - Нужен class Program.
  - - static\s+void\s+Main\s*\(
    - Нужен static void Main().
  - - using\s+System\s*;
    - Подключи using System;.
  - - System\.Console\.WriteLine
    - Хотя бы один раз вызови System.Console.WriteLine по полному имени.
  - - Console\.Write\s*\(
    - «Готово» выведи через Console.Write, без перевода строки.
  - - \\t
    - Табуляцию пиши как \t.
  - - \\\\
    - Обратный слэш в строке пиши как \\.
forbid:
  - - '@"'
    - 'Здесь без @-строк: потренируй escape-последовательности.'
````

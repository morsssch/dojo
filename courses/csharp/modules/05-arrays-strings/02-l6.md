# Ступенчатые и прямоугольные массивы

**2. Ступенчатые (jagged) многомерные массивы** — одномерные массивы одномерных массивов: `int[][]`. Каждый элемент — ссылка на отдельный массив `int[]`, поэтому строки могут быть разной длины.

```cs run
int[][] j = new int[3][];        // 3 строки, пока все null
j[0] = new int[] { 1, 2 };
j[1] = new int[] { 3, 4, 5, 6 };
j[2] = new int[0];

int[][] k = { new[] { 1 }, new[] { 2, 3 } }; // сразу с данными

Console.WriteLine(j.Length);     // 3 строки
Console.WriteLine(j[1].Length);  // 4 элемента во второй
Console.WriteLine(j[1][2]);      // 5
```

**3. Прямоугольные массивы.** `[,] a = new [4, 3];` — двумерный массив 4 на 3. В памяти представляется как **единый объект**. Размер по каждому измерению даёт метод `.GetLength(номер измерения)`.

int[,] m = new int[4, 3];
m[1, 2] = 7;
Console.WriteLine(m.GetLength(0)); // 4 — строк
Console.WriteLine(m.GetLength(1)); // 3 — столбцов
Console.WriteLine(m.Length);       // 12 — всего элементов

# Задача: таблица умножения в прямоугольном массиве


````task
id: step-2
lang: cs
title: 'Задача: таблица умножения в прямоугольном массиве'
prompt: Прочитай `n`. Создай прямоугольный массив `int[n, n]`, заполни его так, что `m[i, j] = (i + 1) * (j + 1)`, и выведи построчно, разделяя числа пробелом. Для размеров используй `GetLength`.
starter: |-
  int n = int.Parse(Console.ReadLine());
  int[,] m = new int[n, n];
solution: |-
  int n = int.Parse(Console.ReadLine());
  int[,] m = new int[n, n];
  for (int i = 0; i < m.GetLength(0); i++)
      for (int j = 0; j < m.GetLength(1); j++)
          m[i, j] = (i + 1) * (j + 1);

  for (int i = 0; i < m.GetLength(0); i++)
  {
      for (int j = 0; j < m.GetLength(1); j++)
          Console.Write(m[i, j] + " ");
      Console.WriteLine();
  }
tests:
  - stdin: |
      3
    stdout: |-
      1 2 3
      2 4 6
      3 6 9
  - stdin: |
      1
    stdout: '1'
    hidden: true
  - stdin: |
      4
    stdout: |-
      1 2 3 4
      2 4 6 8
      3 6 9 12
      4 8 12 16
    hidden: true
hints:
  - Два вложенных цикла. Чтобы не было пробела в конце строки, можно собирать строку или просто печатать пробел перед каждым числом кроме первого. Лишние пробелы в конце строки проверка всё равно игнорирует.
require:

    - Для обхода используй m.GetLength(0) и m.GetLength(1).
````

# Задача: треугольник Паскаля


````task
id: step-3
lang: cs
title: 'Задача: треугольник Паскаля'
prompt: 'Ввод: n (1–10). Построй **ступенчатый** массив `int[][]`, где строка i имеет длину i + 1: края — единицы, внутри — сумма двух чисел над ним. Выведи строки через пробел.'
starter: |-
  int n = int.Parse(Console.ReadLine());
  int[][] t = new int[n][];
solution: |-
  int n = int.Parse(Console.ReadLine());
  int[][] t = new int[n][];
  for (int i = 0; i < n; i++)
  {
      t[i] = new int[i + 1];
      t[i][0] = t[i][i] = 1;
      for (int j = 1; j < i; j++) t[i][j] = t[i - 1][j - 1] + t[i - 1][j];
  }
  foreach (int[] row in t) Console.WriteLine(string.Join(" ", row));
tests:
  - stdin: |
      5
    stdout: |-
      1
      1 1
      1 2 1
      1 3 3 1
      1 4 6 4 1
  - stdin: |
      1
    stdout: '1'
    hidden: true
hints:
  - for (int i = 0; i < n; i++) { t[i] = new int[i + 1]; t[i][0] = t[i][i] = 1; for (int j = 1; j < i; j++) t[i][j] = t[i-1][j-1] + t[i-1][j]; }
require:
  - - \[\]\s*\[\]
    - Нужен ступенчатый массив int[][].
````

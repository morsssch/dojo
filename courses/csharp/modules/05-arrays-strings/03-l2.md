# Что такое кортеж

**Кортеж** — неизменяемый тип данных фиксированной длины, который определяется набором и порядком входящих в него, возможно разнотипных, элементов.

```cs
(int, string) t = (-8, "Лампа");
(string, int) t2 = ("кружка", 12);   // (int,string) и (string,int) несовместимы
(int, int, double) t3 = (1, 2, 3.5);
(string, (double, double)) t4 = ("точка", (1.5, 2.0)); // кортеж в кортеже
```

Ограничений на типы нет, тип кортежа полноценный и может использоваться где угодно.

**Индексации у кортежа нет**, поэтому 2 варианта доступа к элементам:

- По автогенерируемым полям `Item1`, `Item2` и т. д. Нумерация здесь **с единицы**.

- Описать тип кортежа с **именами полей**.

```cs run
var t1 = (5, "abc");
Console.WriteLine(t1.Item1);   // 5
Console.WriteLine(t1.Item2);   // abc

(int n, string name) t2 = (5, "abc");
Console.WriteLine(t2.n + " " + t2.name);

var t3 = (n: 5, name: "abc");  // имена прямо в значении
Console.WriteLine(t3.n + " " + t3.name);
Console.WriteLine(t3);         // (5, abc)
```

> [!DEEP] В конспекте / на самом деле
> «Кортеж неизменяемый» — так сказано на лекции. В C# у кортежей `(int, string)` элементы на самом деле **можно** перезаписать: `t1.Item1 = 10;` скомпилируется. Неизменяемыми (readonly) они становятся, только если так объявлена переменная или поле. На защите говори по лекции, но не удивляйся, если `t.Item1 = …` сработает.


# Возврат нескольких значений

Главное применение кортежей — вернуть из функции несколько результатов:

```cs run
(int div, int mod) DivMod(int n, int m)
{
    return (n / m, n % m);
}

var r = DivMod(10, 3);
Console.WriteLine(r.div);  // 3
Console.WriteLine(r.mod);  // 1

var (q, rest) = DivMod(17, 5);  // сразу разложить на две переменные
Console.WriteLine($"{q} и {rest}");
```

Запись `var (q, rest) = …` называется **деконструкцией**. Ещё один удобный трюк — обмен значений без временной переменной: `(a, b) = (b, a);`


# Задача: минимум, максимум и среднее


````task
id: step-3
lang: cs
title: 'Задача: минимум, максимум и среднее'
prompt: 'Напиши функцию `(int min, int max, double avg) Stats(int[] a)`, которая за один проход считает минимум, максимум и среднее. Программа читает числа из строки и выводит `min=… max=… avg=…`, среднее — с двумя знаками после запятой: `{avg:F2}`.'
starter: |-
  (int min, int max, double avg) Stats(int[] a)
  {
      // твой код
  }

  string[] parts = Console.ReadLine().Split(' ');
  int[] nums = new int[parts.Length];
  for (int i = 0; i < parts.Length; i++) nums[i] = int.Parse(parts[i]);

  var s = Stats(nums);
  Console.WriteLine($"min={s.min} max={s.max} avg={s.avg:F2}");
solution: |-
  (int min, int max, double avg) Stats(int[] a)
  {
      int min = a[0], max = a[0];
      long sum = 0;
      foreach (int x in a)
      {
          if (x < min) min = x;
          if (x > max) max = x;
          sum += x;
      }
      return (min, max, (double)sum / a.Length);
  }

  string[] parts = Console.ReadLine().Split(' ');
  int[] nums = new int[parts.Length];
  for (int i = 0; i < parts.Length; i++) nums[i] = int.Parse(parts[i]);

  var s = Stats(nums);
  Console.WriteLine($"min={s.min} max={s.max} avg={s.avg:F2}");
tests:
  - stdin: |
      4 8 15 16 23 42
    stdout: min=4 max=42 avg=18,00
  - stdin: |
      7
    stdout: min=7 max=7 avg=7,00
  - stdin: |
      -3 3 1
    stdout: min=-3 max=3 avg=0,33
    hidden: true
hints:
  - 'Внутри: int min = a[0], max = a[0]; long sum = 0; цикл по всем; return (min, max, (double)sum / a.Length);'
````


# Задача: упорядоченная пара


````task
id: step-4
lang: cs
title: 'Задача: упорядоченная пара'
prompt: Напиши функцию `(int Lo, int Hi) Ordered(int a, int b)`, которая возвращает пару, где `Lo ≤ Hi`. Программа читает два числа и печатает `Lo..Hi`, получая результат деконструкцией `var (lo, hi) = …`.
starter: |-
  (int Lo, int Hi) Ordered(int a, int b)
  {
      return (a, b);
  }

  int x = int.Parse(Console.ReadLine());
  int y = int.Parse(Console.ReadLine());
solution: |-
  (int Lo, int Hi) Ordered(int a, int b)
  {
      return a <= b ? (a, b) : (b, a);
  }

  int x = int.Parse(Console.ReadLine());
  int y = int.Parse(Console.ReadLine());
  var (lo, hi) = Ordered(x, y);
  Console.WriteLine($"{lo}..{hi}");
tests:
  - stdin: |
      9
      3
    stdout: 3..9
  - stdin: |
      2
      5
    stdout: 2..5
    hidden: true
  - stdin: |
      4
      4
    stdout: 4..4
    hidden: true
require:
  - - var\s*\(\s*\w+\s*,\s*\w+\s*\)\s*=
    - 'Получи результат деконструкцией: var (lo, hi) = Ordered(x, y);'
````

  }

# Мини-экзамен модуля 4


````task
id: step-1
lang: cs
title: Мини-экзамен модуля 4
prompt: |-
  > [!DEEP] Мини-экзамен модуля 4
  > По мотивам LeetCode 1 «Two Sum» (Easy) — самая известная задача LeetCode. Здесь она ещё и про разбор строки, массив и кортеж.

  **Ввод:** в первой строке целые числа через пробел (массив `nums`), во второй — целое `target`.

  Найди индексы `i < j`, для которых `nums[i] + nums[j] == target`. Если пар несколько — первую при переборе: сначала по возрастанию i, потом по возрастанию j. Выведи:

  ```cs
  i j (nums[i] + nums[j] = target)
  ```

  например `0 1 (2 + 7 = 9)`. Если пары нет — `нет пары`.

  - строку разбей через `Split` и переведи в массив `int[]`;

  - ответ храни в кортеже с именованными полями: `(int i, int j) pair = (-1, -1);` — найденную пару запиши в него, а вывод сделай после циклов, разобрав кортеж.
starter: |-
  string[] parts = Console.ReadLine().Split(' ');
  int target = int.Parse(Console.ReadLine());
solution: |-
  string[] parts = Console.ReadLine().Split(' ');
  int target = int.Parse(Console.ReadLine());

  int[] nums = new int[parts.Length];
  for (int k = 0; k < parts.Length; k++)
      nums[k] = int.Parse(parts[k]);

  (int i, int j) pair = (-1, -1);
  for (int i = 0; i < nums.Length && pair.i == -1; i++)
      for (int j = i + 1; j < nums.Length; j++)
          if (nums[i] + nums[j] == target)
          {
              pair = (i, j);
              break;
          }

  if (pair.i == -1)
      Console.WriteLine("нет пары");
  else
  {
      var (a, b) = pair;
      Console.WriteLine($"{a} {b} ({nums[a]} + {nums[b]} = {target})");
  }
````

# Format, интерполяция, сырые строки

У типа `string` (или `String` — в этом контексте синонимы) есть статический метод `.Format(string fmt, params object[] args)` с большим количеством перегрузок. Первое значение — форматная строка, остальное — аргументы (что значит `params` — в модуле про методы).

```cs run
int x = 3, y = 4;
Console.WriteLine(string.Format("{0}={1}", x, 5));
Console.WriteLine(string.Format("{0}+{1}={2}", x, y, x + y));
Console.WriteLine(string.Format("{0} и снова {0}", "эхо"));  // номер можно повторять
```

**Интерполяция строк.** Если перед строкой стоит символ `$`, внутри можно вставить `{ }` с любым выражением: компилятор вычислит его и вставит результат `.ToString()`.

```cs run
int x = 3, y = 4;
string s = $"{x}+{y}={x + y}";
Console.WriteLine(s);
double pi = Math.PI;
Console.WriteLine($"π ≈ {pi:F2}, в процентах {0.256:P1}, с шириной [{x,5}]");
```

После двоеточия — формат: `F2` два знака после запятой, `P1` проценты, `X8` шестнадцатеричное, `,5` — ширина поля.

**Сырые строки.** Если поставить `@` перед первым символом, ничего внутри строки не интерпретируется: `
` будет буквально двумя символами. Это называется сырой (verbatim) строкой, удобна для путей Windows:

```cs run
string a = "D:\\Program Files\\a.txt";  // обычная: каждый \ удваиваем
string b = @"D:\Program Files\a.txt";    // сырая: пишем как есть
Console.WriteLine(a == b);
Console.WriteLine(@"строка с \n внутри");
Console.WriteLine("а тут \n перенос");
```

> [!DEEP] Уточнение
> Внутри `@"…"` кавычку пишут удвоенной: `@"он сказал ""привет"""`. А в C# 11 появились ещё и «raw string literals» с тремя кавычками `"""…"""` — их тоже называют сырыми, не путай с `@`.


# Класс Console

Класс `Console` используется для консольного ввода-вывода. Для вывода — статический метод `Console.Write()`, который можно использовать так же, как `string.Format()`:

```cs run
int x = 7;
Console.Write("{0}=5\n", x);
Console.WriteLine("{0} + {1} = {2}", 1, 2, 3);
```

> [!NOTE] Сокращение преподавателя
> Дальше на лекциях преподаватель не будет полностью прописывать `Console.Write()`, а будет писать сокращённо **c.w()**. Когда увидишь на доске `c.w(...)` — это `Console.Write`/`WriteLine`. В конспекте метод записан с маленькой буквы, `Console.write`, — в коде обязательно с заглавной: `Write`.

## Ввод

дополнение `Console.ReadLine()` читает строку целиком и возвращает `string?`: если ввод закончился, придёт `null`. Число из строки получают так:

```cs run
Console.Write("Возраст: ");
int age = int.Parse(Console.ReadLine());   // упадёт с FormatException на «abc»
Console.WriteLine($"Через год будет {age + 1}");

Console.Write("Ещё раз: ");
if (int.TryParse(Console.ReadLine(), out int age2))
    Console.WriteLine($"Через год будет {age2 + 1}");
else
    Console.WriteLine("Это не число");
```

Пример ввода: `25
тридцать
`
Знак вопроса в `string?` говорит «здесь может быть null». Компилятор предупреждает, если ты используешь такое значение без проверки. Предупреждение — не ошибка, но в лабах лучше проверять.


# Полезные методы строк

Строка в C# **неизменяема**: любой метод возвращает **новую** строку, исходная не меняется. Самое нужное для лаб:

| Метод | Пример → результат |
| --- | --- |
| `Length` | `"abc".Length` → 3 |
| `ToUpper / ToLower` | `"Abc".ToLower()` → "abc" |
| `Trim` | `"  a b  ".Trim()` → "a b" |
| `Split` | `"a,b,,c".Split(',')` → ["a","b","","c"] |
| `Split(…, RemoveEmptyEntries)` | `"a  b".Split(' ', StringSplitOptions.RemoveEmptyEntries)` → ["a","b"] |
| `string.Join` | `string.Join("-", new[]{"a","b"})` → "a-b" |
| `Contains / StartsWith / EndsWith` | `"hello".StartsWith("he")` → True |
| `IndexOf` | `"hello".IndexOf('l')` → 2, нет → -1 |
| `Substring` | `"hello".Substring(1, 3)` → "ell" |
| `Replace` | `"a-b".Replace("-", "+")` → "a+b" |
| `string.IsNullOrWhiteSpace` | true для null, "" и "   " |
| индекс | `"hello"[0]` → 'h' (тип char) |

Для символов пригодятся статические методы `char`: `char.IsLetter`, `char.IsDigit`, `char.IsPunctuation`, `char.IsWhiteSpace`, `char.ToUpper`.

```cs run
string s = "  Привет, мир! Как дела?  ";
string t = s.Trim();
Console.WriteLine($"[{t}] длина {t.Length}");
string[] words = t.Split(' ', StringSplitOptions.RemoveEmptyEntries);
Console.WriteLine(words.Length + " слова: " + string.Join(" | ", words));
Console.WriteLine(t.ToUpper());
int letters = 0;
foreach (char c in t) if (char.IsLetter(c)) letters++;
Console.WriteLine("букв: " + letters);
Console.WriteLine(s); // исходная не изменилась
```


# Задача: карточка студента


````task
id: step-4
lang: cs
title: 'Задача: карточка студента'
prompt: |-
  Ввод: ФИО одной строкой (слова через пробелы, могут быть лишние пробелы), затем номер в списке группы. Выведи две строки:

  - `Студент: Фамилия И. О.` — первое слово целиком, от остальных только первые буквы с точкой;
  - `№07 · вариант 2 из 5` — номер двумя цифрами, вариант = номер mod 5 (если 0, то 5). Используй интерполяцию и формат `{n:D2}`.
starter: |-
  string fio = Console.ReadLine();
  int n = int.Parse(Console.ReadLine());
solution: |-
  string fio = Console.ReadLine();
  int n = int.Parse(Console.ReadLine());
  var parts = fio.Split(' ', StringSplitOptions.RemoveEmptyEntries);
  string name = parts[0];
  for (int i = 1; i < parts.Length; i++)
      name += $" {parts[i][0]}.";
  int v = n % 5 == 0 ? 5 : n % 5;
  Console.WriteLine($"Студент: {name}");
  Console.WriteLine($"№{n:D2} · вариант {v} из 5");
````

# Задача: гласные и палиндром


````task
id: step-7
lang: cs
title: 'Задача: гласные и палиндром'
prompt: 'Ввод: строка. Выведи две строки: количество гласных русских и английских букв (`аеёиоуыэюяaeiou`, без учёта регистра) и `палиндром` или `нет` — читается ли строка одинаково с двух сторон, если убрать пробелы и не учитывать регистр. Палиндром проверь циклом с двумя индексами.'
starter: string s = Console.ReadLine();
solution: |-
  string s = Console.ReadLine();
  int count = 0;
  foreach (char c in s.ToLower())
      if ("аеёиоуыэюяaeiou".Contains(c)) count++;
  Console.WriteLine(count);

  string t = s.Replace(" ", "").ToLower();
  bool pal = true;
  for (int i = 0; i < t.Length / 2; i++)
      if (t[i] != t[t.Length - 1 - i]) { pal = false; break; }
  Console.WriteLine(pal ? "палиндром" : "нет");

      Марк

      1
      нет
  - stdin: |
      Level
    stdout: |-
      2
      палиндром
    hidden: true
hints:
  - 'Гласные: foreach (char c in s.ToLower()) if ("аеёиоуыэюяaeiou".Contains(c)) count++; Палиндром: string t = s.Replace(" ", "").ToLower(); сравнивай t[i] и t[t.Length - 1 - i].'
````

# Одномерные массивы

В C# 3 типа массивов, и **все они ссылочные**.

**1. Одномерный массив.** Тип записывается как `[]`, например `int[] a = new int[5];`. Ссылка `a` ссылается на линейную область памяти, где хранится содержимое массива.

- При создании массива его память **зануляется**. Для массива ссылочных типов это значит, что он заполняется `null`.

- У массива **фиксированная длина**. При этом массив — **изменяемая** структура: элементы менять можно.

- Допускается индексация с конца, но не `a[-1]`, а `a[^1]`.

- `a.Length` — свойство длины: не функция и не поле. Содержит количество элементов.

Способы создания, от полного к короткому (цепочка с лекции):

```cs run
int[] a1 = new int[5] { 2, 3, 5, -1, 16 }; // элементов ровно столько, сколько размер
int[] a2 = new int[] { 2, 3, 5, -1, 16 };  // размер можно не писать
int[] a3 = new[] { 2, 3, 5, -1, 16 };      // можно убрать тип
var a4 = new[] { 2, 3, 5, -1, 16 };
int[] a5 = { 2, 3, 5, -1, 16 };            // самый короткий вид

Console.WriteLine(a5.Length);   // 5
Console.WriteLine(a5[0]);       // 2
Console.WriteLine(a5[^1]);      // 16 — последний
Console.WriteLine(a5[^2]);      // -1 — предпоследний

string[] names = new string[3];
Console.WriteLine(names[0] == null); // True: заполнен null-ами
```

> [!DEEP] В конспекте / на самом деле
> В конспекте: «выход за пределы массива в debug-режиме пробрасывает исключение, а в релизе не контролируется». В C# выход за границы проверяется **всегда**, в любом режиме, и бросает `IndexOutOfRangeException`. Возможно, преподаватель сравнивал с C++, где в релизе проверки действительно нет. Проверь сам:
> 
> ```cs run
> int[] a = new int[3];
> a[3] = 1; // IndexOutOfRangeException
> ```


# foreach

```cs
foreach ( in )
{
    ...
}
```

Переменную можно описать прямо внутри: `foreach (int x in A)`. Каждый элемент приводится к указанному типу. Если в коллекции лежат разные типы или нет нужды явно указывать тип, пиши `var`.

```cs run
int[] a = { 1, 2, 3 };
foreach (int x in a) Console.Write(x * 10 + " ");
Console.WriteLine();

object[] mixed = { 1, 2, 3 };
foreach (int x in mixed) Console.Write(x + " "); // каждый object приводится к int
Console.WriteLine();

foreach (var ch in "C#") Console.Write($"[{ch}]");
```

> [!DEEP] Уточнения
> - В конспекте: «переменная может быть уже существующей». В C# в `foreach` переменная **всегда объявляется** в заголовке, взять существующую нельзя.
> - Переменная цикла только для чтения: `x = 5;` внутри foreach не скомпилируется. Чтобы менять элементы массива, нужен обычный `for` с индексом.


# Типичные приёмы с массивами

Почти любая задача на массив — один из шаблонов. Узнаёшь шаблон — пишешь код без раздумий.

| Шаблон | Как |
| --- | --- |
| Накопление (сумма, количество) | переменная до цикла, в цикле `+=` или `++` |
| Поиск лучшего (max, min) | начать с `a[0]`, сравнивать с остальными |
| Поиск элемента | цикл до первого совпадения, `break`; признак «не нашли» — индекс −1 |
| Изменение на месте | только `for` с индексом (переменная `foreach` только для чтения) |
| Разворот | менять местами `a[i]` и `a[n-1-i]` до середины |

```cs run
int[] a = { 4, 8, 15, 16, 23, 42 };

int idx = -1;
for (int i = 0; i < a.Length; i++)
    if (a[i] == 16) { idx = i; break; }
Console.WriteLine("16 на позиции " + idx);

for (int i = 0; i < a.Length / 2; i++)
{
    int j = a.Length - 1 - i;
    (a[i], a[j]) = (a[j], a[i]);       // обмен через кортеж
}
Console.WriteLine(string.Join(" ", a));  // склеить элементы в строку
```

| i | j | массив после обмена |
| --- | --- | --- |
| 0 | 5 | 42 8 15 16 23 4 |
| 1 | 4 | 42 23 15 16 8 4 |
| 2 | 3 | 42 23 16 15 8 4 |
| i = 3 = Length / 2 — стоп, середина пройдена |

# Задача: сколько раз встречается


````task
id: step-5
lang: cs
title: 'Задача: сколько раз встречается'
prompt: 'Первая строка — числа через пробел, вторая — число x. Выведи, сколько раз x встречается в массиве, и индекс его первого вхождения (или −1). Формат: `count=… first=…`.'
starter: |-
  string[] parts = Console.ReadLine().Split(' ');
  int x = int.Parse(Console.ReadLine());
solution: |-
  string[] parts = Console.ReadLine().Split(' ');
  int x = int.Parse(Console.ReadLine());
  int count = 0, first = -1;
  for (int i = 0; i < parts.Length; i++)
  {
      if (int.Parse(parts[i]) == x)
      {
          count++;
          if (first == -1) first = i;
      }
  }
  Console.WriteLine($"count={count} first={first}");
tests:
  - stdin: |
      5 3 5 1 5
      5
    stdout: count=3 first=0
  - stdin: |
      1 2 3
      9
    stdout: count=0 first=-1
  - stdin: |
      4 4 7 4
      7
    stdout: count=1 first=2
    hidden: true
````


# Задача: максимум и его индекс


````task
id: step-6
lang: cs
title: 'Задача: максимум и его индекс'
prompt: |-
  В первой строке ввода — числа через пробел. Выведи максимальное число и его индекс (первое вхождение) в формате `max=… at …`, а в следующей строке — последний элемент, взятый через `^1`.

  Разбить строку: `string[] parts = line.Split(' ');`
starter: |-
  string line = Console.ReadLine();
  string[] parts = line.Split(' ');
  int[] a = new int[parts.Length];
  for (int i = 0; i < parts.Length; i++)
      a[i] = int.Parse(parts[i]);

  // найди максимум и индекс, выведи последний через ^1
solution: |-
  string line = Console.ReadLine();
  string[] parts = line.Split(' ');
  int[] a = new int[parts.Length];
  for (int i = 0; i < parts.Length; i++)
      a[i] = int.Parse(parts[i]);

  int max = a[0], idx = 0;
  for (int i = 1; i < a.Length; i++)
      if (a[i] > max) { max = a[i]; idx = i; }
  Console.WriteLine($"max={max} at {idx}");
  Console.WriteLine($"last={a[^1]}");
tests:
  - stdin: |
      3 9 -2 9 4
    stdout: |-
      max=9 at 1
      last=4
  - stdin: |
      -5 -1 -7
    stdout: |-
      max=-1 at 1
      last=-7
  - stdin: |
      42
    stdout: |-
      max=42 at 0
      last=42
    hidden: true
hints:
  - Начни с int max = a[0], idx = 0; и в цикле обновляй, только если a[i] > max (строго больше — тогда останется первое вхождение).
require:
  - - \^\s*1
    - Последний элемент возьми через индексацию с конца a[^1].
````


# Задача: сумма чётных через foreach


````task
id: step-7
lang: cs
title: 'Задача: сумма чётных через foreach'
prompt: Прочитай числа через пробел, выведи сумму чётных и количество нечётных в формате `even_sum=… odd_count=…`. Используй `foreach`.
starter: string[] parts = Console.ReadLine().Split(' ');
solution: |-
  string[] parts = Console.ReadLine().Split(' ');
  int evenSum = 0, oddCount = 0;
  foreach (string p in parts)
  {
      int x = int.Parse(p);
      if (x % 2 == 0) evenSum += x;
      else oddCount++;
  }
  Console.WriteLine($"even_sum={evenSum} odd_count={oddCount}");
tests:
  - stdin: |
      1 2 3 4 5 6
    stdout: even_sum=12 odd_count=3
  - stdin: |
      -2 -3 0
    stdout: even_sum=-2 odd_count=1
    hidden: true
hints:
  - 'foreach (string p in parts) { int x = int.Parse(p); if (x % 2 == 0) … else … }. Осторожно: у отрицательных нечётных x % 2 == -1, поэтому проверяй чётность через == 0.'
require:
  - - foreach
    - Используй foreach.
````

# Символы, StringBuilder, регулярные выражения

Для Лабы 2 нужно чистить и разбирать текст. Три инструмента:

## 1. char-методы — посимвольная работа

```cs run
string s = "Привет, мир! 2 + 2 = 4?";
string noPunct = new string(s.Where(c => !char.IsPunctuation(c)).ToArray());
Console.WriteLine(noPunct);
Console.WriteLine(s.Count(char.IsLetter) + " букв, " + s.Count(char.IsDigit) + " цифр");
Console.WriteLine(char.IsPunctuation('+') + " " + char.IsSymbol('+'));   // + — символ, а не пунктуация!
```

Осторожно с определениями: в Юникоде `+ = $ ` — «символы» (`IsSymbol`), а `. , ! ? — « »` — пунктуация. В лабе, где нужно «удалить знаки препинания» или «проверить отсутствие специальных символов», явно зафиксируй, что считаешь спецсимволом, и скажи это на защите.

## 2. StringBuilder — собирать строку по кусочку

Строка неизменяема, и `s += x` в цикле каждый раз создаёт новую строку. `StringBuilder` — изменяемый буфер:

```cs run
var sb = new System.Text.StringBuilder();
string[] digits = { "ноль", "один", "два", "три", "четыре", "пять", "шесть", "семь", "восемь", "девять" };
foreach (char c in "Дом 42, кв 7")
    sb.Append(char.IsDigit(c) ? digits[c - '0'] : c.ToString());
Console.WriteLine(sb.ToString());
```

`c - '0'` — трюк: цифра-символ минус символ нуля даёт её числовое значение.

## 3. Regex — шаблоны

```cs run
using System.Text.RegularExpressions;

string messy = "  много    пробелов   тут  ";
Console.WriteLine("[" + Regex.Replace(messy, @"\s+", " ").Trim() + "]");
Console.WriteLine(Regex.IsMatch("abc@mail.ru", @"^[^@\s]+@[^@\s]+\.[^@\s]+$"));
foreach (Match m in Regex.Matches("цены: 100, 250 и 999", @"\d+")) Console.Write(m.Value + " ");
```

`s+` — один или больше пробельных символов, `d` — цифра, `w` — буква/цифра/подчёркивание. Сырая строка `@"…"` тут очень кстати: не надо удваивать обратные слеши.


# Задача: частотный анализ


````task
id: step-2
lang: cs
title: 'Задача: частотный анализ'
prompt: |-
  Разминка к `TextAnalyzer` из Лабы 2: три метода статистики по тексту на LINQ. Слово — цепочка букв и цифр, регистр не важен: «Кот», «кот» и «КОТ» — одно слово `кот`.

  **Что написать**

  - Всё пишешь внутри `static class Analyzer` (он уже в заготовке), методы `public static`.
  - Сначала вспомогательный `private static IEnumerable Words(string text)` — все слова текста **в нижнем регистре**. Проще всего регулярным выражением: `Regex.Matches(text, @"[\p{L}\p{Nd}]+").Select(m => m.Value.ToLower())` (`\p{L}` — любая буква, `\p{Nd}` — цифра). Можно и своим циклом, как в задаче про `yield`.
  - `public static Dictionary WordFrequency(string text)` — словарь «слово → сколько раз встретилось»: `Words(text).GroupBy(w => w).ToDictionary(g => g.Key, g => g.Count())`.
  - `public static IEnumerable Longest(string text, int n)` — `n` самых длинных **разных** слов: `Distinct()` → `OrderByDescending(w => w.Length)` → `Take(n)`. При одинаковой длине слова идут в порядке первого появления в тексте — `OrderBy` устойчивая, ничего дополнительно делать не надо.
  - `public static char MostFrequentLetter(string text)` — самая частая **буква** (не цифра) в нижнем регистре. Возьми `text.Where(char.IsLetter).Select(char.ToLower).ToList()`; если список пуст — `throw new InvalidOperationException(…)`; иначе `GroupBy(c => c)` → `OrderByDescending(g => g.Count())` → `First().Key`. При равенстве победит буква, встреченная раньше: группы идут в порядке первого появления, а сортировка устойчивая.

  **Как проверка будет пользоваться твоим кодом**

  ```cs
  var f = Analyzer.WordFrequency("Кот и кот, и КОТ! Пёс.");
  // f["кот"] == 3, f["и"] == 2, f["пёс"] == 1   (проверка печатает по алфавиту: и=2 кот=3 пёс=1)

  Analyzer.Longest("Лямбда делегат LINQ событие лямбда код", 3);   // делегат, событие, лямбда
  //   длины: делегат 7, событие 7 (равные — в порядке появления), лямбда 6; «лямбда» дважды, но берётся один раз
  Analyzer.Longest("a bb cc d", 2);                                  // bb, cc

  Analyzer.MostFrequentLetter("Абракадабра!");   // 'а' — 5 раз (А и а считаются вместе)
  Analyzer.MostFrequentLetter("xyYX");           // 'x' — x и y по 2 раза, x встретилась раньше
  Analyzer.MostFrequentLetter("123 !!");         // InvalidOperationException — букв нет
  ```

  Main не пиши: проверка сама вызывает методы. `using System.Text.RegularExpressions;` уже стоит в заготовке. Проверка требует `GroupBy` (или `group … by`).
starter: |-
  using System.Text.RegularExpressions;

  static class Analyzer
  {
  }
solution: |-
  using System.Text.RegularExpressions;

  static class Analyzer
  {
      private static IEnumerable<string> Words(string text) =>
          Regex.Matches(text, @"[\p{L}\p{Nd}]+").Select(m => m.Value.ToLower());

      public static Dictionary<string, int> WordFrequency(string text) =>
          Words(text).GroupBy(w => w).ToDictionary(g => g.Key, g => g.Count());

      public static IEnumerable<string> Longest(string text, int n) =>
          Words(text).Distinct().OrderByDescending(w => w.Length).Take(n);

      public static char MostFrequentLetter(string text)
      {
          var letters = text.Where(char.IsLetter).Select(char.ToLower).ToList();
          if (letters.Count == 0) throw new InvalidOperationException("В тексте нет букв");
          return letters.GroupBy(c => c)
                        .OrderByDescending(g => g.Count())
                        .First().Key;
      }
  }
````

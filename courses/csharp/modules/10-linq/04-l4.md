# record и enum

На лекции 08.09 **записи** стоят в колонке ссылочных типов. дополнение `record` — класс для хранения данных, которому компилятор сам генерирует: конструктор, свойства только для инициализации, `Equals`/`GetHashCode` по содержимому, `==`, красивый `ToString` и копирование `with`.

```cs run
enum Priority { Low, Normal, High, Critical }

record Notification(int Id, string Title, Priority Priority);            // позиционная запись
record EmailNotification(int Id, string Title, Priority Priority, string Email)
    : Notification(Id, Title, Priority);                                  // запись-наследник

class Program
{
    static void Main()
    {
        var n1 = new Notification(1, "Сдача лабы", Priority.High);
        var n2 = new Notification(1, "Сдача лабы", Priority.High);
        Console.WriteLine(n1);
        Console.WriteLine(n1 == n2);                         // True: сравнение по содержимому
        var n3 = n1 with { Priority = Priority.Critical };   // копия с изменением
        Console.WriteLine(n3);
        Notification e = new EmailNotification(2, "Письмо", Priority.Low, "teacher@example.com");
        Console.WriteLine(e);
        Console.WriteLine((int)Priority.Critical + " " + Enum.Parse("Normal"));
    }
}
```

**enum** — перечисление: набор именованных констант. Внутри это числа (`Low = 0`, `Normal = 1`…), снаружи — понятные имена. `ToString()` даёт имя, `(int)` — число.


# Сопоставление с образцом (pattern matching)

Помнишь pattern с лекции — «распознающий шаблон, определяет соответствие условию»? В C# это целый набор шаблонов для `is` и `switch`. преподаватель обещал switch-выражения «позже в ходе курса» — вот они.

```cs run
enum Priority { Low, Normal, High, Critical }
record Notification(string Title, Priority Priority);
record Email(string Title, Priority Priority, string Address) : Notification(Title, Priority);
record Sms(string Title, Priority Priority, string Phone) : Notification(Title, Priority);
record Push(string Title, Priority Priority, string DeviceId) : Notification(Title, Priority);

class Program
{
    static string Route(Notification n) => n switch
    {
        Email { Address: var a } => "почта " + a,                     // шаблон типа + свойства
        Sms s when s.Phone.StartsWith("+7") => "SMS по России " + s.Phone,   // с условием when
        Sms s => "SMS за рубеж " + s.Phone,
        Push p => "push на " + p.DeviceId,
        null => throw new ArgumentNullException(nameof(n)),
        _ => "неизвестный тип"                                        // _ — «всё остальное»
    };

    static string Level(Priority p) => p switch
    {
        Priority.Critical or Priority.High => "срочно",
        Priority.Normal => "обычно",
        _ => "когда-нибудь"
    };

    static void Main()
    {
        Notification[] all = { new Email("A", Priority.High, "a@b.ru"), new Sms("B", Priority.Low, "+79001234567"), new Sms("C", Priority.Normal, "+4412345"), new Push("D", Priority.Critical, "dev-1") };
        foreach (var n in all) Console.WriteLine($"{Route(n)} — {Level(n.Priority)}");

        object o = 42;
        if (o is int x and > 0) Console.WriteLine("положительное int " + x);
    }
}
```

| Шаблон | Пример |
| --- | --- |
| тип | `o is string s`, `Email e => …` |
| константа | `null => …`, `Priority.Low => …` |
| сравнение | `>= 90 => "отлично"` |
| логические | `>= 1 and <= 5`, `6 or 7`, `not null` |
| свойства | `{ Address: var a }`, `{ Length: 0 }` |
| условие | `Sms s when s.Phone.StartsWith("+7")` |
| всё остальное | `_` |


# record по строкам, деконструкция и ловушки

Сравним обычный класс и запись с одинаковыми данными — по строкам.

```cs run
class C
{
    public int X { get; }
    public C(int x) => X = x;
}
record R(int X);

class Program
{
    static void Main()
    {
        Console.WriteLine(new C(1) == new C(1));      // 1
        Console.WriteLine(new R(1) == new R(1));      // 2
        Console.WriteLine(new C(1) + " | " + new R(1)); // 3
        var a = new R(1);
        var b = a with { X = 2 };                     // 4
        Console.WriteLine($"{a} {b} {ReferenceEquals(a, b)}");
        // a.X = 5;                                   // 5: CS8852
    }
}
```

| Строка | Результат | Почему |
| --- | --- | --- |
| 1 | False | у класса `==` сравнивает **ссылки**: это два разных объекта |
| 2 | True | у записи компилятор сгенерировал сравнение **по содержимому** |
| 3 | `C | R { X = 1 }` | класс печатает имя типа, запись — имя и все свойства |
| 4 | `R { X = 1 } R { X = 2 } False` | `with` создаёт **новую** запись-копию, исходная не меняется |
| 5 | CS8852 | свойства позиционной записи — `init`: задаются только при создании. Менять — через `with` |

## Деконструкция и позиционные шаблоны

Позиционную запись можно «разобрать» на переменные, а в switch — сопоставлять по позициям, как кортеж:

```cs run
record Point(int X, int Y);

class Program
{
    static string Quarter(Point p) => p switch
    {
        (0, 0) => "начало координат",
        ( > 0, > 0) => "I четверть",
        (  0) => "II четверть",
        (  "III четверть",
        ( > 0,  "IV четверть",
        _ => "на оси"
    };

    static void Main()
    {
        var (x, y) = new Point(3, -4);          // деконструкция
        Console.WriteLine($"x = {x}, y = {y}");
        foreach (var p in new[] { new Point(3, -4), new Point(0, 5), new Point(0, 0), new Point(-1, 2) })
            Console.WriteLine($"{p} → {Quarter(p)}");
    }
}
```

> [!WARNING] switch-выражение без «всё остальное»
> Если ни одна ветка не подошла, switch-выражение бросает **SwitchExpressionException** во время работы. Компилятор об этом предупреждает (CS8509 «не обрабатывает все возможные значения»), но это только предупреждение. Поэтому последней веткой почти всегда ставят `_ => …` — значение по умолчанию или `throw` с понятным сообщением.

````task
  record Point(int X, int Y);

      public static Point Move(this Point p, int dx, int dy)

      }
  }
````

# Задача: форматирование по типу записи


````task
id: step-7
lang: cs
title: 'Задача: форматирование по типу записи'
prompt: |-
  В заготовке три записи: базовая `Order(Title)` и два наследника — `DigitalOrder(Title, Url)` и `PhysicalOrder(Title, Weight)`. Нужно одной функцией описать любой заказ, выбирая ветку **по типу объекта и значению его свойства** — через switch-выражение с шаблонами.

  **Что написать**

  - Записи не трогай. Меняешь только тело `public static string Describe(Order o)` в `static class Fmt`: вместо `=> ""` напиши `=> o switch { … };`.
  - `null => throw new ArgumentNullException(nameof(o))` — в switch-выражении `throw` можно поставить прямо вместо значения.
  - `DigitalOrder d => $"цифровой: {d.Title}, ссылка {d.Url}"` — шаблон типа: если `o` на самом деле `DigitalOrder`, он попадает в переменную `d` уже нужного типа, и у неё есть `Url`.
  - `PhysicalOrder { Weight: > 10 } p` → `тяжёлый: {Title}, {Weight} кг` — шаблон свойства: тип `PhysicalOrder` **и** вес больше 10.
  - Просто `PhysicalOrder p` → `посылка: {Title}, {Weight} кг` — остальные посылки.
  - `_` → `заказ: {o.Title}` — всё остальное (обычный `Order`).
  - Порядок веток важен: сверху частные, снизу общие. Если поставить `PhysicalOrder p` выше ветки с весом, тяжёлые заказы до неё не дойдут (компилятор даже выдаст ошибку CS8510 — ветка недостижима).

  **Как проверка будет пользоваться твоим кодом**

  ```cs
  Console.WriteLine(Fmt.Describe(new DigitalOrder("Курс", "https://x.ru")));  // цифровой: Курс, ссылка https://x.ru
  Console.WriteLine(Fmt.Describe(new PhysicalOrder("Стол", 25)));             // тяжёлый: Стол, 25 кг
  Console.WriteLine(Fmt.Describe(new PhysicalOrder("Книга", 0.8)));           // посылка: Книга, 0,8 кг
  Console.WriteLine(Fmt.Describe(new Order("Услуга")));                       // заказ: Услуга
  Fmt.Describe(null);                                                         // ArgumentNullException
  ```

  Ожидаемый вывод:

  цифровой: Курс, ссылка https://x.ru
  тяжёлый: Стол, 25 кг
  посылка: Книга, 0,8 кг
  заказ: УслугаMain не пиши. Вес `0.8` печатается как `0,8`: курс запускает код в культуре ru-RU, интерполяция `{p.Weight}` сама ставит запятую.
starter: |-
  record Order(string Title);
  record DigitalOrder(string Title, string Url) : Order(Title);
  record PhysicalOrder(string Title, double Weight) : Order(Title);

  static class Fmt
  {
      public static string Describe(Order o) => "";
  }
solution: |-
  record Order(string Title);
  record DigitalOrder(string Title, string Url) : Order(Title);
  record PhysicalOrder(string Title, double Weight) : Order(Title);

  static class Fmt
  {
      public static string Describe(Order o) => o switch
      {
          null => throw new ArgumentNullException(nameof(o)),
          DigitalOrder d => $"цифровой: {d.Title}, ссылка {d.Url}",
          PhysicalOrder { Weight: > 10 } p => $"тяжёлый: {p.Title}, {p.Weight} кг",
          PhysicalOrder p => $"посылка: {p.Title}, {p.Weight} кг",
          _ => $"заказ: {o.Title}"
      };
  }
tests:

    harness: |-

      foreach (var o in list) Console.WriteLine(Fmt.Describe(o));
      try { Fmt.Describe(null); Console.WriteLine("нет"); } catch (ArgumentNullException) { Console.WriteLine("ok"); }
hints:
  - 'Порядок важен: сначала PhysicalOrder { Weight: > 10 } p, потом просто PhysicalOrder p, и в конце Order — иначе общая ветка перехватит частные.'

  - - switch\s*\{
````

# Вопросы по LINQ и записям на защите


````cards
id: step-8
title: Вопросы по LINQ и записям на защите
items:
  - q: Что такое метод расширения и как он вызывается на самом деле?
    a: Статический метод статического класса, у которого перед первым параметром стоит this. Вызов `s.WordCount()` компилятор превращает в `TextExtensions.WordCount(s)`. Доступа к закрытым членам типа у него нет.
  - q: Что значит «LINQ ленивый»?
    a: 'Where, Select и похожие не выполняются сразу, а возвращают описание запроса. Вычисление происходит при переборе: foreach, ToList, Count. Если исходная коллекция изменилась до перебора, результат это учтёт.'
  - q: Чем record отличается от class?
    a: Компилятор генерирует для record сравнение по содержимому (Equals, ==, GetHashCode), ToString со всеми свойствами, копирование через with и неизменяемые свойства в позиционной форме. Class по умолчанию сравнивается по ссылке.
  - q: Где у вас сопоставление с образцом?
    a: 'Покажи switch-выражение или `is` с шаблоном. Пояснение по лекции: pattern — распознающий шаблон, он ничего не порождает, а определяет соответствие условию, в отличие от template.'
  - q: Почему проверка на null в GetWords срабатывает не сразу?
    a: 'Метод с `yield return` — итератор: при вызове он только создаёт объект, а тело начинает выполняться при первом переборе. Проверка аргумента — часть тела, поэтому исключение появится при foreach, ToList или Count.'
  - q: Чем First отличается от FirstOrDefault?
    a: 'На пустой последовательности `First` бросает InvalidOperationException, а `FirstOrDefault` возвращает значение по умолчанию: 0 для int, null для ссылочных типов.'
  - q: Зачем ThenBy, если есть OrderBy?
    a: 'Второй `OrderBy` сортирует всё заново и отменяет первый. `ThenBy` добавляет дополнительный ключ: упорядочивает только элементы, равные по первому.'
  - q: Как изменить запись, если её свойства только для чтения?
    a: 'Никак — её не меняют, а создают изменённую копию: `var b = a with { Year = 2025 };`. Исходная запись остаётся прежней. Это неизменяемость из функционального стиля.'
````

````task
  - Запись `record WordCount(string Word, int Count);` уже в заготовке. Методы — внутри `static class WordStats`, все `public static`.
  - `public static IEnumerable Tokens(this string text)` — расширение-итератор: слова текста в нижнем регистре через `yield return`. Слово — цепочка букв и цифр (`char.IsLetterOrDigit`), как в задаче про `GetWords`. `text == null` → `ArgumentNullException` (может сработать лениво).
  - `public static List TopK(string text, int k)`: `k  w.Word, StringComparer.Ordinal)`, возьми `Take(k)`. Слов меньше k — вернутся все.
  - `public static string Label(this WordCount w)` — расширение со switch-выражением по `w.Count`: `1` → `"разовое"`, `2 or 3` → `"повторяется"`, `>= 4` → `"ключевое"`, всё остальное — `throw new ArgumentOutOfRangeException(…)`. `w == null` → `ArgumentNullException`.
  - Своих циклов-счётчиков в TopK нет: проверка требует `GroupBy` и `yield return`.

  **Как проверка будет пользоваться твоим кодом**

  ```cs
  string text = "Делегат, лямбда и делегат. Событие? Лямбда! Делегат и событие и делегат";
  foreach (var w in WordStats.TopK(text, 3))
      Console.WriteLine($"{w.Word} {w.Count} {w.Label()}");
  // делегат 4 ключевое
  // и 3 повторяется         — «и», «лямбда», «событие»: и встречается 3 раза
  // лямбда 2 повторяется    — «лямбда» и «событие» по 2, «лямбда» раньше по алфавиту
  Console.WriteLine(string.Join("|", "Ок, ОК: ок2".Tokens()));     // ок|ок|ок2
  Console.WriteLine(WordStats.TopK("один", 5).Count);              // 1 — слов меньше k
  WordStats.TopK("текст", 0);                                      // ArgumentOutOfRangeException
  ```

Почему `StringComparer.Ordinal`: в культуре ru-RU обычное сравнение строк ставит кириллицу раньше латиницы и почти не различает регистр, а Ordinal сравнивает коды символов — так же, как сортирует LeetCode. Слова у нас в нижнем регистре, поэтому для кириллицы без «ё» оба способа дают алфавитный порядок. solution: |-
  using System.Text;

  record WordCount(string Word, int Count);

  static class WordStats
  {
      public static IEnumerable<string> Tokens(this string text)
      {
          if (text == null) throw new ArgumentNullException(nameof(text));
          var sb = new StringBuilder();
          foreach (char c in text)
          {
              if (char.IsLetterOrDigit(c)) sb.Append(char.ToLower(c));
              else if (sb.Length > 0) { yield return sb.ToString(); sb.Clear(); }
          }
          if (sb.Length > 0) yield return sb.ToString();
      }

      public static List<WordCount> TopK(string text, int k)
      {
          if (k < 1) throw new ArgumentOutOfRangeException(nameof(k));
          return text.Tokens()
                     .GroupBy(w => w)
                     .Select(g => new WordCount(g.Key, g.Count()))
                     .OrderByDescending(w => w.Count)
                     .ThenBy(w => w.Word, StringComparer.Ordinal)
                     .Take(k)
                     .ToList();
      }

      public static string Label(this WordCount w)
      {
          if (w == null) throw new ArgumentNullException(nameof(w));
          return w.Count switch
          {
              1 => "разовое",
              2 or 3 => "повторяется",
              >= 4 => "ключевое",
              _ => throw new ArgumentOutOfRangeException(nameof(w))
          };
      }
  }
````

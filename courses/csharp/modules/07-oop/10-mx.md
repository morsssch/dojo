  > [!DEEP] Мини-экзамен модуля 6
  > По мотивам LeetCode 155 «Min Stack» (Medium). Задача на проектирование класса: интерфейс, инкапсуляция, свойства, List и исключения.

  **Стек** — коллекция «последним положил — первым взял», как стопка тарелок. Нужен стек целых чисел, который кроме обычных операций **мгновенно** отвечает, какой элемент в нём сейчас минимальный — без перебора всех элементов.

  Интерфейс уже дан в заготовке. Напиши `class MinStack : IStack`:

  - данные — в закрытых полях типа `List`; снаружи их не видно;

  - `Push` кладёт наверх, `Pop` снимает и возвращает верхний, `Peek` возвращает верхний, не снимая, `Count` — свойство только для чтения;

  - свойство `Min` — текущий минимум, работает без цикла по всему стеку;

  - `Pop`, `Peek` и `Min` на пустом стеке бросают `InvalidOperationException`.

  Код верхнего уровня (его пиши **над** объявлениями типов) читает команды до конца ввода: `push x` — ничего не выводит; `pop`, `top`, `min`, `count` — выводят результат. Если стек пуст — выведи `пусто` (поймай исключение), неизвестная команда — `?`.

  Трюк для Min: держи второй список минимумов. При Push кладёшь туда минимум из нового числа и текущего минимума, при Pop снимаешь верхний из обоих.

solution: |-
  var stack = new MinStack();
  string? line;
  while ((line = Console.ReadLine()) != null)
  {
      var cmd = line.Split(' ');
      try
      {
          switch (cmd[0])
          {
              case "push": stack.Push(int.Parse(cmd[1])); break;
              case "pop": Console.WriteLine(stack.Pop()); break;
              case "top": Console.WriteLine(stack.Peek()); break;
              case "min": Console.WriteLine(stack.Min); break;
              case "count": Console.WriteLine(stack.Count); break;
              default: Console.WriteLine("?"); break;
          }
      }
      catch (InvalidOperationException)
      {
          Console.WriteLine("пусто");
      }
  }

  interface IStack
  {
      void Push(int x);
      int Pop();
      int Peek();
      int Count { get; }
  }

  class MinStack : IStack
  {
      private readonly List<int> items = new();
      private readonly List<int> mins = new();

      public int Count => items.Count;

      public int Min
      {
          get
          {
              if (mins.Count == 0) throw new InvalidOperationException("Стек пуст");
              return mins[mins.Count - 1];
          }
      }

      public void Push(int x)
      {
          items.Add(x);
          mins.Add(mins.Count == 0 ? x : Math.Min(x, mins[mins.Count - 1]));
      }

      public int Peek()
      {
          if (items.Count == 0) throw new InvalidOperationException("Стек пуст");
          return items[items.Count - 1];
      }

      public int Pop()
      {
          int top = Peek();
          items.RemoveAt(items.Count - 1);
          mins.RemoveAt(mins.Count - 1);
          return top;
      }
  }

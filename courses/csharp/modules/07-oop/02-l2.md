# Поля, конструктор, модификаторы доступа

Класс описывает, из чего состоит объект (**поля**) и что он умеет (**методы**). Объект создаётся через `new`, при этом вызывается **конструктор** — метод с именем класса и без типа результата.

```cs run
class Student
{
    private string name;       // поле: внутреннее состояние
    private int number;

    public Student(string name, int number)   // конструктор
    {
        if (string.IsNullOrWhiteSpace(name)) throw new ArgumentException("Имя пустое", nameof(name));
        this.name = name;      // this.name — поле, name — параметр
        this.number = number;
    }

    public int Variant(int variants) => number % variants == 0 ? variants : number % variants;
    public override string ToString() => $"{name} (№{number})";
}

class Program
{
    static void Main()
    {
        var s = new Student("Марк", 7);
        Console.WriteLine(s);                  // вызывает ToString()
        Console.WriteLine(s.Variant(5));
        Console.WriteLine(s.Variant(4));
    }
}
```

| Модификатор | Кому виден член |
| --- | --- |
| `private` | только внутри этого класса. **По умолчанию** для членов класса |
| `protected` | внутри класса и его наследников |
| `internal` | внутри той же сборки (проекта). По умолчанию для самих классов |
| `public` | всем |

Правило инкапсуляции: поля делаем `private`, наружу выставляем свойства и методы, которые сохраняют целостность объекта.


# Объект в памяти: new, ссылка, this

Класс — чертёж, объект — вещь, сделанная по чертежу. `new Student("Марк", 7)` делает три вещи: выделяет в куче место под все поля, вызывает конструктор, чтобы их заполнить, и возвращает **ссылку** на новый объект. Класс — ссылочный тип, поэтому переменная хранит ссылку, а не сам объект.

![Переменные s1 и s2 ссылаются на один объект Student в куче, s3 — на другой объект](./diagrams/csharp/diagram-6.svg)

```cs run
class Student
{
    public string Name;
    public int Number;
    public Student(string name, int number) { Name = name; Number = number; }
}

class Program
{
    static void Main()
    {
        var s1 = new Student("Марк", 7);
        var s2 = s1;                       // копия ссылки
        var s3 = new Student("Марк", 7);   // другой объект с теми же данными
        s2.Number = 8;
        Console.WriteLine(s1.Number);      // 8: объект один
        Console.WriteLine(s1 == s2);       // True: одна и та же ссылка
        Console.WriteLine(s1 == s3);       // False: разные объекты, хоть данные и совпадают
    }
}
```

Последняя строка — важная мысль для Лабы 1: для классов `==` по умолчанию сравнивает **ссылки**, а не содержимое. Чтобы сравнивать по смыслу, равенство переопределяют сами (модуль 7).

## this

Внутри метода объекта слово `this` — ссылка на тот объект, для которого метод вызван. Пишут его, когда имя параметра совпадает с именем поля: `this.name = name;`. В вызове `s1.Describe()` внутри Describe `this` — это s1.

## ToString и override

Помнишь методы System.Object с лекции 08.09? У каждого объекта уже есть `ToString()`, по умолчанию он возвращает имя типа. Ключевое слово `override` заменяет эту реализацию своей, и тогда `Console.WriteLine(obj)` и интерполяция `$"{obj}"` сами вызовут твою версию. Подробно про override — в уроке о наследовании.


# Методы объекта и объекты-параметры

Метод, объявленный в классе без `static`, — это **метод объекта**. Он всегда вызывается у конкретного объекта: `s.Describe()`, `a.MoveTo(b, 3)`. Внутри метода имена полей (`apples`, `name`) означают поля **именно того объекта**, у которого метод вызвали, то есть `this.apples`, `this.name`. Код метода один на весь класс, а данные у каждого объекта свои.

## Параметр — объект своего же класса

Параметр метода объявляется так же, как ты делал в [модуле 5](lesson:methods/l1): сначала тип, потом имя. Тип может быть не только `int` или `string`, но и твой собственный класс:

```cs
public void MoveTo(Box other, int n)   // other — ещё один ящик, n — число
```

При вызове `a.MoveTo(b, 3)` внутри метода два ящика: «я» (`this`, то есть `a`) и «другой» (`other`, то есть `b`). Так устроены почти все «парные» операции: расстояние между точками, перевод денег между кошельками, сравнение двух дробей.

```cs run
class Box
{
    private int apples;
    private readonly string name;

    public Box(string name, int apples)
    {
        this.name = name;
        this.apples = apples;
    }

    public void MoveTo(Box other, int n)
    {
        if (other == null) throw new ArgumentNullException(nameof(other));
        if (n > apples) throw new InvalidOperationException($"В ящике {name} только {apples}");
        apples -= n;          // это this.apples — ящик, у которого вызвали метод
        other.apples += n;    // закрытое поле ДРУГОГО ящика: можно, мы внутри класса Box
    }

    public override string ToString() => $"{name}: {apples}";
}

class Program
{
    static void Main()
    {
        var a = new Box("A", 10);
        var b = new Box("B", 2);
        a.MoveTo(b, 3);
        Console.WriteLine(a);   // A: 7
        Console.WriteLine(b);   // B: 5
        try { a.MoveTo(null, 1); }
        catch (ArgumentNullException e) { Console.WriteLine("Ошибка: не передан параметр " + e.ParamName); }
    }
}
```

![В кадре метода MoveTo параметр this указывает на ящик A, параметр other — на ящик B; оба объекта лежат в куче](./diagrams/csharp/diagram-7.svg)

**Трассировка `a.MoveTo(b, 3)`:** в кадр метода кладутся `this` → ящик A (10 яблок), `other` → ящик B (2 яблока), `n = 3`. Проверка на null — other не null, идём дальше. 3 ≤ 10 — исключения нет. `apples -= n` — это поле this, у A стало 7. `other.apples += n` — поле B, стало 5. Метод закончился, кадр снят, но изменения остались в объектах в куче, поэтому `Console.WriteLine(b)` печатает 5.

## Почему можно трогать закрытое поле другого объекта

`private` защищает поле от **других классов**, а не от других объектов. Код внутри `Box` писал автор класса `Box`, он знает его устройство. Поэтому в методе `MoveTo` можно читать и менять `other.apples`, а в `Main` (это другой класс, `Program`) написать `b.apples` нельзя: ошибка CS0122.

## Проверка на null

Класс — ссылочный тип, поэтому вместо объекта в параметр может прийти `null` (урок про [null](lesson:variables/l3)). Обращение `other.apples` тогда упадёт с NullReferenceException где-то в середине метода, и будет непонятно, кто виноват. Принято проверять параметры **первой строкой** и бросать понятное исключение:

```cs
if (other == null) throw new ArgumentNullException(nameof(other));
// nameof(other) — это просто строка "other": имя параметра, которое увидит тот, кто поймает исключение
```

Это одно из общих требований преподавателя к лабам: «проверка параметров на null».

## Если конструктор не написан

Если в классе нет ни одного конструктора, компилятор сам добавляет пустой открытый конструктор без параметров. Поэтому `new Wallet()` работает, даже если ты конструктор не писал: все поля получат значения по умолчанию (0, false, null). Как только ты написал хотя бы один свой конструктор, этот «бесплатный» исчезает.


# Задача: счётчик нажатий


````task
id: step-4
lang: cs
title: 'Задача: счётчик нажатий'
prompt: |-
  Самый простой класс: счётчик нажатий, как у кликера. Только поле, конструктор, методы и `ToString` — свойства будут в следующем уроке.

  **Что написать**

  - `class Counter` с одним закрытым полем `count` типа `int`.
  - Конструктор `public Counter(int start)`: если `start < 0`, брось `ArgumentOutOfRangeException`, иначе запиши `start` в поле.
  - Метод `public void Click()` — увеличивает count на 1.
  - Метод `public void Reset()` — обнуляет count.
  - Метод `public int Value()` — возвращает текущее значение count.
  - `public override string ToString()` — возвращает строку `Нажатий: N`.

  **Как проверка будет пользоваться твоим кодом**

  ```cs
  var c = new Counter(5);
  c.Click();
  c.Click();
  Console.WriteLine(c.Value());   // 7
  Console.WriteLine(c);           // Нажатий: 7 — вызовется твой ToString
  c.Reset();
  Console.WriteLine(c);           // Нажатий: 0
  var d = new Counter(0);
  d.Click();
  Console.WriteLine($"{c.Value()} {d.Value()}");   // 0 1 — у каждого объекта своё поле
  new Counter(-1);                // ArgumentOutOfRangeException
  ```

  Main не пиши: проверка сама создаёт счётчики и вызывает методы.
starter: |-
  class Counter
  {
  }
solution: |-
  class Counter
  {
      private int count;

      public Counter(int start)
      {
          if (start < 0) throw new ArgumentOutOfRangeException(nameof(start));

      }

      public void Click() => count++;
      public void Reset() => count = 0;
      public int Value() => count;
      public override string ToString() => $"Нажатий: {count}";
  }

      True
````

# Задача: точка на плоскости


````task
id: step-6
lang: cs
title: 'Задача: точка на плоскости'
prompt: |-
  Точка на плоскости, которая умеет считать расстояние до другой точки. Здесь всё из этого урока: закрытые поля, конструктор с `this`, метод, который принимает другой объект своего класса, и `ToString`.

  **Что написать**

  - `class Point` с двумя закрытыми полями `x` и `y` типа `double`.
  - Конструктор `public Point(double x, double y)`. Параметры называются так же, как поля, поэтому присваивай через `this`: `this.x = x;`.
  - Метод `public double DistanceTo(Point other)` — расстояние от этой точки до точки `other`: √((x - other.x)² + (y - other.y)²). Корень — `Math.Sqrt(…)`. **Первой строкой**: если `other == null`, брось `ArgumentNullException` с `nameof(other)`.
  - `public override string ToString()` — строка вида `(x; y)`, например `(3; 4)`.

  **Как проверка будет пользоваться твоим кодом**

  ```cs
  var a = new Point(0, 0);
  var b = new Point(3, 4);
  Console.WriteLine(a.DistanceTo(b));     // 5: внутри метода this — это a, other — это b
  Console.WriteLine(b);                   // (3; 4) — вызовется твой ToString
  Console.WriteLine(new Point(1.5, -2));  // (1,5; -2) — дробь печатается с запятой
  a.DistanceTo(null);                     // ArgumentNullException
  ```

  Main не пиши: проверка сама создаёт точки. Если непонятно, почему внутри метода можно читать `other.x`, хотя поле закрытое, — это объясняется в шаге «Методы объекта и объекты-параметры».
starter: |-
  class Point
  {
  }
solution: |-
  class Point
  {
      private double x;
      private double y;

      public Point(double x, double y)
      {
          this.x = x;
          this.y = y;
      }

      public double DistanceTo(Point other)
      {
          if (other == null) throw new ArgumentNullException(nameof(other));
          double dx = x - other.x, dy = y - other.y;
          return Math.Sqrt(dx * dx + dy * dy);
      }

      public override string ToString() => $"({x}; {y})";
  }
tests:
  - name: расстояние и вывод
    stdout: |-
      5
      (3; 4)
      (1,5; -2)
    harness: |-
      var a = new Point(0, 0);
      var b = new Point(3, 4);
      Console.WriteLine(a.DistanceTo(b));
      Console.WriteLine(b);
      Console.WriteLine($"{new Point(1.5, -2)}");
  - name: 'null'
    stdout: ok
    harness: try { new Point(1, 1).DistanceTo(null); Console.WriteLine("нет"); } catch (ArgumentNullException) { Console.WriteLine("ok"); }
  - name: поля закрыты
    stdout: 'True'
    harness: |-
      var f = typeof(Point).GetField("x", System.Reflection.BindingFlags.NonPublic | System.Reflection.BindingFlags.Instance);
      Console.WriteLine(f != null && f.IsPrivate);
hints:
  - public double DistanceTo(Point other) { if (other == null) throw new ArgumentNullException(nameof(other)); double dx = x - other.x, dy = y - other.y; return Math.Sqrt(dx * dx + dy * dy); }
needs:
  - oop/l2
  - methods/l1
  - control-flow/l4
require:
  - - this\.
    - В конструкторе используй this.x = x;
````

# static: общее для всего класса

Член с `static` принадлежит **классу**, а не конкретному объекту. Вызывается через имя класса: `Math.Sqrt`, `int.Parse`, `string.Format` — всё это статические методы. В лабах так делаются **фабрики**: `Rational.From(1, 2)`.

```cs run
class Ticket
{
    private static int counter = 0;         // общий на все объекты
    public int Id { get; }
    public string Title { get; }

    private Ticket(string title)            // конструктор закрыт: создавать только через фабрику
    {
        Id = ++counter;
        Title = title;
    }

    public static Ticket Create(string title)       // статическая фабрика
    {
        if (string.IsNullOrWhiteSpace(title)) throw new ArgumentException("Пустой заголовок");
        return new Ticket(title.Trim());
    }

    public static int Created => counter;
}

class Program
{
    static void Main()
    {
        var a = Ticket.Create("Лаба 1");
        var b = Ticket.Create("Лаба 2");
        Console.WriteLine($"{a.Id}:{a.Title}, {b.Id}:{b.Title}, всего {Ticket.Created}");
    }
}
```

`Id = ++counter;` — префиксный инкремент: сначала увеличить счётчик, потом взять новое значение. Первый билет получит 1, второй — 2. С `counter++` (постфиксным) первый получил бы 0. А поскольку `counter` статический, он один на весь класс и продолжает расти от объекта к объекту.

Статический класс (`static class`) содержит только статические члены, объект от него не создать. Так устроены `Math`, `Console` и будут твои `TextExtensions` и `TextProcessors` в Лабе 2.


# Задача: счётчик созданных объектов и фабрика


````task
id: step-2
lang: cs
title: 'Задача: счётчик созданных объектов и фабрика'
prompt: |-
  Заказы нумеруются сами: первый созданный получает Id 1, второй — 2 и так далее. Для этого нужен счётчик, общий для всех заказов, — статическое поле. А создавать заказы можно только через фабрику с проверкой суммы.

  **Что написать**

  - Закрытое статическое поле-счётчик: `private static int count;`. Оно одно на весь класс, а не своё у каждого заказа.
  - Статическое свойство `public static int Count` только для чтения — сколько заказов создано (возвращает count).
  - Свойства объекта только для чтения: `Id` (int) и `Total` (decimal).
  - **Закрытый** конструктор `private Order(decimal total)`: увеличивает счётчик, берёт его новое значение как Id и запоминает total. Удобно одной строкой: `Id = ++count;` — сначала увеличить, потом взять значение (`count++` вернул бы старое).
  - Статическая фабрика `public static Order Create(decimal total)`: если `total <= 0`, брось `ArgumentException` — тогда заказ не создаётся и счётчик не растёт. Иначе верни `new Order(total)`. Внутри класса закрытый конструктор доступен.

  **Как проверка будет пользоваться твоим кодом**

  ```cs
  var a = Order.Create(100m);
  var b = Order.Create(250.5m);
  Console.WriteLine($"{a.Id} {a.Total} {b.Id} {b.Total} {Order.Count}");  // 1 100 2 250,5 2
  Order.Create(0);          // ArgumentException, Count не меняется
  // new Order(5m);         // не должно компилироваться: конструктор закрыт
  ```

  Статические члены вызываются через имя класса (`Order.Create`, `Order.Count`), а свойства объекта — через переменную (`a.Id`).
starter: |-
  class Order
  {
  }
solution: |-
  class Order
  {
      private static int count;
      public static int Count => count;

      public int Id { get; }
      public decimal Total { get; }

      private Order(decimal total)
      {
          Id = ++count;
          Total = total;
      }

      public static Order Create(decimal total)
      {
          if (total <= 0) throw new ArgumentException("Сумма заказа должна быть положительной", nameof(total));
          return new Order(total);
      }
  }
tests:
  - name: нумерация
    stdout: 1 100 2 250,5 2
    harness: |-
      var a = Order.Create(100m);
      var b = Order.Create(250.5m);
      Console.WriteLine($"{a.Id} {a.Total} {b.Id} {b.Total} {Order.Count}");
  - name: валидация
    stdout: ok 0
    harness: |-
      try { Order.Create(0); Console.WriteLine("нет исключения"); }
      catch (ArgumentException) { Console.WriteLine("ok " + Order.Count); }
  - name: конструктор закрыт
    stdout: '0'
    harness: Console.WriteLine(typeof(Order).GetConstructors().Length);
hints:
  - private static int count; public int Id { get; } private Order(decimal total) { Id = ++count; Total = total; } public static int Count => count;
needs:
  - oop/l6
````

# Инвариант дроби

**Инвариант** — условие, которое верно для объекта всегда, с момента создания. В Лабе 1 (вариант 2) их три:

- Знаменатель не равен нулю.
- Знак числа хранится только в числителе (знаменатель > 0).
- Дробь всегда несократима: у числителя и знаменателя нет общих делителей.

Раз структура неизменяемая, инварианты достаточно обеспечить **в одном месте** — в конструкторе. Отсюда алгоритм нормализации:

- d == 0 → исключение.
- d < 0 → n = −n, d = −d.
- g = НОД(|n|, d); n /= g; d /= g.
- Ноль: 0/5 → 0/1 (НОД(0, 5) = 5, так и получится само).

## НОД по Евклиду

НОД(a, b) = НОД(b, a mod b), пока b не станет нулём. Тогда ответ — a.

```cs run
static int Gcd(int a, int b)
{
    a = Math.Abs(a); b = Math.Abs(b);
    while (b != 0)
        (a, b) = (b, a % b);   // обмен через кортеж
    return a;
}

Console.WriteLine(Gcd(12, 18));  // 6
Console.WriteLine(Gcd(-4, 6));   // 2
Console.WriteLine(Gcd(0, 5));    // 5
Console.WriteLine(Gcd(7, 13));   // 1
```

> [!WARNING] Переполнение
> `int` вмещает примерно ±2,1 млрд. При сложении дробей знаменатели перемножаются: 50000/1 · 1/50000 — уже 2,5 млрд, `int` молча переполнится и даст мусор. Решение: считать промежуточные значения в `long` и проверять, влезает ли результат, либо обернуть вычисления в `checked( … )` — тогда вместо мусора будет `OverflowException`. Отдельный случай: `-int.MinValue` не помещается в int.
> 
> ```cs run
> int big = 50000;
> Console.WriteLine(big * big);           // мусор: переполнение
> try { Console.WriteLine(checked(big * big)); }
> catch (OverflowException) { Console.WriteLine("checked поймал переполнение"); }
> long ok = (long)big * big;
> Console.WriteLine(ok);
> ```

solution: |-
  static int Gcd(int a, int b)
  {
      a = Math.Abs(a); b = Math.Abs(b);
      while (b != 0) (a, b) = (b, a % b);
      return a;
  }

  static (int num, int den) Normalize(int n, int d)
  {
      if (d == 0) throw new ArgumentException("Знаменатель не может быть нулём", nameof(d));

      }

  }

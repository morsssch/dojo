# Общий предок всех типов

В C# у всех типов один общий предок — `System.Object` (короткое имя `object`). От него наследуются и твои классы, и структуры, и даже `int`. Поэтому у **любого** значения есть четыре метода:

| Метод | Что делает | Можно переопределить |
| --- | --- | --- |
| `ToString()` | текстовое представление | да, `virtual` |
| `Equals(object? obj)` | «равен ли я этому объекту» | да, `virtual` |
| `GetHashCode()` | число-«отпечаток» для хэш-таблиц | да, `virtual` |
| `GetType()` | настоящий тип во время выполнения | нет |

`ToString` ты уже переопределял в [модуле 6](lesson:oop/l2): `public override string ToString()`. С `Equals` и `GetHashCode` то же самое: `override` заменяет реализацию из `object` на твою. Сначала посмотрим, как они работают, если ничего не переопределять:

```cs run
class PC { public int X; public PC(int x) => X = x; }
struct PS { public int X; public PS(int x) => X = x; }

class Program
{
    static void Main()
    {
        object o = 42;
        Console.WriteLine(o.ToString() + " " + o.GetType());

        var c1 = new PC(1);
        var c2 = new PC(1);
        Console.WriteLine($"class:  Equals = {c1.Equals(c2)}, == {c1 == c2}");   // ссылки разные

        var s1 = new PS(1);
        var s2 = new PS(1);
        Console.WriteLine($"struct: Equals = {s1.Equals(s2)}");                  // поля равны
        // Console.WriteLine(s1 == s2);   // CS0019: для структуры == не определён

        Console.WriteLine(new PC(1));     // ToString по умолчанию — имя типа
    }
}
```

| По умолчанию | class | struct |
| --- | --- | --- |
| `ToString()` | имя типа | имя типа |
| `Equals` | сравнивает **ссылки**: два объекта с одинаковыми полями не равны | сравнивает **поля**, но медленно: через рефлексию и упаковку |
| `GetHashCode()` | свой у каждого объекта | по полям, но иногда только по первому полю |
| `==` | сравнивает ссылки | не определён — ошибка компиляции |

Вывод: для типа-значения, который сравнивается по содержимому (дробь, деньги, точка), равенство пишут сами. Ровно это требует Лаба 1: `IEquatable` и всё, что к нему прилагается.


# Проверка типа: is и шаблон

Параметр `Equals(object? obj)` принимает что угодно: дробь, строку, число, `null`. Знак вопроса в `object?` значит «здесь может прийти null» (об этом был урок про [null](lesson:variables/l3)). Прежде чем сравнивать, надо проверить, что пришёл именно наш тип, и достать значение. Для этого оператор `is`:

```cs
obj is Point p   // true, если obj — это Point; тогда в новой переменной p лежит это значение
                 // false, если obj другого типа или null; p тогда использовать нельзя
```

```cs run
static string Describe(object? o)
{
    if (o is int n) return $"целое {n}, вдвое больше: {n * 2}";
    if (o is string s) return $"строка из {s.Length} символов";
    if (o is null) return "null";
    return "что-то другое: " + o.GetType().Name;
}

Console.WriteLine(Describe(21));
Console.WriteLine(Describe("привет"));
Console.WriteLine(Describe(null));
Console.WriteLine(Describe(3.5));
```

Как это выглядело раньше и почему шаблон лучше:

```cs
if (obj is Point)               // 1) проверили тип
{
    var p = (Point)obj;         // 2) привели — второй раз проверка типа внутри
    ...
}
if (obj is Point p) { ... }     // то же самое одним действием
```

Отсюда стандартная строчка, которую ты увидишь в каждой реализации равенства:

```cs
public override bool Equals(object? obj) => obj is Rational r && Equals(r);
//  «если пришла дробь — сравни как дробь (вызов Equals(Rational)), иначе false»
```

`&&` здесь важен: если `is` вернул false, правая часть не вычисляется (короткое замыкание из [модуля 3](lesson:control-flow/l1)), и мы не трогаем переменную `r`, которой нет.

# Зачем GetHashCode: как устроен HashSet

`HashSet` и `Dictionary` (из [модуля 6](lesson:oop/l4)) находят элемент почти мгновенно, даже если их миллион. Секрет в **корзинах**:

- У добавляемого значения вызывается `GetHashCode()` — получается число.

- По этому числу выбирается корзина: грубо говоря, `хэш % количество_корзин`.

- Значение кладётся в эту корзину.

- При поиске всё повторяется: хэш → корзина → `Equals` только с теми немногими, кто в этой корзине.

![Значение 1/2 даёт хэш, по хэшу выбирается одна корзина, и Equals вызывается только с элементами этой корзины](./diagrams/csharp/diagram-9.svg)

Отсюда **главное правило**: равные значения (Equals вернул true) обязаны давать **одинаковый** хэш. Иначе два равных значения уйдут в разные корзины, и HashSet их не узнает. Обратное не обязательно: разные значения в одной корзине — нормальная ситуация (коллизия), её разберёт Equals.

```cs run
class Bad
{
    public int X;
    public Bad(int x) => X = x;
    public override bool Equals(object? obj) => obj is Bad b && b.X == X;
    // GetHashCode не переопределён: компилятор предупредит (CS0659)
}

class Good
{
    public int X;
    public Good(int x) => X = x;
    public override bool Equals(object? obj) => obj is Good g && g.X == X;
    public override int GetHashCode() => X.GetHashCode();
}

class Program
{
    static void Main()
    {
        var bad = new HashSet { new Bad(1), new Bad(1) };
        var good = new HashSet { new Good(1), new Good(1) };
        Console.WriteLine($"Bad: {bad.Count}, Good: {good.Count}");   // Bad: 2 — дубликат не узнан
        Console.WriteLine(new Bad(1).Equals(new Bad(1)));            // True, а HashSet этого не увидел
    }
}
```

## Как посчитать хэш из нескольких полей

Готовый помощник: `HashCode.Combine(a, b, …)` — перемешивает хэши всех переданных полей в одно число.

```cs
public override int GetHashCode() => HashCode.Combine(Numerator, Denominator);
```

> [!WARNING] В хэш — только то, что участвует в Equals
> Если в `Equals` сравниваются числитель и знаменатель, в хэш идут ровно они. Взять поле, которое в Equals не участвует, — значит нарушить правило: равные значения получат разные хэши. А самодельное `X + Y` работает, но даёт много коллизий: (1, 2) и (2, 1) попадут в одну корзину.


# Задача: книги без дубликатов


````task
id: step-5
lang: cs
title: 'Задача: книги без дубликатов'
prompt: Есть `class Book` со свойствами `Title` и `Author`. Книги считаются равными, если совпадают и название, и автор. Переопредели в классе `Equals(object? obj)` (через шаблон `is`) и `GetHashCode()` (через `HashCode.Combine`), чтобы `HashSet` перестал хранить дубликаты.
starter: |-
  class Book
  {
      public string Title { get; }
      public string Author { get; }

      public Book(string title, string author)
      {
          Title = title ?? throw new ArgumentNullException(nameof(title));
          Author = author ?? throw new ArgumentNullException(nameof(author));
      }

      public override string ToString() => $"{Author} «{Title}»";
  }
solution: |-
  class Book
  {
      public string Title { get; }
      public string Author { get; }

      public Book(string title, string author)
      {
          Title = title ?? throw new ArgumentNullException(nameof(title));
          Author = author ?? throw new ArgumentNullException(nameof(author));
      }

      public override bool Equals(object? obj) => obj is Book other && Title == other.Title && Author == other.Author;
      public override int GetHashCode() => HashCode.Combine(Title, Author);
      public override string ToString() => $"{Author} «{Title}»";
  }
tests:
  - name: Equals
    stdout: True False False False False
    harness: |-
      var a = new Book("Мастер и Маргарита", "Булгаков");
      var b = new Book("Мастер и Маргарита", "Булгаков");
      var c = new Book("Белая гвардия", "Булгаков");
      Console.WriteLine($"{a.Equals(b)} {a.Equals(c)} {a.Equals(null)} {a.Equals("Булгаков")} {a == b}");
  - name: HashSet
    stdout: |-
      2
      True
    harness: |-
      var set = new HashSet<Book> { new("Мастер и Маргарита", "Булгаков"), new("Мастер и Маргарита", "Булгаков"), new("Белая гвардия", "Булгаков"), new("Белая гвардия", "Булгаков") };
      Console.WriteLine(set.Count);
      Console.WriteLine(new Book("A", "B").GetHashCode() == new Book("A", "B").GetHashCode());
hints:
  - 'public override bool Equals(object? obj) => obj is Book other && Title == other.Title && Author == other.Author; Обрати внимание: == у класса всё ещё сравнивает ссылки, поэтому a == b даёт False.'
needs:
  - oop/l5
  - oop/l4
require:
  - - HashCode\.Combine
    - Посчитай хэш через HashCode.Combine(Title, Author).
  - - \bis\s+Book\s+\w+
    - В Equals используй шаблон obj is Book other.
````

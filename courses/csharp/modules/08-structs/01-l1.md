# Структура — значимый тип

В модуле 6 ты описывал свои **классы**. Структура (`struct`) пишется почти так же: поля, свойства, конструкторы, методы. Отличие одно, но главное: по лекции 08.09 структуры стоят в колонке **значимых** типов, рядом с `int`, `double` и кортежами. Класс — ссылочный тип.

Что это значит на практике: переменная структуры хранит **само значение** (все его поля), а присваивание **копирует** это значение целиком. Переменная класса хранит только ссылку на объект в куче, и присваивание копирует ссылку.

```cs run
struct PointS { public int X; public int Y; }
class PointC { public int X; public int Y; }

class Program
{
    static void Main()
    {
        var s1 = new PointS { X = 1, Y = 2 };
        var s2 = s1;          // копия значения: оба поля скопированы
        s2.X = 100;
        Console.WriteLine($"struct: s1.X = {s1.X}");   // 1

        var c1 = new PointC { X = 1, Y = 2 };
        var c2 = c1;          // копия ссылки, объект один
        c2.X = 100;
        Console.WriteLine($"class:  c1.X = {c1.X}");   // 100
    }
}
```

## Как это выглядит в памяти

Помнишь схему стека и кучи из урока про значимые типы ([модуль 2](lesson:variables/l3))? Для структуры поля лежат прямо там, где объявлена переменная: локальная переменная метода — в кадре стека, поле класса — внутри объекта в куче, элемент массива — внутри массива. Отдельного объекта в куче у структуры нет, поэтому `new PointS()` ничего не выделяет в куче: он просто заполняет поля.

|  | struct | class |
| --- | --- | --- |
| Что хранит переменная | все поля значения | ссылку на объект |
| `b = a` | копирует все поля | копирует ссылку, объект общий |
| Может быть `null` | нет (только `T?`) | да |
| Значение по умолчанию | все поля нули: `default` | `null` |
| Наследование | нельзя наследовать и наследоваться | можно |
| Интерфейсы | можно реализовывать | можно реализовывать |
| Сравнение по умолчанию | `Equals` по полям, `==` не определён | `Equals` и `==` по ссылке |

## Передача в метод

Параметр метода — тоже переменная, а значит, в метод уходит **копия** структуры (если нет `ref`, это ты видел в [модуле 5](lesson:methods/l2)). Метод меняет копию, у вызывающего ничего не меняется:

```cs run
struct Counter { public int Value; }

class Program
{
    static void Inc(Counter c) { c.Value++; }               // меняет копию
    static void IncRef(ref Counter c) { c.Value++; }       // меняет оригинал
    static Counter Next(Counter c) => new Counter { Value = c.Value + 1 };   // возвращает новое значение

    static void Main()
    {
        var c = new Counter { Value = 1 };
        Inc(c);
        Console.WriteLine(c.Value);    // 1: метод получил копию
        IncRef(ref c);
        Console.WriteLine(c.Value);    // 2
        c = Next(c);
        Console.WriteLine(c.Value);    // 3: так принято для значимых типов
    }
}
```

**Трассировка `Inc(c)`:** в кадр стека `Inc` кладётся параметр `c` — копия {Value = 1}. `c.Value++` делает копию {Value = 2}. Метод завершается, кадр снимается вместе с копией. В `Main` по-прежнему {Value = 1}.

дополнение Когда выбирать struct: для **маленьких значений**, которые логично сравнивать по содержимому и не менять: число, дробь, точка, цвет, время, деньги. Ровно такие типы во всех вариантах Лабы 1. Большие объекты с поведением и «личностью» (студент, заказ, окно программы) — классы.

# Задача: время суток


````task
id: step-3
lang: cs
title: 'Задача: время суток'
prompt: |-
  Опиши `struct Time`:

  - свойства только для чтения `Hours` и `Minutes` (`int`);
  - конструктор `Time(int hours, int minutes)`: часы 0..23, минуты 0..59, иначе `ArgumentOutOfRangeException`;
  - метод `Time AddMinutes(int m)` возвращает **новое** время, сдвинутое на m минут, с переходом через полночь (m бывает и отрицательным);
  - `ToString()` → `ЧЧ:ММ`, с ведущими нулями: формат `{Hours:D2}`.
starter: |-
  struct Time
  {
  }
solution: |-
  struct Time
  {
      public int Hours { get; }
      public int Minutes { get; }

      public Time(int hours, int minutes)
      {
          if (hours < 0 || hours > 23) throw new ArgumentOutOfRangeException(nameof(hours));
          if (minutes < 0 || minutes > 59) throw new ArgumentOutOfRangeException(nameof(minutes));
          Hours = hours;
          Minutes = minutes;
      }

      public Time AddMinutes(int m)
      {
          int total = ((Hours * 60 + Minutes + m) % 1440 + 1440) % 1440;
          return new Time(total / 60, total % 60);
      }

      public override string ToString() => $"{Hours:D2}:{Minutes:D2}";
  }
tests:
  - name: сдвиг и полночь
    stdout: |-
      23:50
      00:05
      23:00
      23:55
      23:50
    harness: |-
      var t = new Time(23, 50);
      Console.WriteLine(t);
      Console.WriteLine(t.AddMinutes(15));
      Console.WriteLine(t.AddMinutes(-24 * 60 - 50));
      Console.WriteLine(new Time(0, 5).AddMinutes(-10));
      Console.WriteLine(t);
  - name: проверки и значимый тип
    stdout: |-
      ok1
      ok2
      True
    harness: |-
      try { new Time(24, 0); Console.WriteLine("нет"); } catch (ArgumentOutOfRangeException) { Console.WriteLine("ok1"); }
      try { new Time(1, 60); Console.WriteLine("нет"); } catch (ArgumentOutOfRangeException) { Console.WriteLine("ok2"); }
      Console.WriteLine(typeof(Time).IsValueType);
hints:
  - 'Переведи всё в минуты от полуночи: total = Hours * 60 + Minutes + m. Остаток от деления отрицательного числа в C# отрицательный, поэтому ((total % 1440) + 1440) % 1440. Потом new Time(total / 60, total % 60).'
needs:
  - oop/l2
  - oop/l5
  - control-flow/l4
````

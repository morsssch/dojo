# readonly struct и неизменяемость

`readonly struct` — структура, которую после создания нельзя изменить: все поля обязаны быть `readonly`, а свойства — без `set` (или с `init`). «Изменение» делается возвратом **нового** значения, как у строк.

```cs run
readonly struct Point
{
    public int X { get; }
    public int Y { get; }

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }

    public Point Move(int dx, int dy) => new Point(X + dx, Y + dy);   // новый, старый не трогаем
    public override string ToString() => $"({X}; {Y})";
}

class Program
{
    static void Main()
    {
        var p = new Point(1, 2);
        var q = p.Move(10, 0);
        Console.WriteLine($"{p} → {q}");
        // p.X = 5;   // CS0200: свойство только для чтения
    }
}
```

Зачем так строго? Неизменяемое значение нельзя испортить после проверок в конструкторе. Проверил один раз, что знаменатель не ноль, — и он никогда не станет нулём. Это та самая **внутренняя целостность** из лекции про инкапсуляцию.

> [!WARNING] Ловушка default
> У любой структуры есть значение по умолчанию: `default(Point)` или элемент нового массива `new Point[3]`. Оно создаётся **без вызова твоего конструктора**, все поля — нули. Для точки это (0; 0), и это нормально. А для дроби будет 0/0 — нарушение инварианта «знаменатель не ноль». В Лабе 1 это нужно учесть, например так:
> 
> ```cs
> private readonly int den;                          // для default будет 0
> public int Denominator => den == 0 ? 1 : den;      // снаружи default выглядит как 0/1
> ```
> 
> преподаватель вполне может спросить «а что будет, если создать массив ваших дробей?». Ответ: элементы будут `default`, и благодаря такому свойству они ведут себя как ноль, 0/1.


# Задача: неизменяемый интервал


````task
id: step-2
lang: cs
title: 'Задача: неизменяемый интервал'
prompt: |-
  Опиши `readonly struct Range`:

  - свойства только для чтения `From` и `To` (`int`);
  - конструктор: если `from > to`, **меняет их местами** (инвариант From ≤ To);
  - свойство `Length` = To − From (стрелочная форма);
  - метод `Range Shift(int d)` — новый интервал, сдвинутый на d;
  - метод `bool Contains(int x)`;
  - `ToString()` → `[From..To]`.
starter: |-
  readonly struct Range
  {
  }
solution: |-
  readonly struct Range
  {
      public int From { get; }
      public int To { get; }

      public Range(int from, int to)
      {
          if (from > to) (from, to) = (to, from);
          From = from;
          To = to;
      }

      public int Length => To - From;
      public Range Shift(int d) => new Range(From + d, To + d);
      public bool Contains(int x) => x >= From && x <= To;
      public override string ToString() => $"[{From}..{To}]";
  }
tests:
  - name: инвариант и методы
    stdout: |-
      [3..10] 7 True False
      [3..10] [8..15]
    harness: |-
      var r = new Range(10, 3);
      Console.WriteLine($"{r} {r.Length} {r.Contains(5)} {r.Contains(11)}");
      var s = r.Shift(5);
      Console.WriteLine($"{r} {s}");
  - name: значимая семантика и readonly
    stdout: |-
      True
      True
      True
    harness: |-
      var a = new Range(1, 2);
      var b = a;
      Console.WriteLine(a.Equals(b));
      Console.WriteLine(typeof(Range).IsValueType);
      Console.WriteLine(typeof(Range).GetCustomAttributes(false).Any(x => x.GetType().Name == "IsReadOnlyAttribute"));
hints:
  - public Range(int from, int to) { if (from > to) (from, to) = (to, from); From = from; To = to; }
````

# Задача: структура-деньги


````task
id: step-4
lang: cs
title: 'Задача: структура-деньги'
prompt: 'Опиши `readonly struct Money` со свойствами только для чтения `Rubles` (long) и `Kopecks` (int, 0..99). Конструктор `Money(long rubles, int kopecks)` нормализует копейки: 150 коп → +1 руб 50 коп; отрицательные копейки → `ArgumentOutOfRangeException`. Метод `Money Add(Money other)` возвращает новую сумму. `ToString()` → `12 руб. 05 коп.`'
starter: |-
  readonly struct Money
  {
  }
solution: |-
  readonly struct Money
  {
      public long Rubles { get; }
      public int Kopecks { get; }

      public Money(long rubles, int kopecks)
      {
          if (kopecks < 0) throw new ArgumentOutOfRangeException(nameof(kopecks));
          Rubles = rubles + kopecks / 100;
          Kopecks = kopecks % 100;
      }

      public Money Add(Money other) => new Money(Rubles + other.Rubles, Kopecks + other.Kopecks);
      public override string ToString() => $"{Rubles} руб. {Kopecks:D2} коп.";
  }
tests:
  - name: нормализация и сложение
    stdout: |-
      11 руб. 50 коп.
      13 руб. 05 коп.
      11 руб. 50 коп.
    harness: |-
      var a = new Money(10, 150);
      var b = new Money(1, 55);
      Console.WriteLine(a);
      Console.WriteLine(a.Add(b));
      Console.WriteLine(a);
  - name: ошибка и readonly
    stdout: |-
      ok
      True
    harness: |-
      try { new Money(1, -1); Console.WriteLine("нет"); } catch (ArgumentOutOfRangeException) { Console.WriteLine("ok"); }
      Console.WriteLine(typeof(Money).IsValueType && typeof(Money).GetCustomAttributes(false).Any(x => x.GetType().Name == "IsReadOnlyAttribute"));
hints:
  - 'В конструкторе: if (kopecks < 0) throw …; Rubles = rubles + kopecks / 100; Kopecks = kopecks % 100; ToString: $"{Rubles} руб. {Kopecks:D2} коп."'
````

# Что значит «равны»

По лекции `Equals(object a)` возвращает `true`, если объекты **совпадают по содержанию**. Но по умолчанию:

- для **классов** и `Equals`, и `==` сравнивают **ссылки**: два разных объекта с одинаковыми полями не равны;

- для **структур** `Equals` сравнивает поля (медленно, через рефлексию), а `==` вообще не определён — не скомпилируется.

Поэтому для типов-значений равенство реализуют сами. Полный набор, который требует Лаба 1:

```cs run
readonly struct Money : IEquatable
{
    public decimal Amount { get; }
    public string Currency { get; }
    public Money(decimal amount, string currency) { Amount = amount; Currency = currency ?? throw new ArgumentNullException(nameof(currency)); }

    public bool Equals(Money other) => Amount == other.Amount && Currency == other.Currency;   // IEquatable
    public override bool Equals(object? obj) => obj is Money m && Equals(m);                  // для object
    public override int GetHashCode() => HashCode.Combine(Amount, Currency);                  // равные → равный хэш
    public static bool operator ==(Money a, Money b) => a.Equals(b);
    public static bool operator !=(Money a, Money b) => !a.Equals(b);
    public override string ToString() => $"{Amount} {Currency}";
}

class Program
{
    static void Main()
    {
        var a = new Money(100, "RUB");
        var b = new Money(100m, "RUB");
        Console.WriteLine(a == b);
        Console.WriteLine(a.Equals((object)b));
        Console.WriteLine(a.GetHashCode() == b.GetHashCode());
        var set = new HashSet { a, b, new Money(5, "USD") };
        Console.WriteLine(set.Count);   // 2: a и b — одно значение
    }
}
```

| Член | Зачем |
| --- | --- |
| `bool Equals(T other)` | Сам интерфейс `IEquatable`. Сравнение без упаковки |
| `override bool Equals(object? obj)` | Чтобы работало через object, в коллекциях и у тех, кто не знает про T |
| `override int GetHashCode()` | Правило: **равные объекты обязаны давать равный хэш**. Иначе Dictionary и HashSet сломаются |
| `operator ==` и `!=` | Всегда парой, иначе ошибка CS0216 |

Почему в дроби важна нормализация: если хранить 1/2 и 2/4 как есть, «равенство по содержанию» пришлось бы считать перекрёстным умножением, а хэш не совпал бы. После нормализации обе — 1/2, и достаточно сравнить поля.

# IComparable: кто больше

`IComparable` — один метод `int CompareTo(T other)`. Результат: **отрицательный**, если this меньше; **0**, если равны; **положительный**, если больше. Реализовал — и заработали `Sort`, `OrderBy`, `Max`.

```cs run
readonly struct Grade : IComparable
{
    public int Points { get; }
    public Grade(int p) => Points = p;
    public int CompareTo(Grade other) => Points.CompareTo(other.Points);   // готовый CompareTo у int
    public override string ToString() => Points.ToString();
}

class Program
{
    static void Main()
    {
        var list = new List { new(72), new(95), new(60) };
        list.Sort();
        Console.WriteLine(string.Join("  0);
    }
}
```

Для дробей a/b и c/d сравнение без деления (чтобы не терять точность): сравнить **a·d** и **c·b** — знаменатели положительные, поэтому знак сохраняется. Умножать в `long`, чтобы не переполниться:

```cs
public int CompareTo(Rational other) => ((long)Numerator * other.Denominator).CompareTo((long)other.Numerator * Denominator);
```


# Задача: версия программы


````task
id: step-4
lang: cs
title: 'Задача: версия программы'
prompt: 'Опиши `readonly struct Ver : IEquatable, IComparable` с свойствами `Major` и `Minor` (неотрицательные, иначе `ArgumentOutOfRangeException`). Нужны: `Equals(Ver)`, `Equals(object?)`, `GetHashCode()`, `==`, `!=`, `CompareTo` (сначала по Major, потом по Minor), `ToString()` → `Major.Minor`. И статический `Ver Parse(string s)` для строки `"2.10"` (при плохом формате — `FormatException`).'
starter: |-
  readonly struct Ver : IEquatable<Ver>, IComparable<Ver>
  {
  }
solution: |-
  readonly struct Ver : IEquatable<Ver>, IComparable<Ver>
  {
      public int Major { get; }
      public int Minor { get; }

      public Ver(int major, int minor)
      {
          if (major < 0) throw new ArgumentOutOfRangeException(nameof(major));
          if (minor < 0) throw new ArgumentOutOfRangeException(nameof(minor));
          Major = major;
          Minor = minor;
      }

      public static Ver Parse(string s)
      {
          if (s == null) throw new ArgumentNullException(nameof(s));
          var p = s.Split('.');
          if (p.Length != 2 || !int.TryParse(p[0], out int a) || !int.TryParse(p[1], out int b))
              throw new FormatException($"Неверная версия: {s}");
          return new Ver(a, b);
      }

      public bool Equals(Ver other) => Major == other.Major && Minor == other.Minor;
      public override bool Equals(object? obj) => obj is Ver v && Equals(v);
      public override int GetHashCode() => HashCode.Combine(Major, Minor);
      public static bool operator ==(Ver a, Ver b) => a.Equals(b);
      public static bool operator !=(Ver a, Ver b) => !a.Equals(b);

      public int CompareTo(Ver other)
      {
          int c = Major.CompareTo(other.Major);
          return c != 0 ? c : Minor.CompareTo(other.Minor);
      }

      public override string ToString() => $"{Major}.{Minor}";
  }
tests:
  - name: равенство
    stdout: |-
      True False True True
      2
    harness: |-
      var a = new Ver(1, 2); var b = Ver.Parse("1.2");
      Console.WriteLine($"{a == b} {a != b} {a.Equals((object)b)} {a.GetHashCode() == b.GetHashCode()}");
      Console.WriteLine(new HashSet<Ver> { a, b, new Ver(1, 3) }.Count);
  - name: сравнение и сортировка
    stdout: |-
      0.5 1.9 1.10 2.0
      True
    harness: |-
      var list = new List<Ver> { Ver.Parse("2.0"), Ver.Parse("1.10"), Ver.Parse("1.9"), new Ver(0, 5) };
      list.Sort();
      Console.WriteLine(string.Join(" ", list));
      Console.WriteLine(new Ver(1, 10).CompareTo(new Ver(1, 9)) > 0);
  - name: ошибки
    stdout: |-
      ok1
      ok2
      ok3
    harness: |-
      try { new Ver(-1, 0); Console.WriteLine("нет"); } catch (ArgumentOutOfRangeException) { Console.WriteLine("ok1"); }
      try { Ver.Parse("abc"); Console.WriteLine("нет"); } catch (FormatException) { Console.WriteLine("ok2"); }
      try { Ver.Parse("1.2.3"); Console.WriteLine("нет"); } catch (FormatException) { Console.WriteLine("ok3"); }
````

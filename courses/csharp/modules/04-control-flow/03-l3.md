# switch в C#

В современном C# есть **switch-оператор** и **switch-выражение**. Сейчас про оператор. Отличия от C-подобного switch:

- Любая метка `case` должна заканчиваться одной из трёх строк: `break;`, `return;` или `goto case …;`. Если не написать ни одну — ошибка компиляции.

- Параметром switch может быть **строка**.

```cs run
string cmd = "help";
switch (cmd)
{
    case "run":
        Console.WriteLine("Запуск");
        break;
    case "help":
        Console.WriteLine("Справка");
        goto case "run";      // явный переход вместо «проваливания»
    case "exit":
    case "quit":              // пустые метки подряд — можно
        Console.WriteLine("Выход");
        break;
    default:
        Console.WriteLine("Неизвестная команда");
        break;
}
```

> [!DEEP] Уточнение
> Кроме трёх строк с лекции, case может заканчиваться `throw` или `continue` (если switch внутри цикла) — главное, чтобы управление не «проваливалось» в следующую метку. А несколько пустых меток подряд (`case "exit": case "quit":`) разрешены: это одна ветка с двумя условиями.

Для сравнения, **switch-выражение** (о нём на лекциях будет позже) возвращает значение:

```cs run
int day = 6;
string kind = day switch
{
    6 or 7 => "выходной",
    >= 1 and  "будний",
    _ => "нет такого дня"
};
Console.WriteLine(kind);
```


# Задача: калькулятор на switch


````task
id: step-2
lang: cs
title: 'Задача: калькулятор на switch'
prompt: 'Ввод: три строки — число, операция (`+ - * /`), число (целые). Выведи результат. Если операция неизвестна — `Неизвестная операция`. Деление целочисленное; если делитель 0 — `Деление на ноль`. Используй **switch-оператор** со строкой.'
starter: |-
  int a = int.Parse(Console.ReadLine());
  string op = Console.ReadLine();
  int b = int.Parse(Console.ReadLine());

  switch (op)
  {
      // твои case
  }
solution: |-
  int a = int.Parse(Console.ReadLine());
  string op = Console.ReadLine();
  int b = int.Parse(Console.ReadLine());

  switch (op)
  {
      case "+": Console.WriteLine(a + b); break;
      case "-": Console.WriteLine(a - b); break;
      case "*": Console.WriteLine(a * b); break;
      case "/":
          if (b == 0) Console.WriteLine("Деление на ноль");
          else Console.WriteLine(a / b);
          break;
      default:
          Console.WriteLine("Неизвестная операция");
          break;
  }
tests:
  - stdin: |
      7
      +
      5
    stdout: '12'
  - stdin: |
      7
      /
      2
    stdout: '3'
  - stdin: |
      7
      /
      0
    stdout: Деление на ноль
    hidden: true
  - stdin: |
      7
      %
      2
    stdout: Неизвестная операция
    hidden: true
  - stdin: |
      3
      *
      -4
    stdout: '-12'
    hidden: true
  - stdin: |
      3
      -
      10
    stdout: '-7'
    hidden: true
hints:
  - В ветке "/" сначала if (b == 0) { … } else { … }, и не забудь break в конце каждой ветки, включая default.
require:
  - - switch\s*\(\s*op\s*\)
    - Нужен switch-оператор по строке op.
  - - case\s+"
    - 'Метки case должны быть строками, например case "+":'
````


# Задача: тип дня


````task
id: step-3
lang: cs
title: 'Задача: тип дня'
prompt: 'Ввод: номер дня недели. Через **switch-оператор** со стопкой пустых меток выведи `будний` для 1–5, `выходной` для 6 и 7, иначе `ошибка`.'
starter: |-
  int d = int.Parse(Console.ReadLine());
  switch (d)
  {
  }
solution: |-
  int d = int.Parse(Console.ReadLine());
  switch (d)
  {
      case 1: case 2: case 3: case 4: case 5:
          Console.WriteLine("будний");
          break;
      case 6: case 7:
          Console.WriteLine("выходной");
          break;
      default:
          Console.WriteLine("ошибка");
          break;
  }
tests:
  - stdin: |
      3
    stdout: будний
  - stdin: |
      7
    stdout: выходной
  - stdin: |
      0
    stdout: ошибка
    hidden: true
  - stdin: |
      6
    stdout: выходной
    hidden: true
  - stdin: |
      1
    stdout: будний
    hidden: true
require:
  - - case\s+1\s*:\s*case\s+2
    - 'Сделай стопку меток: case 1: case 2: … и одну ветку на них.'
````

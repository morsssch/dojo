# Три цикла

По лекции `while`, `do while` и арифметический `for (int i …)` такие же, как в C++. Условие — только `bool`.

| Цикл | Когда выбирать | Сколько раз минимум |
| --- | --- | --- |
| `while (усл) { … }` | число повторений заранее неизвестно: «пока есть ввод», «пока не нашли» | 0 |
| `do { … } while (усл);` | тело должно выполниться хотя бы раз: меню, «спросить, пока не введут правильно» | 1 |
| `for (иниц; усл; шаг) { … }` | счётчик: «от 1 до n», «по индексам массива» | 0 |

```cs run
int n = 3;
while (n > 0) { Console.Write(n + " "); n--; }
Console.WriteLine("старт!");

int k = 10;
do { Console.WriteLine("do выполнился хотя бы раз, k = " + k); } while (k  7) break;           // выйти из цикла совсем
    Console.Write(i + " ");
}
Console.WriteLine();
```


# Алгоритм Евклида: цикл, который понадобится в Лабе 1

Чтобы сократить дробь 12/18, нужен наибольший общий делитель (НОД). Евклид заметил: НОД(a, b) = НОД(b, a mod b), а НОД(a, 0) = a. Каждый шаг уменьшает числа, поэтому цикл обязательно закончится.

```cs run
int a = 12, b = 18;
Console.WriteLine($"a={a} b={b}");
while (b != 0)
{
    int r = a % b;
    a = b;
    b = r;
    Console.WriteLine($"a={a} b={b}");
}
Console.WriteLine("НОД = " + a);
```

| Итерация | a | b | r = a % b |
| --- | --- | --- | --- |
| до цикла | 12 | 18 |  |
| 1 | 18 | 12 | 12 % 18 = 12 |
| 2 | 12 | 6 | 18 % 12 = 6 |
| 3 | 6 | 0 | 12 % 6 = 0 |
| b == 0 — выход | ответ a = 6 |

Обрати внимание на первую итерацию: если a < b, алгоритм сам меняет их местами. Отдельно проверять, что больше, не нужно.

> [!WARNING] Бесконечный цикл
> Если условие никогда не станет false (забыл `n--`), программа зависнет. В Visual Studio Code её останавливают Shift+F5, а здесь, в браузере, При зависании рантайм перезапустится сам, а программа покажет сообщение о тайм-ауте.

````task

starter: int n = int.Parse(Console.ReadLine());
````

````task
prompt: 'Ввод: n. Выведи через пробел все простые числа от 2 до n включительно. Число простое, если не делится ни на одно число от 2 до √n. Используй вложенный цикл и `break`.'
starter: int n = int.Parse(Console.ReadLine());
solution: |-
  int n = int.Parse(Console.ReadLine());
  for (int x = 2; x <= n; x++)
  {
      bool prime = true;
      for (int d = 2; d * d <= x; d++)

          if (x % d == 0) { prime = false; break; }
      }
      if (prime) Console.Write(x + " ");
  }
  Console.WriteLine();

    hidden: true
````

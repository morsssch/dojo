# Логическое выражение и if

Программа выбирает путь по **логическому выражению** — значению типа `bool`: `true` или `false`. Его дают операторы сравнения:

| Оператор | Смысл | Пример → результат |
| --- | --- | --- |
| `==` | равно (два знака!) | `5 == 5` → true |
| `!=` | не равно | `5 != 3` → true |
| ` =` | сравнение | `2 >= 3` → false |

```cs run
int age = 20;
bool adult = age >= 18;          // результат сравнения можно хранить
Console.WriteLine(adult);

if (age  [!NOTE] (!!!) С лекции 15.09
> Там, где по логике оператора должно быть логическое выражение (`if`, `while`, `for`), может быть **только выражение логического типа**. `while (i)` недопустим. В C и JavaScript число 0 означает «ложь», а любое другое — «истину»; в C# так нельзя.

```cs run
int i = 3;
// if (i) { }        // CS0029: int нельзя превратить в bool
// if (i = 5) { }    // тоже ошибка: присваивание даёт int — защищает от опечатки = вместо ==
if (i != 0) Console.WriteLine("так правильно");
```

Фигурные скобки
Если в ветке одна команда, скобки можно опустить, как выше. Но вторая строка без скобок уже **не** входит в ветку, хотя стоит с отступом. Надёжное правило для лаб: ставь скобки всегда, кроме совсем коротких однострочников.


# И, ИЛИ, НЕ и тернарный оператор

| Оператор | Смысл | Особенность |
| --- | --- | --- |
| `&&` | И: true, если оба true | если левое false, правое **не вычисляется** |
| `||` | ИЛИ: true, если хоть одно true | если левое true, правое не вычисляется |
| `!` | НЕ: переворачивает | `!true` → false |

Сокращённое вычисление — не мелочь, а приём: `s != null && s.Length > 0` безопасно, потому что при null до `s.Length` дело не дойдёт.

```cs run
string? s = null;
if (s != null && s.Length > 0) Console.WriteLine("непустая");
else Console.WriteLine("null или пустая — и без исключения");

int year = 2028;
bool leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
Console.WriteLine($"{year} високосный: {leap}");

// тернарный оператор: условие ? если_да : если_нет — это ВЫРАЖЕНИЕ, у него есть значение
int a = 7, b = 12;
int max = a > b ? a : b;
Console.WriteLine($"max = {max}, {(max % 2 == 0 ? "чётный" : "нечётный")}");
```

Правило выбора: если по условию нужно **получить значение** — тернарный `?:`; если нужно **сделать разные действия** — `if`.

````task

starter: |-
  int a = int.Parse(Console.ReadLine());
  int b = int.Parse(Console.ReadLine());
  int c = int.Parse(Console.ReadLine());
solution: |-
  int a = int.Parse(Console.ReadLine());
  int b = int.Parse(Console.ReadLine());

# Задача: треугольник


````task
id: step-5
lang: cs
title: 'Задача: треугольник'
prompt: 'Ввод: три длины сторон (целые). Выведи `не треугольник`, если любая сторона ≥ суммы двух других или какая-то сторона ≤ 0. Иначе: `равносторонний`, `равнобедренный` или `разносторонний`.'
starter: |-
  int a = int.Parse(Console.ReadLine());
  int b = int.Parse(Console.ReadLine());
  int c = int.Parse(Console.ReadLine());
solution: |-
  int a = int.Parse(Console.ReadLine());
  int b = int.Parse(Console.ReadLine());
  int c = int.Parse(Console.ReadLine());
  if (a <= 0 || b <= 0 || c <= 0 || a >= b + c || b >= a + c || c >= a + b)
      Console.WriteLine("не треугольник");
  else if (a == b && b == c)
      Console.WriteLine("равносторонний");
  else if (a == b || b == c || a == c)
      Console.WriteLine("равнобедренный");
  else
      Console.WriteLine("разносторонний");

      4
      5
    stdout: разносторонний
  - stdin: |

  - stdin: |

      2
      3
    stdout: не треугольник
  - stdin: |
      5
      5
      8
    stdout: равнобедренный
    hidden: true

    stdout: не треугольник

  - stdin: |

  > [!DEEP] Мини-экзамен модуля 3
  > По мотивам LeetCode 7 «Reverse Integer» (Medium). Нужны условия, цикл с трассировкой цифр и исключения, причём переполнение надо поймать честно.

  Программа читает строки до конца ввода. В каждой строке — целое число типа `int`. Для каждого выведи число, записанное цифрами в обратном порядке, со знаком исходного: `123 → 321`, `-120 → -21`, `0 → 0`.

  - Если перевёрнутое число не помещается в `int` — выведи `0`. Ловить переполнение нужно через `checked` и `catch (OverflowException)`; тип `long` не используй.

  - Если строка — не число (или число не помещается в int) — выведи `ошибка` и продолжай со следующей строкой.

  Подсказка по алгоритму: последняя цифра — `x % 10`, отбросить её — `x /= 10`, приписать к результату — `r = r * 10 + цифра`. Для отрицательного x остаток тоже отрицательный, так что знак получится сам.
starter: |-
  string? line;
  while ((line = Console.ReadLine()) != null)
  {
      // твой код
  }
solution: |-
  string? line;
  while ((line = Console.ReadLine()) != null)
  {
      if (!int.TryParse(line, out int x))
      {
          Console.WriteLine("ошибка");
          continue;
      }

      try
      {
          int r = 0;
          while (x != 0)
          {
              r = checked(r * 10 + x % 10);
              x /= 10;
          }
          Console.WriteLine(r);
      }
      catch (OverflowException)
      {
          Console.WriteLine(0);
      }
  }

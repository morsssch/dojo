# Привет. Ты теперь бэкендер

Ситуация знакомая: хакатон, 48 часов, фронт готов, дизайн шикарный, а API падает на защите, потому что его собрали на коленке в последнюю ночь. Этот курс — чтобы такого больше не было.

К весне ты сможешь:

- писать сервисы на **Go** и понимать, что происходит под капотом, а не копировать заклинания;
- проектировать базу в **PostgreSQL** и писать к ней нормальные запросы;
- работать в команде через **git** и не терять чужой код;
- поднять за час свой **хакатон-стартер**: авторизация, CRUD, файлы, WebSocket, Telegram-бот, LLM, админка;
- упаковать всё в **Docker** и задеплоить, чтобы на защите работало не только на ноутбуке.

Стартовые знания не нужны. Если писал хоть что-то на JS или Python — уже фора.

# Как здесь учиться

Каждый урок — это шаги, как на Stepik. Плитки сверху — карта урока: книга — теория, знак вопроса — вопрос, `</>` — задача, ветка — git, плёнка — схема.

Ритм простой: **почитал кусочек → ответил на вопрос → решил задачу**. Теории за раз немного, зато после каждого куска — проверка, что всё уложилось.

> [!DEEP]
> Блоки «Под капотом» — для тех, кому интересно, как всё устроено внутри: что лежит в памяти, как планировщик раскидывает горутины, что на самом деле летит по сети. Их можно пропускать, но именно они отличают «умею писать» от «понимаю, что пишу».

Код запускается прямо в браузере. Попробуй — поменяй строку и нажми «Запустить»:

```go run
package main

import "fmt"

func main() {
	name := "бэкендер"
	fmt.Println("Привет,", name)
}
```

# Пояса и роадмап

Прогресс копится в **поясах**, как в додзё: белый → жёлтый → оранжевый → … → чёрный. Полоски на конце пояса — модули курса: закрыл модуль — полоска побелела.

**Роадмап** (кнопка сверху) — карта всего курса. Узлы можно двигать, по клику видно, какие уроки внутри и что уже пройдено. Если какую-то тему уже знаешь — отметь «Я это уже знаю», и она засчитается.

В конце многих модулей есть урок **«Проверь себя»**: решишь большую часть — модуль можно закрыть сразу, не проходя всё подряд.

> [!TIP]
> Прогресс хранится в браузере. Чтобы не потерять его или перенести на другой компьютер — в настройках (шестерёнка) есть «Скачать прогресс».

# Песочница и что дальше

**Песочница** (кнопка сверху) — место, где можно гонять Go, SQL на Postgres и git без всяких проверок. Застрял на задаче — сходи туда, поэкспериментируй.

Дальше — поставим Go на твой компьютер и разберёмся с терминалом. Многие уроки курса ещё пишутся: они помечены «скоро» и появятся по мере наполнения.

# Dojo

Платформа интерактивных курсов, которая целиком работает в браузере. Она статическая и хостится на GitHub Pages.

- Теория короткими шагами, после каждого — вопрос.
- Задачи на **Go**, **SQL** (настоящий PostgreSQL через PGlite), **JS** и **Python** с автопроверкой.
- **Git-терминал** с графом коммитов.
- Анимированные схемы, роадмап и прогресс в виде поясов.

```bash
npm install
npm run build:go-runtime   # нужен Go 1.22+
npm run dev
```

Как писать курсы — в [`docs/AUTHORING.md`](docs/AUTHORING.md). Готовые скиллы для создания курсов и статей и инструкции по установке — в [`skills/README.md`](skills/README.md).
